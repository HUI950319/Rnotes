ToyData 概览

14 个示例数据对象：临床队列、机器学习解释与单细胞数据

发布于

2026年9月30日

ToyData 保存各包文档和教程共用的示例数据。目前共有 14 个数据对象，覆盖甲状腺癌、卵巢癌、胰腺癌模型解释和甲状旁腺单细胞分析。它们包括患者数据表、模型解释结果、机器学习任务和 Seurat 对象。

下表按 2026-09-30 本地 ToyData 0.1.0 的实际对象整理。行数、列数及对象类型已读取核对；后续新增或更新数据时，这份目录也需要相应更新。各包的测试仍使用各自附带的数据，不依赖 ToyData。

数据对象一览

对象 类型与规模 内容 适合的展示
toy_ptc_m1_cnd tibble；598 × 95 M1 乳头状甲状腺癌（PTC）清洁队列，含 CND 分组、年龄、治疗和生存结局 基线表、DSS、竞争风险、年龄交互及后续分析示例
seer_thyroid_mtc_2026 tibble；4,549 × 94 SEER 甲状腺髓样癌（MTC）队列，含 AJCC 第 8 版 MTC 分期及衍生变量 回归、生存分析、分期与治疗变量展示
oc_tidy tibble；410 × 43 卵巢癌工作簿首个临床整理表，含人口学、实验室、分期、治疗及 PFS/OS 字段 临床变量探索、缺失情况、队列筛选
oc tibble；375 × 34 来自同一工作簿 Sheet2 的分析队列，剔除结局或时间缺失及随访时间非正的记录 临床回归、生存曲线、基线表
oc1 tibble；304 × 39 Article 1 卵巢癌临床队列，含铂类反应分组及可用的 PFS/OS 时间 铂敏感性分组、生存分析
oc2 tibble；304 × 3 与 oc1 的 ID 对齐的 BMI 表：ID、BMI_2、BMI_3 多时点 BMI 数据合并
oc0 tibble；304 × 41 oc1 按 ID 左连接 oc2，原 BMI 改名为 BMI_1 临床变量与三个时点 BMI 的联合展示
oc_BMI data.table / data.frame；301 × 38 已处理的 BMI 轨迹分析队列，含插补后的临床变量、轨迹类别、类别概率及 PFS/OS BMI 轨迹分组、生存及分组比较
tsk_oc mlr3proba::TaskSurv；310 例，24 个特征 从 oc_tidy 构建的右删失 PFS 任务，目标为 time 和 PFS mlr3 生存学习器及任务接口示例
toy_imp data.frame；45 × 5 胰腺导管腺癌（PDAC）特征重要性结果，含三种重要性方法 MLR 特征重要性图、变量网络图
toy_shp shapviz；SHAP 矩阵 400 × 14 SEER TNM-I 期 PDAC 随机生存森林的 SHAP、特征值及交互结果 SHAP 总结图、重要性、依赖与交互图
Toy_gene_importance data.frame；800 × 5 scMMR DNN 的 16 类细胞基因重要性，每类最多 50 个基因 排名图、基因集 Jaccard 热图、环形棒棒糖图
ref_umap data.frame；170,852 × 3 甲状旁腺参考单细胞数据的 UMAP 坐标与 16 类细胞注释 参考 UMAP、查询细胞投影展示
toy_test Seurat；36,601 个基因 × 3,115 个细胞 甲状旁腺单细胞测试对象，含 RNA、RAS assay 和 group、celltype 元数据 scMMR 预测、通路及单细胞可视化

14 个对象不代表 14 个独立队列。例如 oc0、oc1、oc2 对应同一批 304 例患者的不同数据组织方式；toy_imp 和 toy_shp 是模型解释结果；tsk_oc 是封装好的生存任务。

598 例 M1 PTC：后续分析的共享示例

toy_ptc_m1_cnd 保存了两个研究分析目录共用的清洁临床队列：CND/1.CND_DSS_M1_PTC 与 CND/3.CND_Age_DSS_M1_PTC。它从 seerR::seer_thyroid_2026 按原研究流程筛选，并在保存前完成原年龄分析中的标签整理。

队列范围与分组

  • 诊断范围：2004–2023 年，组织学亚型为 cl.PTC、fv.PTC、tc.PTC 或 ds.PTC。
  • 纳入条件：年龄 18–90 岁、符合原流程的显微镜确诊与分级条件、城乡信息已知、远处转移 M1、全甲状腺切除、随访时间大于 0、DSS 状态已知。
  • 淋巴结分组：保留原 N_4 中的 N0 与 N_noExamined，依次标记为 CND 与 No CND。CND 是该因子的第一水平。
  • 保存内容：598 行、95 个临床及衍生变量；保留原行序、因子顺序和缺失值，没有额外进行完整病例筛选或插补。对象不含患者标识列、拟合模型、.cate 或 .dr_score。

这里的 CND 分组是研究依据登记淋巴结变量作出的操作性定义。解释组间结果时，需要结合原研究的暴露定义，不能仅凭显示标签认定它直接记录了临床手术细节。

生存结局与后续用途

time 的单位为月。DSS 是甲状腺癌死亡的 0/1 指示变量，OS 是全因死亡的 0/1 指示变量；竞争风险展示使用 event 的 0/1/2 编码或相应状态因子。time.RFS、RFS 是原数据保留的其他字段，不是本队列主要的 DSS 结局。

这份数据可以复用于基线表、DSS 生存曲线、Cox 回归、竞争风险和年龄交互展示。进行不同模型分析时，仍需要按所用变量检查缺失情况；“清洁数据”并不表示所有变量均完整。对象的 flt 属性保留了九步纳入筛选的汇总记录，可用于展示筛选流程。

卵巢癌对象之间的关系

oc_tidy 来自 OC_tidy.xlsx 的首个工作表 410整理，oc 来自另一工作表 Sheet2；后者不能简单理解为前者直接删去 35 行。tsk_oc 则由 oc_tidy 筛选并整理而来：保留三个铂类反应组且 PFS 时间可用的患者，去除缺失超过 30% 的特征，并去除 Drug_res、nodes_exa、nodes_pos。

Article 1 的临床与 BMI 数据按下列方式组织：

oc1：304 例临床与生存资料，原 BMI → BMI_1
oc2：相同 ID 的 BMI_2、BMI_3
  └─ 按 ID 左连接 → oc0：304 × 41

oc_BMI：已处理的 301 例 BMI 轨迹分析队列
         含 class、prob1–prob3，以及 PFS/OS

oc1 中 Drug_res 的 0、1、2 分别表示铂敏感、部分敏感、耐药。oc_BMI 包含已插补的临床变量和已生成的轨迹分组，因此展示原始缺失情况应从相应临床表开始。

模型解释与单细胞对象

toy_imp 的三种重要性方法是 mean.SHAP、impurity、permutation。yhat 是方法内部缩放后的重要性，yhat_raw 保留原始值，order 表示该方法内的排名。这个对象适合直接演示重要性绘图，无需重新拟合模型。

toy_shp 来自 TNM-I 期 PDAC 随机生存森林，包含 400 × 14 的 SHAP 矩阵、400 × 14 × 14 的交互数组、特征值和基线值。它与 toy_imp 来自不同的 PDAC 分析设置，不能视为同一模型的两种输出。SHAP 与特征重要性描述模型的预测行为，数值不等同于因果效应。

Toy_gene_importance 的重要性是各细胞类别内的平均绝对 integrated gradients（IG），可用于比较基因排名或不同类别的基因集重叠。ref_umap 只保存坐标和注释；需要表达数据、assay 或细胞元数据时，使用 toy_test。

在本地加载与查看

以下示例用于已经安装 ToyData 的 R 环境。代码展示对象接口，本站不运行这些代码生成患者明细，也不提供数据文件下载。

library(ToyData)

# 查看已安装版本的数据目录和单个对象的帮助
data(package = "ToyData")
help("toy_ptc_m1_cnd", package = "ToyData")

# 加载 M1 PTC 队列，仅查看规模和汇总计数
data("toy_ptc_m1_cnd", package = "ToyData")
dim(toy_ptc_m1_cnd)                         # 598 × 95
table(toy_ptc_m1_cnd[["N_4"]])             # CND 233；No CND 365
table(toy_ptc_m1_cnd[["event"]])           # 0:328；1:175；2:95
summary(toy_ptc_m1_cnd[["time"]])          # 随访月份
attr(toy_ptc_m1_cnd, "flt")                 # 筛选流程汇总

# 数据表、SHAP 对象和任务对象有不同的查看接口
data("oc0", package = "ToyData")
dim(oc0)                                   # 304 × 41

data("toy_shp", package = "ToyData")
dim(toy_shp[["S"]])                       # 400 × 14

# 使用生存任务对象前，需要安装并加载 mlr3proba
library(mlr3proba)
data("tsk_oc", package = "ToyData")
tsk_oc[["nrow"]]                          # 310
length(tsk_oc[["feature_names"]])         # 24

临床数据表用于重新构建分析，结果对象用于复现可视化，任务对象用于衔接学习器；选择对象时，先确认它的结局、筛选条件和数据类型。具体字段说明与准备过程以 ToyData 的帮助页及 data-raw/ 脚本为准。
