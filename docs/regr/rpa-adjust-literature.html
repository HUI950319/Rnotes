RPA 建树时要不要调整协变量：ctree 与 mob 的文献检索

既往预后递归分区研究的做法、方法学依据与 partykit 本机验证

发布于

2026年10月2日

get_rpa() 的两条生存路径对 adj_var 的用法不同：rpa_model = "cit" 用 ctree 建树，adj_var 不进入树，只在建树之后用于调整生存曲线和 HR2；rpa_model = "mob" 把 adj_var 放进每个节点的 Weibull 模型，会影响分裂。本页回答一个问题：既往用 ctree 或 mob 做预后递归分区的研究，建树时有没有加调整变量？

检索日期与范围： 2026-10-02 试检。PMC 全文（E-utilities）与 PubMed 题录对照，Google Scholar 5 条检索式探索维度，PMC 全文按固定种子抽样后逐篇读方法部分。这是有边界的抽样核验，不是系统综述，限制见文末。

结论

  1. ctree 的应用研究建树时都不调整。 读过全文的预后分期研究全部是“多因素 Cox 筛变量 → ctree 不调整建树 → KM 或调整 Cox 验证”。需要证明独立预后价值时，做法是另走一条“调整 HR 分组”的并行路线，而不是改造树。
  2. mob 在医学中主要用于治疗效应亚组。 节点模型放的是治疗变量。用 mob 做预后分层、并在节点模型里放协变量的生存研究只核实到 1 篇。
  3. 方法学上有“调整后建树”的做法：用含协变量的 Cox 模型的鞅残差建树、阶梯函数协变量效应、PALM 树的全局效应等。但在 ctree 的应用论文中没有找到先例：PMC 全文中“ctree + 调整后鞅残差”命中 0 篇。
  4. 对分期研究而言，cit 建树加事后 HR2 与调整曲线是主流写法。若要证明分组独立于协变量，可参照 AJCC 第 9 版 HPV 阳性口咽癌分期：调整 HR 分组与 ctree 分组并行，再用 Groome 标准比较。

背景：调整能放在算法的哪一步

mob 的公式写作 Surv(time, DSS) ~ adj_var | rpa_var：竖线左边是节点模型的回归变量，右边是分区变量。RegR 0.1.3 在 mob 建树前执行 setdiff(adj_var, rpa_var)，但这只作用于建树一步；之后 get_cat() 计算调整曲线和 HR2 时，两条路径都使用原样传入的 adj_var。因此 adj_var 与 rpa_var 应由调用者保证不重叠。

ctree 的默认 logrank 分数等价于不含协变量的 Cox 模型的鞅残差。把它换成含调整变量的 Cox 模型的鞅残差，每次分裂检验的就是“扣除调整变量后，候选变量是否仍与剩余风险相关”，相当于协变量调整后的 logrank 检验。与 mob 不同，每个观测只有一列分数，所以调整变量的效应在亚组间不同不会触发分裂。

本机验证：partykit 能否让 ctree 调整协变量

partykit 1.3.1 有两种写法。函数形式的 ytrafo 在帮助文档中标注为实验性功能。

library(partykit); library(survival)
ctrl <- ctree_control(minsplit = 20L, minbucket = 20L, alpha = 0.05,
                      testtype = "Bonferroni")

# A. 两阶段：全体数据上算一次调整后的鞅残差，再对残差建树
d$mres <- residuals(coxph(Surv(time, DSS) ~ Sex, data = d), type = "martingale")
ctree(mres ~ Age + T_stage, data = d, control = ctrl)

# B. 逐节点：ytrafo 写成函数，每个节点重新拟合 Cox 再取残差
h <- function(y, x, start = NULL, weights, offset, estfun = TRUE, object = FALSE, ...) {
  i  <- weights > 0
  xx <- x[i, colnames(x) != "(Intercept)", drop = FALSE]   # x 为竖线左边的调整变量
  r  <- numeric(length(weights))
  r[i] <- residuals(coxph(y[i, , drop = FALSE] ~ xx), type = "martingale")
  list(estfun = matrix(r, ncol = 1), converged = TRUE)
}
ctree(Surv(time, DSS) ~ Sex | Age + T_stage, data = d, control = ctrl, ytrafo = h)

写法 B 中，ctree 把竖线左边的变量作为 x 传入 ytrafo，实测传入的列为 (Intercept), SexMale。

数据为 RegR 自带的 seer_thyroid_mtc_2026（4387 例），候选变量 Age 与 T_stage，调整变量 Sex，Windows R 4.4.3。全体数据中 Sex 的 HR 为 2.35（P < 1e-23）。

  • 逐节点 logrank 与逐节点鞅残差的分组完全一致，印证两者等价。默认 ctree 只在根节点算一次分数，所以写法 B 即使不调整也不会复现默认树。
  • Sex 的预后作用很强，调整后树却几乎不变。调整能否改变分组，取决于调整变量与候选变量是否相关（混杂），而不是调整变量的预后作用大小。
  • 调整只移动了切点，主干分裂完全相同。

检索方法

来源与通道。 PMC 全文检索（esearch db=pmc）与 PubMed 题录（db=pubmed）用同一检索式对照；对照检索 "survival analysis" 在两库分别返回 347,682 与 200,401 条，通道正常。Google Scholar 跑了 5 条检索式，用于发现词表之外的说法，例如“adjusted prognostic splitting”“PALM tree”，以及 Cedars-Sinai 团队的一组 ctree 分期论文。未跑 OpenAlex 与引文追踪。

其中 CTREE = ("conditional inference tree" OR "conditional inference trees" OR "conditional inference survival tree" OR ctree)，MOB = ("model-based recursive partitioning" OR "model based recursive partitioning")。PubMed 只索引题名与摘要，方法学词汇的召回比 PMC 全文低一到两个数量级，所以以 PMC 全文为主。

抽样与核验。 固定种子 20261002：

  • ctree + 生存 + 分期 + SEER 子集，38 篇抽 20 篇；
  • ctree + 生存 + 分期，555 篇抽 15 篇；
  • mob + 生存 + 预后，123 篇抽 20 篇；
  • ctree + 鞅残差 3 篇、传统 RPA + 鞅残差 47 篇全部纳入。

去重后共 102 篇，取到全文 84 篇，18 篇无开放全文。全文先取 BioC，取不到时改抓 PMC 网页。用脚本摘出建树相关词附近含“调整、残差、协变量、回归变量”的段落，再逐篇读方法部分定案。另按 Google Scholar 线索定向检索 Cedars-Sinai 团队作者（3 篇在 PMC）和 mob 生存节点模型（48 篇按题名分类，6 篇读全文）。

结果

ctree 应用：建树不调整，调整放在外面

随机抽到的 ctree 生存论文大多是机器学习模型比较、综述或非生存结局。真正用 ctree 做预后分组的论文都属于上表的模式。另一种少见用法是把协变量作为候选分裂变量放进树里，例如 Azuero 等 2014，结局是生活质量评分，不是生存。

用 Stata cart 或 rpart 做的传统 RPA 也一样：以 Cox 模型的鞅残差计算分裂统计量，文中都没有提到在这个 Cox 模型里放调整变量；候选变量事先由单因素或多因素 Cox 筛选。例子有：

  • Karski 等 2016，尤文肉瘤：单变量递归分区找年龄切点；
  • Lontos 等 2025，MDS/AML；
  • Acharya 等 2020，儿童低级别胶质瘤；
  • Lamborn 等 2004，胶质母细胞瘤：引用 Therneau 1990 的鞅残差方法。

反向检查没有找到例外。 PMC 全文中：

  • ctree + 调整后鞅残差：0 篇；
  • ctree + 鞅残差：3 篇，均为综述或方法比较；
  • 用到 ytrafo 的 4 篇都不是生存预后分区。

未读全文的同类研究。 Google Scholar 显示 Cedars-Sinai 团队还有一批 ctree 分期论文，不在 PMC，未核实建树细节：

  • Nguyen 等 2021，Merkel 细胞癌淋巴结负荷，J Am Acad Dermatol；
  • Daskivich 等 2022，前列腺癌 pN 分期，J Urol；
  • Patel 等 2019，膀胱尿路上皮癌 pN 分期，Eur Urol Oncol；
  • Ho 等 2023，唾液腺癌分级分期，Head Neck。

mob 应用：主要是治疗效应亚组

“mob + 生存 + 节点模型”的 48 篇按题名分类：除去综述、方法学和明显无关的论文，应用研究以治疗效应异质性为主，即节点模型放治疗变量，用其他变量分组。读过全文的例子：

  • Chen 等 2020，IgA 肾病免疫抑制治疗；
  • Shepherd-Banigan 等 2020，照护者教育干预；
  • Seidenfeld 等 2021，急诊照护过渡干预。

另有 CPAP 的 ISAACC 试验系列，仅看了题名。

节点模型放协变量、用于预后分层的例子只核实到两篇：

  • Safe 等 2017，伊朗乳腺癌生存：以指数分布为例，节点模型含 ER 与年龄，分裂变量为 HER2、PR 与年龄，年龄兼任两种角色。文中转述的既往德国乳腺癌队列（686 例）mob 示例，同样是把 2 个因素作为节点模型协变量、其余因素作为分区变量。
  • Pirkle 等 2018，代谢综合征风险分群：明确用 mob 得到“按年龄调整的风险组”，但结局为二分类，不是生存。

方法学文献

对分期研究的启示

  1. get_rpa(rpa_model = "cit") 建树，再用 HR2 与调整曲线评价分组，是这类论文的主流写法，审稿人熟悉。
  2. 需要证明分组独立于协变量时，参照 AJCC 第 9 版 HPV 阳性口咽癌分期：调整 HR 分组与 ctree 分组并行，用 Groome 标准比较两套分期的表现。这比改造 ctree 更容易被接受。
  3. 残差法（调整后鞅残差）有方法学出处，但在 ctree 应用论文中没有先例。若采用，方法部分需要专门论证，引用 Therneau 1990 与 Keleş & Segal 2002 这一脉文献，并说明分组的含义变为“扣除调整变量后的剩余预后差异”。
  4. 无论哪种做法，分组都是在数据上挑出来的，同一数据上估计的 HR 与 P 值偏乐观，需要 bootstrap 内部验证或外部队列验证。

覆盖限制

  • 只查了 PMC 全文，非开放获取论文进不来。抽样的 102 篇中 18 篇无全文。
  • 未跑 OpenAlex 与引文追踪，Google Scholar 只跑了 5 条检索式。
  • 应用研究的结论来自抽样核验加定向检索，不是穷尽检索。完整核验 ctree 生存分期约 555 篇与 mob 生存约 160 篇的全文池尚未进行。
  • 方法学表中标“仅题录”或“摘录”的文献未读原文；Cedars-Sinai 团队 4 篇非 PMC 论文未核实建树细节。
