get_eff 竞争风险 CIF：FGR 与 CSC 的耗时和结果差异

cif_args 与 show_surdiff 在不同样本量下的基准评估

发布于

2026年9月29日

评估对象是 RegR 0.1.3（commit 7f2aced）的 get_eff()，在竞争风险分析（surv = FALSE）中比较两个设置：

  • cif_args = list(model = c("FGR", "CSC"))：调整后 CIF（sur_direct）的工作模型。"FGR"（默认）是 Fine-Gray 模型，只能用 50 次 bootstrap 求 CI；"CSC" 是各原因 Cox 模型，用 riskRegression::ate() 的解析方差。
  • show_surdiff = TRUE / FALSE：是否生成 CIF / ΔCIF 表（sur_*）。

结论

  1. CSC 比 FGR 快得多，而且样本越大差距越大。单看 CIF 表新增的耗时，FGR 是 CSC 的 5 倍（n = 500）、10 倍（n = 4387，完整真实数据）、约 96 倍（n = 35096）。整次调用的总耗时差距是 4–8 倍，因为 sHR 表两个后端都要算，把差距摊薄了。
  2. FGR 的耗时几乎全花在 50 次 bootstrap 上。它随 n 近似按 n1.7 增长，5 个 fork worker 一起跑：n = 35096 时墙钟 211 s，CPU 时间 929 s。CSC 的 CIF 部分在 n = 35096 时也只多 2 s 左右。
  3. 竞争风险下，show_surdiff = FALSE 省下的时间几乎等于 FGR 的 bootstrap。用 CSC 时关掉 show_surdiff 只省 0.2–2 s。n 很大时，show_surdiff = FALSE 本身也要 23 s，瓶颈是 tidycmprsk::crr 拟合 sHR 表（约按 n1.9 增长），cif_args 管不到这一步。
  4. 两个后端的结果基本一致。sHR 表和 sur_unadj 完全相同。调整后 CIF 点估计相差 ≤ 1.0 个百分点，ΔCIF 相差 ≤ 1.1 个百分点，所有对比的显著性结论相同。CSC 的 CI 宽度落在 FGR 换随机种子后的波动范围内。
  5. FGR 的 CI 和 P 值受随机种子影响。n_boot = 50 时，同一数据换 5 个种子，CI 宽度变化可达 ±25%；Race = Other/Unknown 的 P 值在 0.019–0.050 之间波动，恰好跨过 0.05。CSC 的结果是确定的。

测试设置

  • 环境：WSL Ubuntu-22.04，R 4.4.3，24 逻辑核；adjustedCurves 0.11.4.9000，riskRegression 2023.12.21，tidycmprsk 1.1.0。已核对 WSL 安装版 RegR 与源码 HEAD 一致。
  • 数据：RegR::seer_thyroid_mtc_2026（n = 4387；event 0/1/2 = 3207/597/583）。n ≤ 4387 用无放回抽样；n = 8774、17548、35096 用有放回重抽样放大（表中标 *），重复行会带来结，只用于看耗时的增长趋势。
  • 计时调用：get_eff(d, cat_var = "Sex", adj_var = c("Age", "Race", "M"), surv = FALSE, time = 120, ...)，methods 用默认的 c("unadj", "direct")。
  • 配置：① show_surdiff = FALSE（此时 cif_args 不起作用）；② show_surdiff = TRUE + cif_args = list(model = "FGR")（即默认）；③ 同上但用 "CSC"。另测了 Cox（surv = TRUE）下 show_surdiff 开和关作为对照。
  • 重复：n ≤ 4387 每格 5 次，更大的 n 每格 3 次；每个 n 内部配置顺序随机打乱，正式计时前先预热一次。报告取墙钟时间中位数。
  • 并行：单个 cat_var 时外层串行。FGR 的 adjustedcif(bootstrap = TRUE, n_boot = 50, n_cores = 5) 在 Linux 上走 fork 后端。

耗时结果

n 从 4387 增到 35096（8 倍）时，拟合出的幂律指数：FGR 总耗时约 n1.74，FGR 的 CIF 增量约 n1.73，show_surdiff = FALSE（即 crr 的 sHR 表）约 n1.90，CSC 的 CIF 增量约 n0.63。大样本下，CSC 调用的总耗时基本就是 crr 拟合 sHR 表的耗时。

CPU 时间说明了 FGR 贵在哪里：n = 35096 时，FGR 墙钟 211 s、CPU 929 s（约 4.4 个核满载）；CSC 墙钟 25 s、CPU 63 s。在共享服务器或 Windows PSOCK 环境下，FGR 的实际代价会比这里的墙钟时间更明显。

show_surdiff 开和关

  • 竞争风险 + FGR（默认）：打开 show_surdiff 后总耗时是关闭时的 9–13 倍，这是最值得优化的地方。
  • 竞争风险 + CSC：打开后在 n ≤ 2000 时约为关闭时的 3 倍，但绝对值不到 0.5 s；n 越大越接近 1 倍。
  • Cox：打开后每次多 0.14–0.7 s，基本可以忽略。

FGR 与 CSC 的结果差异

固定条件：完整数据 n = 4387，cat_var = c("Sex", "Race", "Che", "M")，adj_var = c("Age", "Sur")，分别在 60 个月和 120 个月比较 sur_direct。

  • haz_unadj、haz_direct 两张表在 FGR 与 CSC 之间 identical() 为 TRUE，sur_unadj（Aalen–Johansen）也完全相同。cif_args 只影响 sur_direct。
  • ΔCIF 的方向约定：estimate = 参照组 CIF − 该组 CIF，所以 Male、M1 等风险更高的组显示为负值。

FGR 随机种子造成的波动

在 120 个月、同一数据上用 5 个种子（101–105）重跑 FGR：点估计完全不变（点估计不依赖 bootstrap），但 CI 和 P 值都会变。

样本量变化时的一致性（Sex，120 个月）

两个后端的 ΔCIF 始终同号、显著性判断相同。FGR 的 |ΔCIF| 系统性地大 0.3–0.7 个百分点，原因是两者的工作模型不同（比例子分布风险 vs 各原因比例风险），不是随机误差。n = 500 和 1000 时两个后端都不显著（P ≈ 0.06–0.08）。

建议

  • n ≥ 5000、多个 cat_var，或有 sub_var / split_var（每个亚组都要重做一次 bootstrap）时，用 cif_args = list(model = "CSC")。点估计差异在 1 个百分点以内，结果可复现，不受随机种子影响。
  • 要与既往结果对齐，或想让 CIF 曲线与 sHR 表出自同一个 Fine-Gray 模型时，保留默认的 FGR。此时固定 set.seed()，并留意 P 接近 0.05 的对比（n_boot = 50 的 bootstrap P 值精度有限）。
  • 只需要 sHR 表时用 show_surdiff = FALSE，这是最快的配置；但 n 很大时 crr 本身仍是瓶颈（n = 35096 约 23 s）。
  • 帮助页里 “CSC roughly 15x faster” 的说法与实测大致相符（仅 CIF 部分：n = 4387 时约 10 倍，n 越大倍数越高），可以补充说明这个倍数随 n 变化。

局限

  • 只测了 WSL（Linux fork 后端）。Windows R 上 bootstrap 走 PSOCK，每次都要启动进程，FGR 的额外开销预计更大，本次没有测量。
  • 计时只用了一个二分类 cat_var、无 sub_var 的场景。多个 cat_var 时外层会并行（上限 4 个 worker × 内层 5 核），耗时不能简单按变量数线性相乘。
  • n > 4387 的数据是重抽样放大的，只用于看耗时的增长趋势，不应拿来解释效应量。

复现脚本

两个脚本都在 WSL 的 Rscript 下运行，工作目录里生成 bench_timing.csv、bench_results.rds 和 agree_results.rds。本页的耗时图表直接读取 bench/bench_timing.csv。

bench.R：耗时基准 
suppressMessages(library(RegR))
pdf(NULL)
out_csv <- "bench_timing.csv"; if (file.exists(out_csv)) file.remove(out_csv)
d0 <- as.data.frame(RegR::seer_thyroid_mtc_2026)
d0$DSS <- as.numeric(d0$DSS)
ns <- c(500, 1000, 2000, 4387, 8774, 17548, 35096)
cfgs <- list(
  crr_surdiff_FALSE = list(surv = FALSE, show_surdiff = FALSE),
  crr_FGR           = list(surv = FALSE, show_surdiff = TRUE, cif_args = list(model = "FGR")),
  crr_CSC           = list(surv = FALSE, show_surdiff = TRUE, cif_args = list(model = "CSC")),
  cox_surdiff_FALSE = list(surv = TRUE,  show_surdiff = FALSE),
  cox_surdiff_TRUE  = list(surv = TRUE,  show_surdiff = TRUE)
)
quiet <- function(expr) suppressWarnings(suppressMessages(capture.output(r <- expr))) 
call_eff <- function(d, cfg) {
  res <- NULL
  st <- system.time(quiet(res <- do.call(get_eff, c(list(d, cat_var = "Sex",
          adj_var = c("Age", "Race", "M"), time = 120), cfg))))
  list(res = res, st = st)
}
make_data <- function(n) {
  set.seed(20260929 + n)
  if (n <= nrow(d0)) d0[sample(nrow(d0), n), ] else d0[sample(nrow(d0), n, replace = TRUE), ]
}
invisible(call_eff(make_data(500), cfgs$crr_CSC)); invisible(call_eff(make_data(500), cfgs$cox_surdiff_TRUE))  # warm-up
keep <- list(); slow <- character()
for (n in ns) {
  d <- make_data(n)
  reps <- if (n <= 4387) 5 else 3
  for (r in seq_len(reps)) for (nm in sample(names(cfgs))) {
    if (nm %in% slow) next
    set.seed(r)
    x <- call_eff(d, cfgs[[nm]])
    row <- data.frame(n = n, cfg = nm, rep = r, elapsed = x$st[["elapsed"]],
                      cpu = sum(x$st[c("user.self","sys.self","user.child","sys.child")], na.rm = TRUE))
    write.table(row, out_csv, sep = ",", append = file.exists(out_csv), col.names = !file.exists(out_csv), row.names = FALSE)
    cat(sprintf("n=%d %-18s rep%d %.2fs\n", n, nm, r, row$elapsed))
    if (r == 1 && nm %in% c("crr_FGR","crr_CSC")) keep[[paste(n, nm)]] <- x$res
  }
  for (nm in names(cfgs)) { # stop growing a config once it exceeds 10 min
    tt <- read.csv(out_csv); if (any(tt$cfg == nm & tt$n == n & tt$elapsed > 600)) slow <- c(slow, nm)
  }
}
saveRDS(keep, "bench_results.rds")
agree.R：FGR 与 CSC 结果一致性 
suppressMessages(library(RegR))
pdf(NULL)
d <- as.data.frame(RegR::seer_thyroid_mtc_2026)
quiet <- function(expr) invisible(suppressWarnings(suppressMessages(capture.output(expr))))
fit <- function(m, tm, ...) { res <- NULL
  quiet(res <- get_eff(d, cat_var = c("Sex","Race","Che","M"), adj_var = c("Age","Sur"),
                       surv = FALSE, time = tm, cif_args = list(model = m), ...)); res }
agree <- list()
for (tm in c(60, 120)) for (m in c("FGR", "CSC")) { set.seed(1); agree[[paste(tm, m)]] <- fit(m, tm) }
for (s in 1:5) { set.seed(100 + s); agree[[paste0("seed", s)]] <- fit("FGR", 120, methods = "direct")$sur_direct }
saveRDS(agree, "agree_results.rds"); cat("DONE\n")
