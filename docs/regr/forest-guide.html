当前 Cox/Logistic 提示与逐模型森林

以下按已推送 RegR 90ad6d8 在 Windows / WSL R 4.4.3 执行。此前只有 Fine–Gray 的诊断说明；现在 Cox/Logistic 拟合遇到 NA 系数，也会说明未参与估计的设计列、原因、公式和完整病例数，亚组调用会加上所属层。

拟合完成仍需核对实际调整项

library(RegR)
set.seed(831)
forest_data <- data.frame(Tx = factor(sample(c("No", "Yes"), 600, TRUE)),
  Sex = factor(sample(c("F", "M"), 600, TRUE)), Age = rnorm(600, 55, 10))
t1 <- rexp(600, exp(0.3 * (forest_data[["Tx"]] == "Yes") +
  0.3 * (forest_data[["Sex"]] == "M") + 0.02 * (forest_data[["Age"]] - 55)) / 60)
t2 <- rexp(600, 1 / 120)
tc <- rexp(600, 1 / 160)
forest_data[["time"]] <- pmin(t1, t2, tc) + 0.2
forest_data[["event"]] <- ifelse(t1 < t2 & t1 < tc, 1L, ifelse(t2 < tc, 2L, 0L))
forest_data[["DSS"]] <- as.integer(forest_data[["event"]] == 1L)
forest_data[["response"]] <- rbinom(600, 1, plogis(-0.5 +
  0.4 * (forest_data[["Tx"]] == "Yes") + 0.03 * (forest_data[["Age"]] - 55)))
forest_data[["era"]] <- factor(rep(c("early", "late"), 300))
forest_data[["grade"]] <- factor(ifelse(forest_data[["era"]] == "late", "Unknown",
                                         rep(c("G1", "G2", "Unknown"), 200)))
forest_data[["Age_copy"]] <- forest_data[["Age"]]
collect_alias <- function(expr) {
  notes <- character()
  result <- withCallingHandlers(expr, RegR_aliased_coef = function(m) {
    notes <<- c(notes, cli::ansi_strip(conditionMessage(m)))
    invokeRestart("muffleMessage")
  })
  list(result = result, notes = notes)
}
cox_alias <- collect_alias(get_eff(forest_data, "Tx", sub_var = "era",
  adj_var = c("Age", "grade"), surv = TRUE,
  methods_haz = "direct", methods_sur = character(), all = NULL))
log_alias <- collect_alias(tryCatch(get_eff(forest_data, "Tx", sub_var = "era",
  adj_var = c("Age", "Age_copy"), surv = "response",
  methods_haz = "direct", methods_sur = character(), all = NULL), error = identity))
stopifnot(length(cox_alias[["notes"]]) >= 1L, length(log_alias[["notes"]]) >= 1L,

          grepl("conf.low", conditionMessage(log_alias[["result"]]), fixed = TRUE))
cat(paste(cox_alias[["notes"]], collapse = "\n"))
conditionMessage(log_alias[["result"]])
log_age <- get_eff(forest_data, "Tx", sub_var = "era", adj_var = "Age",
  surv = "response", methods_haz = "direct", methods_sur = character(), all = NULL)

late 层有 300 个完整病例，Cox 模型的 grade 全为 Unknown；设计矩阵中的 G2 列全 0，Unknown 列全 1，相应常量由基线风险吸收。Logistic 示例则让 Age_copy 完全复制 Age，消息给出共线关系。消息类为 RegR_aliased_coef，也继承 RegR_empty_levels，不是“已修复所有变量”的保证。只有一个观察水平的因子仍可能在 Logistic 构建设计矩阵时直接报 contrasts 错误，不能假定一定能完成拟合并给出 NA 提示。

本例 Cox 返回结果；Logistic 在提示 Age_copy 共线后，当前版本仍会在整理系数与置信区间时因列长度不一致而报错，上面的 tryCatch() 用于保留并检查这个错误，不会生成有效效应表。末尾移除重复列、仅调整 Age 后成功返回；实际分析需先按研究方案核对调整集合，再重新拟合，不要仅消除提示后继续使用失败对象。

这与患者数据缺失导致的完整病例减少不同。即使拟合正常返回，也不能据此写“已调整所有请求变量”，或把 NA 系数改成零效应。相关 Cox 入口（如 get_cat()、get_fit()、get_roc_cox()）复用此提示，bootstrap 重拟合保持安静；Fine–Gray 的常量移除和奇异错误仍按下方合同处理。

非 95% 区间的显示 P 值

library(RegR)
set.seed(20261021)
ci_data <- data.frame(Tx = factor(rep(c("No", "Yes"), 240)), Age = rnorm(480, 55, 10))
failure <- rexp(480, exp(-3.8 + 0.2 * (ci_data[["Tx"]] == "Yes") + 0.02 * (ci_data[["Age"]] - 55)))
censor <- rexp(480, 0.012)
ci_data[["time"]] <- pmin(failure, censor)
ci_data[["DSS"]] <- as.integer(failure <= censor)
ci80 <- get_eff(ci_data, "Tx", adj_var = "Age", methods = "direct",
  conf_level = 0.8, show_sur = FALSE, all = NULL)[["haz_direct"]]
rows <- which(ci80[["row_type"]] == "level" & is.finite(ci80[["estimate"]]) &
  ci80[["conf.high"]] > ci80[["conf.low"]])
estimate <- ci80[["estimate"]][rows]
lower <- ci80[["conf.low"]][rows]; upper <- ci80[["conf.high"]][rows]
p_display <- 2 * pnorm(-abs(log(estimate) / ((log(upper) - log(lower)) / (2 * 1.96))))
stopifnot(isTRUE(all.equal(ci80[["p_value"]][rows], p_display)))
validation_values <- data.frame(estimate = estimate, actual_conf_level = 0.8,
  display_p = ci80[["p_value"]][rows], original_wald_p = ci80[["p.value_0.95"]][rows])
validation_values

兼容规则使用未舍入区间和固定 1.96回推 p_value，比值在 log 尺度、差值在原尺度计算。非对称区间取朝向无效值一侧的半宽；零宽、不包含估计或缺失的无效区间返回 NA，不产生星号。95% 时保留原模型检验，交互单元的星号也不再先把 P 舍入到五位小数。上例 80% 区间的显示 P 为 0.00005143，原 Wald P 为 0.00810948；两者不可互换。非 95% 时显示 P 不是原模型检验，原值另存 p.value_0.95；不要用改变置信水平后的星号声称显著性增强。

当前多个图表模板的表头固定写 95% CI，即使 conf_level 设为其他值。区间实际水平必须看调用及元数据；需要其他水平时显式改可覆盖的表头或轴标题，并在图注记录，不能仅复制默认标题。get_facet_diff() 的森林星号仍用原 Wald P，不套用上述显示 P 规则。

直接标准化的 Cox / CSC 组间概率差使用 riskRegression::ate() 的联合推断：差值方差包含两个组估计之间的协方差，不能把两组标准误平方直接相加。更新前后的点估计可以相同，但置信区间和 P 值会改变；本页主教程图已按当前实现重绘。

每张效应表的 fit_info 属性记录实际模型、公式、估计目标、完整案例样本量和事件数；匹配/加权路径还记录匹配人数、ESS 或权重摘要，以及发生的后端回退。subgroup_model = "interaction" 的亚组行来自共享交互模型，当前不会逐行登记；不要把缺少记录解释成没有拟合。检查这些信息时应读取结果属性，不能把原始队列人数直接当成每个模型的分析人数。

当前输入检查按 surv 明确选择 Cox、竞争风险或 Logistic；结局编码、目标事件、正时间点、方法名称和 conf_level 必须有效。无目标事件的分析层，以及无非事件的 Logistic 分析层，会明确报错。非标准列名应先整理为合法列名再调用。

HR/OR 为 0 或无限大等不可估计结果显示为 Not estimable，对应数值字段置为 NA；图上缺少点或区间不应解释为“没有效应”。生存表的原始 Wald P 值保存在 p.value_0.95，非 95% 显示区间下的 p_value 仍沿用本页下方解释的兼容合同。

倾向评分模型只在同一次调用内复用；对比不同数据、调整项或分析设计时仍会分别拟合。性能复用不改变 ATE/ATT 的定义，也不能代替平衡与重叠诊断。

亚组模型、交互与外层分层

设置 实际分析方式 适合展示
subgroup_model = "separate" 在各亚组内分别拟合暴露效应；交互指标另由交互模型计算 各亚组分别建模的结果
subgroup_model = "interaction" 对每个亚组变量建立暴露 × 亚组模型，再提取各水平的简单效应和交互指标 同一模型中的亚组效应与层级交互
split_var = "age_55" 先分成两个年龄层，各层独立分析，再合并结果表并保留分层列 年龄块内的 Sex 亚组结果
all 控制二分类亚组路径的总体行；默认 "Age" 要求数据有 Age。此路径可用 NULL 省略总体行 汇总行；不等于“所有协变量”

本页采用 interaction 生成可比较的简单效应、全局交互 P 值和层级交互信息。当前该模式要求单个二分类主要暴露，亚组至少有两个观测水平，且比值方法为 unadj / direct。多水平亚组的 p_inter 是整体 Wald 检验；stra_p_inter 比较某层与亚组参考层的交互。

MS 为乘法交互指标，参考值为 1；RERI 为模型比值尺度计算的加法交互指标，参考值为 0。Cox / Fine–Gray 下，它们来自 HR / sHR 的组合，不能直接称为绝对风险尺度的交互。调整后的全局 Sex 交互 P 值在本页为 0.932，年龄组为 0.182；切换布局不会改变这些数值。

split_var 与 sub_var 有不同含义：前者让模型在各外层数据子集中分别拟合，后者定义某个分析中的效应修饰变量。缺失的分层值不进入该层分析，层内不变的调整变量会被去除。

另有两个针对特定任务的参数：cat_var_combine 将多列组合为联合分类变量，联合类别本身不等于交互检验；direct_replace 为单因素 / 多因素比值路径指定目标变量的调整组合，不同步改变概率表。

多个分期方案分别调整

cat_var_rpa 用于比较多列分期方案：每一列与 adj_var 分别建立 direct 模型。普通 cat_var = c(...) 在多因素路径中把这些列同时放入模型；cat_var_combine 则交叉成联合暴露。三者回答的问题不同。cat_var_rpa 与 cat_var_combine 不能同时指定；若同时提供 cat_var，函数提示并优先采用 cat_var_rpa。

set_eff()：改写结果与调整区间

本节于 2026-10-01 按当前源码补充，并在 WSL R 4.4.3 运行。复用前文 598 人队列与 eff_crude；原有 24 张参数图之外，再增加三张对照图和数值表。

set_eff 会改变结果表的数值，适用于注明来源的外部估计或敏感性展示，不重新拟合模型。默认 inplace=TRUE 会写回传入变量；以下均显式设为 FALSE，保留原对象。多个比值表时必须指定 which；sur_* 概率差表不支持。

输入 实际行为
CND=“1.20 (0.90, 1.60)” 将字符串视为 95% 比值区间，重写点估计、上下限、P 值、星号与 effect 文本
CND=1.20 / estimate=list(CND=1.20) 保留由原 95% 区间推算的 log-SE，移动点估计和区间，重新计算 P 值
CND=“conf_0.90” 点估计不变，改变该行显示置信水平；原模型 p.value_0.95 保留
effect=list(N_4=c(CND=“conf_0.90”)) 按“标题块→行标签”定位；重复标签时比直接按 label 更明确
header / 数字名称 header 限定标签所在块；数字名称为行号，包含标题行，数据变化后需重新核对

P 值边界： 由区间反推使用 log 正态近似，受输入小数精度影响。非 95% 展示时 p_value/星号遵循当前显示区间，不能直接当作原来的模型 P 值；原 95% 值见 p.value_0.95。数字 0.90 是新比值，字符串 conf_0.90 才是置信水平。区间换级记录在 conf_level_rows 属性中；重排行后不应继续沿用该属性。

筛选后的空水平与单水平暴露

2026-10-17 按已推送 RegR 197faa2，在 WSL R 4.4.3 核验：get_eff() 拟合前会移除暴露及亚组因子的空水平，并给出提示。空水平指有定义但没有记录的水平；它与筛选后只有一个实际观测水平不同。

以下给合成数据增加没有记录的因子水平，比较当前函数与显式 droplevels()。同样的输入可复用本节代码独立执行。
