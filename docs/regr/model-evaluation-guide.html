模型评价：C-index、时点 AUC、Brier 与验证人群

发布于

2026年10月5日

模型区分度、概率误差和拟合优度不是同一个指标。下面将模型拟合、评价人群、时间网格和汇总方式明确分开，展示 RegR 两条评价路线，以及一个固定留出集的实际比较。

版本与执行范围： 按 RegR 0.1.3 当前源码核对，使用 WSL R 4.4.3 实际运行下面的示例并保存汇总输出。示例用于理解接口和输出；不构成外部验证或临床效果结论。

数据准备与复现

使用 RegR 自带的 SEER 甲状腺髓样癌队列。保留完整模型变量、正随访时间及肿瘤大小在 0–200 mm 内的记录，再固定种子抽取最多 800 人。stage 合并为 T1/T2 与其余分期，surgery 为无手术与任一手术。它们是本页的演示编码。时间单位沿用原始队列的月。只发布汇总结果。

library(RegR)
library(ggplot2)
library(survival)
data("seer_thyroid_mtc_2026", package = "RegR")
d <- as.data.frame(seer_thyroid_mtc_2026)
d[["DSS"]] <- as.integer(as.character(d[["DSS"]]))
d[["OS"]] <- as.integer(as.character(d[["OS"]]))
needed <- c("time", "DSS", "OS", "Age", "Tum", "Sex", "Race", "T_stage", "Sur")
d <- d[complete.cases(d[needed]) & d[["time"]] > 0 &
       d[["Tum"]] > 0 & d[["Tum"]] < 200, , drop = FALSE]
d[["stage"]] <- factor(ifelse(d[["T_stage"]] %in% c("T1", "T2"), "Early", "Other"))
d[["surgery"]] <- factor(ifelse(d[["Sur"]] == "No surgery", "No", "Yes"),
                          levels = c("No", "Yes"))
set.seed(20261001)
d <- droplevels(d[sample.int(nrow(d), min(800L, nrow(d))), , drop = FALSE])

共用计算与返回对象

所有 R=0 的 RegR 评价都在传入的同一数据上拟合和评价，属于表观性能。R=1 也走无重采样分支。最后的 score_test 则使用只在 train 拟合的 get_fit() 模型，由 riskRegression::Score 在 test 上计算；这一步没有调用会在 test 上重拟合的 get_score(test, …)。

models <- list(c("Age", "Sex"), c("Age", "Tum", "Sex", "stage"))
score_cox <- run_quiet({get_score(d, vars = models,
  timepoint = c(36, 60, 120), R = 0)})
score_log <- run_quiet({get_score(d, vars = models, surv = "DSS", R = 0)})
single_score <- run_quiet({get_score(d, vars = c("Age", "Tum", "Sex", "stage"),
  timepoint = c(36, 60, 120), R = 0, metrics = c("AUC_score", "BS_score", "AIC"))})
msr <- run_quiet({get_msr(d, vars = models, R = 0)})

# 候选变量预先指定；留出集未用于选择变量或调参。
set.seed(20261001)
train_id <- sample.int(nrow(d), floor(0.7 * nrow(d)))
train <- d[train_id, ]
test <- d[-train_id, ]
fit_train <- get_fit(train, co_var = c("Age", "Tum", "Sex", "stage"))
score_test <- riskRegression::Score(
  object = list(Full = fit_train), formula = Surv(time, DSS) ~ 1,
  data = test, metrics = c("AUC", "Brier"), times = c(36, 60, 120),
  plots = "ROC", null.model = FALSE, contrasts = FALSE, split.method = "none")

函数与估计对象对应

接口 主要行为 输出
get_fit 给定变量集合拟合一个模型；time=NULL 是 Logistic Cox / crr / FGR / glm 对象
get_msr mlr3 路线的 C-index/Brier；拟合优度另用 get_fit_stats 汇总数据框
get_score riskRegression 路线的时点 AUC/Brier（AUC_score/BS_score），可加同一拟合的 AUC/BS/AIC/BIC/PVE Score 对象、AUC.BS.AIC、plt.AUC/BS/combined/ROC
get_score_summary 从 Score 跨时间网格汇总 格式化数据框
plt_score Score 的时间曲线或 Logistic ROC patchwork / ggplot

get_score 的 vars 为 list 时每个元素是一个联合模型，为选列向量时每列一个单变量模型；single_score 分别拟合 Age、Tum、Sex、stage 四个单变量模型，不能把它的输出误认成四变量联合模型。get_msr 和 get_score 的 TRUE/FALSE 分别为 Cox/Fine–Gray，字符结局列为 Logistic；get_msr 的 cause 可选择竞争事件编码。

生存时间网格：AUC 与 Brier

时点 AUC 衡量该时点的风险排序；Brier 是概率预测平方误差，并处理删失。plt_score() 生存图上使用 C-index 字样，但底层 AUC 列是 riskRegression 的时点 AUC，不能解释成 Harrell C。timepoint 变化会改变评价问题，也会改变跨时点平均值。

get_score_summary 的平均值边界

当前实现把选定网格上的 AUC/Brier 做等权平均，用跨时点 SD/sqrt(时点数) 构造正态区间。时点并非独立患者，且没有处理它们的相关性；此区间不能当作外部验证或标准的综合 AUC/IBS 置信区间。表中 C.index 名称沿用接口，实际含义需按来源说明。

.addAIC / .addPVE 已移除；把它们保留在旧脚本中会报 unused argument。surv = TRUE 为 Cox，FALSE 为竞争风险，字符列为二分类；cause = 1L 仅作用于竞争风险路径。Cox 返回 surv.cindex 与 surv.graf，分别为 Harrell C 和该后端的 Brier 指标，不等于 riskRegression 的时间 AUC。

set.seed() 控制 Cox/Logistic bootstrap。R≥2 时，结果中的区间为实际重复指标的 2.5%/97.5% 分位数，不能解释成独立外部验证。get_rpa_mp1() 已弃用，建议迁移到 get_score 的 AUC_mlr/BS_mlr 或 AUC_score/BS_score，并用 R = c(0, n) 对照两个面板。

get_score()：指标、单时点列与双面板

本节使用 2026-10-05 源码 3411eb0。vars = c("Age", "Sex") 是两个单变量模型；vars = list(Basic = c("Age", "Sex")) 才是一个联合模型。list 名称会成为模型标签。

指标 含义与评价数据
AUC_score / BS_score riskRegression 的时点 AUC / Brier；R≥2 用 bootcv 袋外预测
AUC / BS 同一拟合在训练样本上的表观指标；不是袋外评价
AUC_mlr / BS_mlr get_msr 的 mlr3 指标；Cox 的 AUC_mlr 实际为 Harrell C-index
AIC / BIC / PVE 拟合优度；PVE 为 Cox–Snell 型似然伪 R²

timepoint 决定时间平均的网格；times 添加具名单时点列。Score 实际计算两者并集，但平均仅使用 timepoint。超出随访而被跳过的时点返回 NA。全队列时间平均区间采用 get_fit_stats 的平均影响函数标准误近似并截断至 [0,1]，未显式估计所有时点间协方差；它不等于按时间积分的 AUC/IBS，也不同于上节 get_score_summary 的跨时点离散度区间。

R≥2 是普通受试者 bootstrap，所有候选模型共用抽样行；区间为百分位区间，SE 为 bootstrap 标准差。它描述训练拟合的变化，不执行 get_score 的 bootcv 袋外评价。示例 20 次仅作接口演示。

get_score_stage()：分期方案评价

get_rpa_mp2() 的新入口是 get_score_stage()，旧名作为弃用别名保留。它比较分期结构，不计算时间 AUC 或 Brier。下面完全使用模拟队列，六个基础组分别合并为三期和四期，两套方案都嵌套于基础分组。

set.seed(20261005)
ds <- data.frame(Age = runif(600, 30, 80),
                 group = factor(rep(1:6, each = 100)))
ds[["DSS"]] <- rbinom(600, 1, 0.75)
ds[["time"]] <- rexp(600,
  rate = 0.02 * exp(0.35 * (as.integer(ds[["group"]]) - 1))) + 1
ds[["Stage_A"]] <- factor(ceiling(as.integer(ds[["group"]]) / 2), levels = 1:3)
ds[["Stage_B"]] <- factor(c(1, 2, 2, 3, 3, 4)[as.integer(ds[["group"]])], levels = 1:4)
set.seed(20261005)
stage_res <- get_score_stage(ds, cat_groups = c("Stage_A", "Stage_B"),
  adj_var = "Age", R = c(0, 20),
  name_map = c(Stage_A = "Three stages", Stage_B = "Four stages"))

  save = list(path = tempdir(), title = "Comparison of staging schemes"))

新实现直接计算标准并向量化解释变异。与旧 remss 参考实现相比，死亡与删失同时间时的顺序约定，以及重采样后缺少阶段时的实际自由度处理，会引起部分数值差异；不能声称全部数值逐位不变。并行依据测得的全队列计算成本自适应选择，并遵守 options(mc.cores = k)。历史计时不代表当前所有数据的性能。

使用边界、保存与复现记录

R>=2 时 get_score 的 AUC_score/BS_score 使用 bootcv，而 get_msr 使用它自身的 bootstrap 路线；两者不是相同的验证协议。重采样次数、失败拟合、删失处理和预处理位置应明确报告。AUC 高不代表校准良好，Brier 受事件率影响，AIC/PVE 不能替代验证性能。评价多模型时应固定评价队列、终点和时点；本页未计算决策曲线，也未得出临床获益结论。

绘图调色、字体和布局只改变展示；模型、编码、样本、预测时间或权重改变后需要重新计算。带 save 的接口按帮助页传入保存配置；其余返回图可用 ggplot2::ggsave() 或 RegR::save_plt()，表格按返回类型使用 save_tb() / save_gt()。重采样示例的预算仅用于演示，应结合实际分析目的增加并报告失败与收敛情况。
