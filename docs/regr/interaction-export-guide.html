本页接交互分析，把交互结果整理成表格、Word 文档和图。代码沿用该页示例数据与分析尺度准备的 inter_data，以及get_inter() 一节拟合的 inter_single、inter_multi、inter_pairs、inter_grid 和 inter_or，请先运行这两节。

fmt_inter()：自动选择表格后端

# 接口签名（不执行）
fmt_inter(
  df_inter, table_map = NULL,
  output_format = c("flextable", "gt"),
  layout = c("auto", "horizontal", "vertical"),
  table_names = NULL, gt_args = list(), ft_args = list()
)

这个入口识别比值 / 绝对尺度以及 single / mul / grid / multicat 等形状。更改 output_format 只选择渲染后端，不重新拟合模型。后端特有选项放在命名 list 中：gt_args 支持 show_combine、spanner_colors，ft_args 支持 show_subeffect、show_measure；未知、重复或未命名字段会被拒绝。

  • flextable
  • gt

默认后端适合 Word 排版。下面与 fmt_inter_ft(inter_single) 使用同一份 Cox 结果。

fmt_inter(inter_single, output_format = "flextable")

网页表格后端；单个结果默认将未调整和调整模型合并在一个 gt_tbl 中。

fmt_inter(inter_single, output_format = "gt")

Rscript 与 knitr 的默认显示（2026-10-29）

RegR ba6e4ce 中，get_inter()、get_inter_abs() 和 get_eff_inter() 只在交互式会话中默认自动显示 gt；Rscript 批处理无需再为避免数百行 HTML 设置 FALSE。options(RegR.inter.print=TRUE) 会在任何会话强制显示，FALSE 会禁止自动显示；选项均不关闭拟合警告或显式格式化。

在 knitr 的结果代码块中直接展示 get_inter、get_inter_abs 或外层分层的 eff_inter_split 对象，会通过对应 knit_print() 渲染 gt。普通未分层的 get_eff_inter() 返回 data.frame，显式调用 fmt_eff_inter_gt() 可统一排版。下面沿用二分类实跑生成的 ratio29，不重复拟合：

# Rscript 中显式保存/展示；在 knitr 中将对象放在结果代码块的末行。
fmt_inter_gt(ratio29)

这个变化只控制呈现方式。print()、fmt_inter()、save_tb_inter() 的具体返回与保存行为继续按各自接口使用；它也不会重算本站保留的历史结果。

循环分析时关闭自动表格（2026-10-27）

按已推送 RegR 212a156，options(RegR.inter.print=FALSE) 可关闭 get_inter()、get_inter_abs() 和 get_eff_inter() 返回前的 gt 自动打印，适合批量筛选暴露组合。它不关闭拟合、消息、警告或显式格式化，也不改变返回结果。用 withr::with_options() 限制在本次调用，结束后自动恢复原选项。

library(RegR)
set.seed(20261027)
print_data27 <- data.frame(Exposure = factor(rep(c("Low", "High"), each = 60),
  levels = c("Low", "High")), Modifier = factor(rep(rep(c("Early", "Late"), each = 30), 2),
  levels = c("Early", "Late")), Age = rnorm(120, 60, 8))
print_data27[["Outcome"]] <- unlist(lapply(c(6, 12, 15, 24),
  function(events) c(rep(1L, events), rep(0L, 30 - events))))
print_option27 <- getOption("RegR.inter.print")
quiet_inter27 <- withr::with_options(list(RegR.inter.print = FALSE),
  get_inter(print_data27, exposure_names = c("Exposure", "Modifier"),
    adj_var = "Age", surv = "Outcome"))
quiet_table27 <- fmt_inter_gt(quiet_inter27)
gt::gtsave(quiet_table27, file.path(tempdir(), "20261027-update-interaction-print-switch.html"))

上例在关闭自动打印后，仍能显式 fmt_inter_gt(quiet_inter27) 查看或保存同一结果。已有对象的 print()、后续 fmt_inter() 和 save_tb_inter() 也仍按各自接口工作；该选项不是全局静默开关。

fmt_inter_ft()：Word 表格的细节控制

# 接口签名（不执行）
fmt_inter_ft(
  df_inter, table_map = NULL,
  layout = c("auto", "horizontal", "vertical"),
  table_names = NULL,
  show_subeffect = c("both", "column", "row", "none"),
  show_measure = c("above_header", "below_header", "none")
)

show_subeffect 控制两个层内效应摘要："column" 保留效应列，"row" 保留主暴露效应行，"both" 两者都保留，"none" 两者都隐藏。隐藏摘要不会改写模型。

show_measure 控制 HR / Risk 等度量行的位置："above_header" 在表头，"below_header" 在表体首行，"none" 不显示。layout 组织多对比 / 分层表；完整多水平结果使用固定的模型并排布局。

  • 默认摘要
  • 精简表格

保留两类层内效应，度量行位于表头。

fmt_inter_ft(inter_single)

隐藏两类层内摘要，将度量行放在表体。联合效应和交互指标仍来自同一份分析。

fmt_inter_ft(
  inter_single, show_subeffect = "none", show_measure = "below_header"
)

fmt_inter_gt()：网页表格与分组表头

# 接口签名（不执行）
fmt_inter_gt(
  df_inter, table_map = NULL,
  layout = c("auto", "horizontal", "vertical"),
  show_combine = TRUE, table_names = NULL,
  spanner_colors = c("#2C3E50", "#5D6D7E", "#7B4B3A", "#4A6155")

show_combine = TRUE 将单个交互结果的 Unadjusted / Adjusted 合成一个 gt_tbl；FALSE 返回 gt_group。table_names 用于多对比标签，spanner_colors 循环应用于 mul 的分组表头。layout = "auto" 对带 table_names 的多修饰变量结果采用纵向，其余通常横向；single / grid 的 gt 渲染不使用这个布局开关。

  • 完整多水平表
  • 逐对表与颜色

直接识别 multicat，并排显示未调整与调整模型，不需要先拆成逐对表。

fmt_inter_gt(inter_multi)

对 mul 结果选择纵向布局，用两种紫色区分对比表头。颜色与布局只改变显示。

fmt_inter_gt(

save_tb_inter()：Word 导出与发表用表

当前接口

# 接口签名（不执行）
save_tb_inter(
  inter_result, title = NULL,
  layout = c("vertical", "horizontal"),
  table_map = NULL, note = NULL, note_covar = NULL,
  landscape = FALSE, note_below = TRUE, show_ap_si = FALSE,
  show_subeffect = c("row", "both", "column", "none"),
  show_measure = c("above_header", "below_header", "none"),
  show_model = c("both", "unadjusted", "adjusted"),
  covar_map = name_map_seer,
  font_name = "Times New Roman", font_size = 8
)

函数接受原始交互结果，也接受已经排好的 flextable。返回值始终是 flextable，因此可以先预览，再保存；title = NULL 不写文件。非空 title 为输出路径，可带或不带 .docx，目录决定保存位置，去掉扩展名后的文件名用于表题。下面的文件示例写入 R 的临时目录；实际使用时换成自己的输出路径。

参数 用途与适用范围
layout 默认 "vertical"，对比 / 层向下堆叠；"horizontal" 横向排列。完整多水平表保留固定布局
landscape Word 页面横向；独立于表格的横 / 纵布局
show_model 两个模型都保留，或只保留 "unadjusted" / "adjusted"
show_ap_si = FALSE 当前默认；比值结果保留乘性交互与主要加性指标 RERI，绝对结果保留乘性交互与 IC；TRUE保留其他加性指标
show_subeffect, show_measure 保存入口默认 show_subeffect = "row"；fmt_inter_ft() 仍默认 "both"，两者选项含义相同
table_map 变量 / 水平文字映射；是正则子串替换，不改变编码、参考组或估计值
covar_map, note_covar 调整项注释的名称映射与手动覆盖；note_covar 覆盖显示文字，不能改变已拟合的调整模型
note 在标准注释之后追加说明
note_below 默认在 Word 表格下写可编辑段落；返回的 flextable 仍以 footer 行预览注释。缺少相关注释元数据的单表会回退到 footer
font_name, font_size 默认 Times New Roman、8 pt；本页预览使用 10 pt

传入已经格式化的 flextable 时，函数保留其布局；layout、table_map、show_subeffect、show_measure 不重新应用。不显式传 show_ap_si 时保留既有行；显式传 FALSE 会警告并忽略，因为它不能再筛选原始指标。需要精简时应直接传原始分析结果。show_model 可用于已有表，但应确认模型标识仍完整。

plt_inter()：组合图、分解与热图

# 接口签名（不执行）
plt_inter(table_result, theme_use = UtilsR::theme_my, base_size = 14)

输入必须是一个二分类×二分类的 8×4 比值交互表，例如 inter_or[["Adjus"]]；不能直接传整个分析列表、完整多水平结果、分层 grid 或 get_inter_abs() 的 9×4 表。

当前图形坐标标题固定为 OR，所以本节使用前面的 Logistic 结果，避免把 Cox HR 图按 OR 标注。图从显示表中的已四舍五入数值构造，适合展示交互形态；精确统计报告仍应读取原始模型与未舍入估计。

plots <- plt_inter(inter_or[["Adjus"]])
  • 组合图
  • 联合效应热图
  • 加性分解
  • 乘性交互折线

左侧为加性分解，右侧为乘性交互折线。两张图描述同一份 Logistic 比值结果的不同组合方式。

plots[["combined"]]

四个暴露组合相对于共同参考组的 OR。颜色展示数值大小，不单独检验交互。

plots[["add"]]

按 Reference、OnlyB、OnlyA、RERI 分解联合比值。这里的 RERI 基于 OR；柱高不能读成死亡概率或人数。

plots[["stack"]]

用线条比较年龄组内的性别联合 OR。图形受坐标尺度影响，是否存在交互应结合模型检验与区间阅读。

plots[["line"]]

stack、line、add 返回 ggplot，combined 为 patchwork，可以继续调整主题或保存。theme_use 接受主题对象、主题函数或函数名字符串，base_size 设置基础字号。这些参数不重新拟合模型。

get_inter() 返回带 surv_models 类的命名 list；save_tb_inter() 识别该结果，分别返回 flextable 并输出 Word。title、note 可用按模型命名的字符向量或 list，其他参数按模型分别设置时使用同名 list。单个已有 flextable 的保存行为不变。

本节显式设置 AP/SI 和行列摘要，复现时不依赖默认显示选项。模型各自使用其所需变量的完整案例；HR 与 sHR 的加法派生指标不等于绝对风险交互。需要后者时继续使用本页 get_inter_abs() 的原始数据工作流，本节不把它作为多模型接口示例。

check_inter() 的核对范围

本例完整表的未调整 SI 为 NaN，调整后的 SI 区间也很宽，反映该编码下指标不可估计或不稳定，不能填成0或解释为没有交互。精简显示不会修复这一统计问题。

当前入口支持一对 surv_models，按名称分别检查 Cox 与 Fine–Gray；本例两模型均通过。audit_models[["cif"]][["comparison"]] 可查看逐单元结果。它比较的是已格式化的分层 HR/sHR 显示文本，只规范首尾及重复空白，不重新拟合。

下载本例逐单元核对结果。

检查项目 当前行为
同名模型 逐一比较，返回 check_inter_pairs
只有一边存在的模型 记录在 attr(audit_models, "unmatched")，不算已通过
一边多模型、一边单结果 报错；两边都先选择同一模型再比较
不显式传两个对象 在调用环境按 inter_* / facet_* 后缀配对；正式核验宜明确传对象
status equal / different / missing_inter / missing_facet / not_estimable，须查看具体单元

该检查不覆盖交互P值、RERI、曲线、概率差或人数，也不证明两条分析路径在未舍入数值上完全相同。若使用不同模型、参考组或逐对拆分策略，先核对 same_model_expected 与设置，不能为了得到 TRUE 而改写显示文本。

get_inter() 现也接受 cif_args，放在 conf_level 后。"CRR" 让 Fine–Gray 比值与交互拟合回到 tidycmprsk::crr()；"CSC" 在这个不绘制 direct CIF 的入口中仍沿用默认 mets 比值拟合。get_inter_abs() 的固定时点 CIF 另有概率路径和区间要求，见后端边界。
