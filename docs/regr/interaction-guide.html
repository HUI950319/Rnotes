示例数据与分析尺度

本页使用 RegR 自带的 seer_thyroid_mtc_2026，即 4,387 人的甲状腺髓样癌（MTC）队列。它与 森林图示例 使用的 M1 乳头状甲状腺癌（PTC）队列不同。

示例比较性别与种族、性别与年龄组的交互。Female、White、<55 显式设为参考水平；年龄组的 >=55 包含恰好 55 岁。按所用变量完整病例及正随访筛选，不对整个数据集插补。

library(RegR)

data("seer_thyroid_mtc_2026", package = "RegR")
cohort <- as.data.frame(seer_thyroid_mtc_2026)
inter_data <- cohort[
  complete.cases(cohort[, c("Sex", "Age", "Race", "DSS", "time")]) &
    cohort$time > 0,
]
inter_data <- droplevels(inter_data)
inter_data$DSS <- as.numeric(inter_data$DSS)
inter_data$Sex <- factor(inter_data$Sex, levels = c("Female", "Male"))
inter_data$Race <- stats::relevel(factor(inter_data$Race), ref = "White")
inter_data$Age_group <- factor(
  ifelse(inter_data$Age < 55, "<55", ">=55"),
  levels = c("<55", ">=55")
)

get_inter(surv = FALSE) Fine–Gray sHR，以及基于 sHR 的交互指标 使用 time 与 event；0 为删失、1 为目标事件、其他事件为竞争事件

get_inter_abs(surv = FALSE, sur_time = 120) 标准化的目标事件 CIF 及其交互 保留竞争事件；CIF 与上一行的 1 - S 不是同一个量

注记读数与解释边界

surv = FALSE 选择竞争风险路径；选择 Logistic 应传入结局列名字符串。

HR、sHR、OR 是三个不同的比值尺度。由它们计算的 RERI / AP / SI 不能直接当作风险差；尤其 HR / sHR 上的加性指标并不等于固定时点的绝对风险交互。OR 也不能普遍当作风险比使用。

本页用于说明观察性队列的模型与接口行为。模型交互依赖参考组、调整项与所选尺度，不自动建立因果识别；“一组显著、另一组不显著”不能替代交互检验。

get_fit_ms()：保留完整编码的整体乘法交互检验

本节按 RegR 0.1.3 源码 40515e1 核对，复用本页完整案例队列，在 WSL R 4.4.3 中实际执行。get_fit_ms() 不把多分类变量拆成多次二分类比较，而是为每个“暴露 × 修饰变量”拟合嵌套模型，检验全部交互项。

get_fit_ms(data, exposure_names, adj_var = NULL, surv = TRUE,
  test = c("LRT", "Wald"))

exposure_names 的第一个变量是暴露，其余变量按顺序逐一作为修饰变量。二分类、多分类、连续 × 分类、连续 × 连续均保留完整编码；数字编码的分类变量应先转为 factor，否则按线性连续项建模。

Cox / Logistic 默认使用 LRT；Fine–Gray 使用联合 Wald 检验，显式要求 LRT 会提示并改用 Wald。输出给出实际使用的 test、statistic、df、p.value、n 与 events。同一变量对的未调整和调整模型使用同一批完整案例，保证差异来自调整设置。

ms_cox <- get_fit_ms(inter_data, exposure_names = c("Sex", "Race", "Age"),
  adj_var = "Age", surv = TRUE)
inter_data[["status"]] <- factor(inter_data[["event"]], levels = 0:2)
ms_fg <- get_fit_ms(inter_data, exposure_names = c("Age", "Race"),
  adj_var = "Sex", surv = FALSE, test = "Wald")

这是模型比值尺度上的整体交互检验，不给出 RERI、AP、SI，也不等于绝对风险差的交互检验。若要展示每个组合的效应和加法指标，继续使用本页的 get_inter() / get_inter_abs()；若要判断保留完整编码后的整体乘法交互，使用 get_fit_ms()。

空组合会导致不可估计项被剔除并减少实际 df；分类组合内无事件或无非事件会使 Wald 统计量和 P 值成为 NA 并给出提示。不能把 NA 当作“不存在交互”。

比值尺度与绝对尺度的加性交互

令两个二分类暴露为 \(A,B\)，00 为共同参考组。比值尺度中，联合效应为 \(\theta_{11}\)，单独效应为 \(\theta_{10},\theta_{01}\)，参考值 \(\theta_{00}=1\)：

\[ \begin{aligned} M &= \frac{\theta_{11}}{\theta_{10}\theta_{01}},\\ \mathrm{RERI} &= \theta_{11}-\theta_{10}-\theta_{01}+1,\\ \mathrm{AP} &= \frac{\mathrm{RERI}}{\theta_{11}},\\ \mathrm{SI} &= \frac{\theta_{11}-1}{\theta_{10}+\theta_{01}-2}. \end{aligned} \]

M 的无交互值为 1，RERI / AP 为 0，SI 为 1。SI 的分母接近 0 时可能不稳定；保护性效应或改变参考组也会影响这些指标的含义，不能仅凭一行星号归纳交互。

绝对尺度则先估计四个标准化量 \(p_{00},p_{10},p_{01},p_{11}\)，再计算：

\[ \mathrm{IC}=p_{11}-p_{10}-p_{01}+p_{00}. \]

风险 / CIF 模式的 IC 是概率差的差，无加性交互值为 0。例如 IC 为 0.05 表示额外 5 个百分点；发生率模式的 IC 带有人时发生率单位。绝对结果中的 RERI 是 IC 相对 \(p_{00}\) 的归一化量，AP 是 IC 相对 \(p_{11}\) 的归一化量，两者均不同于 IC 本身。

get_inter()：比值尺度与模型组织

当前接口

# 接口签名（不执行）
get_inter(
  data, exposure_names, adj_var = NULL,
  surv = TRUE, conf_level = 0.95,
  cif_args = list(model = c("FGR", "CSC", "CRR")),
  split_var = NULL, ref_idx = NULL,
  multicat_model = c("interaction", "separate"),
  eff_inter = FALSE, binary_ref = NULL
)
参数 使用方式与影响
exposure_names 一个列名时与各 adj_var 逐对分析；两个列名对应一对暴露。多于两个时，第一个为二分类主暴露，其余逐一作为修饰变量；此时需 multicat_model = "separate"
adj_var 调整变量列名；结果保留 Unadj 与 Adjus 模型。修改调整项会重算模型
surv TRUE 为 Cox，FALSE 为 Fine–Gray，结局列名字符串为 Logistic
conf_level 置信水平，默认 0.95；影响区间和显著性显示
cif_args Fine–Gray 拟合后端；默认FGR/mets，CRR使用 tidycmprsk::crr()；本入口的CSC仍使用mets比值拟合
split_var 先按一个或多个变量分层，再在层内计算交互；分层变量从调整项移除
ref_idx 按水平名称或位置合并多水平变量的参考组，其余为 Oth；旧名 binary_ref 警告兼容，两者不能同给。会改变研究对比
multicat_model 二分类×多水平时，"interaction" 用一个完整交互模型；"separate" 用 K−1 个参考组对照的子集模型
eff_inter 默认 FALSE 返回交互指标表；TRUE 转发至 get_eff_inter() 的效应表路径，返回合同随之改变

multicat_model = "interaction" 是当前默认值。二分类×二分类保持单个结果；二分类×多水平从一个包含所有联合水平的模型中提取对比，并保存总体 K−1 自由度 Wald 交互检验。"separate" 每次只保留参考水平与一个非参考水平，各模型的样本和估计值可能不同。

二分类编码、精确 Wald P 与警告来源（2026-10-29）

按 RegR 0.1.3 ba6e4ce、UtilsR 0.6.13 ce17def，在 Windows / WSL R 4.4.3 运行下列 320 行合成 Cox 数据。A0、B0 是参考水平，简单效应在另一变量的固定层内比较 A1 对 A0、B1 对 B0。有序因子、列自带的 contrasts 或全局 contr.sum 不再悄悄改变二分类对比，调用结束也会恢复原 contrasts 选项。

ratio_data29[["DSS"]] <- rbinom(320, 1, .8)
ratio29 <- get_inter(ratio_data29, c("A", "B"), adj_var = "Age", surv = TRUE)
gt::gtsave(fmt_inter_gt(ratio29),

get_eff_inter()：把亚组效应与交互放进一张表

本节于 2026-10-01 按当前源码补充，使用前文同一 RegR MTC 完整病例队列，实际运行以下 Cox 示例。get_eff_inter 将 get_eff 的亚组效应与 get_inter 的乘法交互、RERI 整理到同一张表；它不是 get_inter_abs 的绝对风险输出。

cat_var 必须是单个二分类暴露，sub_var 指定一个或多个分类修饰变量。默认 subgroup_model=“separate” 的亚组效应分别拟合；本节显式设为 “interaction”，从同一完整交互模型提取简单效应和交互指标。Age_group 的每行 HR 均表示该年龄层内 Male 对 Female 的效应，不能读成该年龄层本身的 HR。

返回 data.frame，attr(...,"eff") 保存原始效应表；只有 subgroup_model="interaction" 额外保留 attr(...,"inter")。split_var 非空时返回 eff_inter_split 命名 list，每层独立分析。交互式会话默认自动显示 gt；Rscript 默认不打印，knitr 中展示对象会渲染为 gt。options(RegR.inter.print=FALSE/TRUE) 可禁止或强制打印；再次调用 fmt_eff_inter_gt() 不拟合模型。

当前比值模式支持 Cox、Fine–Gray、Logistic；Fine–Gray 表格底层字段仍以 HR 命名，但格式化显示 sHR。这里实际执行 Cox，RERI 基于 HR 组合，不能直接称为绝对风险交互。RegR ba6e4ce 已移除原本无效的 inter_adjust，继续传入会报 unused argument，应从调用中删除。调整项由 adj_var 指定；选择 interaction 时交互与简单效应来自所选完整模型。

默认 all=“Age” 需要 Age 列；event_by_group=TRUE 将事件数按 cat_var 两组分列，FALSE 则显示合并的事件/总人数。

library(RegR)
library(MLR)
set.seed(721)
di <- data.frame(Tx = factor(rep(c("No", "Yes"), 90)), Marker = rnorm(180),
  Sex = factor(rep(c("F", "F", "M", "M"), 45)),
  Site = factor(rep(c("A", "B"), each = 90)))
di[["Outcome"]] <- factor(ifelse(runif(180) < plogis(
  di[["Marker"]] + (di[["Tx"]] == "Yes")), "Yes", "No"), levels = c("No", "Yes"))
di[["Marker"]][c(3, 111)] <- NA_real_
original_weights <- seq_len(nrow(di))
hst_settings <- list(num.trees = 30, Num.sample = 60, importance = "impurity",
  class = "Yes", case.weights = original_weights, num.threads = 1,
  hstats_args = list(approx = TRUE, grid_size = 8, n_max = 35))
rows_now <- get_int(di, "Tx", vars = c("Marker", "Sex"), split_var = "Site",
  surv = "Outcome", seed = 721, detail = character(),
  ms_args = NULL, inter_args = NULL, shp_args = NULL, hte_args = NULL, tree_args = NULL,
  hst_args = hst_settings)
check_rows <- lapply(c("A", "B"), function(site) {
  keep <- which(di[["Site"]] == site & complete.cases(di[c("Tx", "Marker", "Sex", "Outcome")]))
  manual <- MLR::get_hstats(di[keep, ], c("Tx", "Marker", "Sex"),
    surv = "Outcome", class = "Yes", int_var = "Tx", seed = 721,
    num.trees = 30, Num.sample = 60, importance = "impurity", num.threads = 1,
    case.weights = original_weights[keep], verbose = FALSE,
    hstats_args = list(approx = TRUE, grid_size = 8, n_max = 35))
  got <- rows_now[["strata"]][[site]][["results"]][["hst"]]
  stopifnot(!is.null(got),
    isTRUE(all.equal(attr(got, "interaction_raw"), attr(manual, "interaction_raw"), tolerance = 1e-10)))
  data.frame(site = site, original_complete_rows = length(keep),
             forest_training_rows = attr(got, "settings")[["n_train"]])
})
do.call(rbind, check_rows)
