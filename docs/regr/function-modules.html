get_all()：保留成功层并报告失败层

当前 get_all() 在递归分层分析中隔离层内失败。下面复用森林图补充例子的 800 人 d_scheme，把一层的 Age 人为设为常量，演示 RCS 无法取得足够节点时的行为。

d_all <- d_scheme
d_all[["demo_stratum"]] <- factor(rep(c("Good", "Constant"), each = 400L))
d_all[["Age"]][d_all[["demo_stratum"]] == "Constant"] <- 50
all_res <- get_all(
  com.args = list(data = d_all, adj_var = "Sex", split_var = "demo_stratum", time = 60),
  rcs.args = list(rcs_var = "Age", n = 3L, panel_show = "haz_poi"))
names(all_res)                    # "rcs"
all_res[["rcs"]]                 # 保留 Good 层图形

本次实际运行的摘要保留 Completed 1 analyses: rcs，并明确输出 Failed strata: 1: rcs.args [Constant]；同时发出层内失败警告。Constant 层缺失不是“效应为零”，应随报告说明失败原因。

未传入的分析块默认跳过，不能因为 formals() 显示完整 list 模板就认为它们自动执行。各块未全部成功时，也不能把返回对象解释为全队列完整结果。

get_all()：评分入口、返回值与 Quarto 输出

2026-10-09 按 RegR 0.1.3 源码 40515e1 核对，下面的评分块在 WSL R 4.4.3 中实际执行。

msr.args 现在调用 get_score()；当前返回值是 res[["msr"]][["AUC.BS.AIC"]] 和 res[["msr"]][["ft"]]，不能继续按旧 get_msr() 结构取值。默认指标使用 Score 路径，其他指标可通过 metrics 显式选择；不支持的参数如 cause 会在拟合前报错。

library(RegR)
library(ToyData)
d_score <- as.data.frame(ToyData::toy_ptc_m1_cnd)
all_score <- get_all(
  com.args = list(data = d_score, surv = TRUE, time = 60),
  msr.args = list(vars = c("Age", "Sex"), R = 0,
    metrics = c("AUC_score", "BS_score", "AIC")))
names(all_score)
all_score[["msr"]][["AUC.BS.AIC"]]
model AUC_score AUC_score_60 BS_score BS_score_60 AIC
Age 0.744 (0.701, 0.788) 0.659 (0.600, 0.719) 0.156 (0.144, 0.169) 0.158 (0.137, 0.179) 1938.19
Sex 0.549 (0.500, 0.598) 0.538 (0.481, 0.594) 0.189 (0.180, 0.199) 0.165 (0.144, 0.187) 1984.39

上例未显式设置 msr.args$times，因此公共 time = 60 在随访范围内时会加入一个命名评分时间列；显式 times = NULL 则不追加。公共块和各分析块的未知参数、矛盾分层设置会先检查。分层内恒定调整变量的处理可读 attr(res, "adj_var_dropped")，应随分析报告说明实际调整集合。

get_all() 在各分析完成时打印主要结果一次，赋值不阻止这一输出，返回对象本身为 invisible。Quarto 中表格不要在函数内部反复打印；将返回表放进单独代码块，例如：

# Quarto 文档中的独立表格代码块
all_score[["msr"]][["ft"]]
# 开启其他模块时，分别使用 res$cat_gt 或 fmt_inter_gt(res$interTable)。

交互会话里耗时超过 0.5 秒的图会显示 150 dpi 整图预览；返回对象仍是原始图，可用于矢量保存。该显示路径与 knitr 的输出处理分开，详情见 三种栅格化后端。

fmt_page：图表与文字结果页

2026-10-16按RegR a8a6eb8固定快照在Windows R 4.4.3实际运行；fmt_page已包含于核对时远端1dc3b2f。复用本页介绍该函数，图谱下载件仍保留其历史快照。

fmt_page()按输入顺序组合图、表和文字；命名项成为小标题，NULL项略过。支持ggplot/patchwork/grob、gt、gtsummary、flextable、data.frame/tibble、htmltools标签及htmlwidget。普通list应拆开传，例如 do.call(fmt_page,res[c("combined","gt")])，不能把整个分析结果list当一块图传入。

fmt_page(..., title=NULL, plot_size=c(7,5),
  dpi=150, save=list())

图、表、文字组合成结果页

复用现有目录页介绍RegR::fmt_page。图会嵌入PNG，表格保留HTML；名称变成小标题，NULL项略过。保存为一个HTML文件，网页依赖仍可能需要联网，不能把PNG图当作矢量图。

p_page <- ggplot(mtcars,aes(wt,mpg))+geom_point(colour="#137C8B",size=2)+theme_bw()
page_html <- fmt_page(Plot=p_page,Table=gt::gt(head(mtcars[,c("wt","mpg","cyl")],6)),
  "A reproducible plot and its first six data rows.",NULL,
  title="Weight and mileage",plot_size=c(6,3.5),
  save=list(filename=file.path(tempdir(),"results-page")))
saveRDS(page_html,file.path(tempdir(),"results-page.rds"))
# 在交互会话显示；在Quarto独立代码块中直接写page_html。

数据框、tibble 与已有页面复用

2026-10-17 按已推送 RegR 197faa2，在 Windows / WSL R 4.4.3 实际运行下例。数据框与 tibble 自动转为 gt 表；字符行名成为行标题，普通行号不单独显示；list 列的每个元素用逗号连接。图的 labs(alt=...) 成为图片替代文本。

library(RegR)
