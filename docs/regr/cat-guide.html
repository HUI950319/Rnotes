先用 get_cat() 计算曲线和效应表，再用 plt_cat1()、plt_cat2() 或 plt_cat3() 选择布局。本页参照 MLR 的 SHAP 页面：每个参数选项配可复制代码与实绘图片，在标签页中切换比较，点击图片可放大。

示例准备与读图规则

使用 RegR 自带的 seer_thyroid_mtc_2026：4,387 人甲状腺髓样癌（MTC）队列，Female 2,537 人、Male 1,850 人。甲状腺癌死亡 597 人、其他原因死亡 583 人，存活 / 删失 3,207 人。它与本站 森林图教程 使用的 598 人 M1 PTC 队列是不同的示例数据，不能跨页直接比较结果。

本页以 Sex 为分类变量，明确 Female 为第一水平；调整变量为 Age 与 Race。随访单位是月，单时点概率取 120 月，多时点差值取 60、120、180 月，主图显示 0–180 月，统一采用 95% CI。只检查本页需要的分析列，不对所有原始列做完整案例筛选或插补。

library(RegR)
library(ggplot2)

data("seer_thyroid_mtc_2026", package = "RegR")
d <- as.data.frame(seer_thyroid_mtc_2026)
used <- c("Sex", "Age", "Race", "DSS", "time", "event")
d <- droplevels(d[complete.cases(d[, used]) & d[["time"]] > 0, ])
d[["Sex"]] <- factor(d[["Sex"]], levels = c("Female", "Male"))
d[["status"]] <- factor(d[["event"]], levels = 0:2)

# 分析一次，后面的布局示例复用同一对象。
cat_fit <- get_cat(
  d, cat_var = "Sex", adj_var = c("Age", "Race"),
  surv = TRUE, conf_level = 0.95,
  timepoint = 120, time_dif = c(60, 120, 180),
  methods = c("unadj", "direct")
)
图上的量 本页的含义与方向 参考值 / 范围
HR Cox 危险比，Male 相对 Female；不是死亡概率比 1
sHR 竞争风险 Fine–Gray 亚分布危险比；不是原因特异 HR 1
\(S(t)\) DSS 的生存概率；其他原因死亡按该终点删失 0–1
\(\Delta S(t)\) Female − Male 的生存概率差 0；概率单位
\(CIF_1(t)\) 存在其他死因竞争时，甲状腺癌死亡的累计发生概率 0–1
\(\Delta CIF_1(t)\) Female − Male 的甲状腺癌死亡 CIF 差 0；概率单位
Event/total 目标事件 / 分析组总人数 不是随时间变化的在险人数
Number at risk 指定随访时刻仍在风险集中的人数 位于 plt_cat3() 的曲线下方

例如概率差 0.10 是 10 个百分点，不是 HR = 0.10；CIF 差为负表示第一组的累计发生概率较低。改变表头或曲线颜色不会改变差值方向，若要反向比较，应先改变因子水平，再重新调用 get_cat()。

注记

DSS 生存概率与竞争风险 CIF 是不同的统计量：存在其他死因时，不能把 \(1-S_{\mathrm{DSS}}(t)\) 当作甲状腺癌死亡 CIF，概率定义可参阅 survival 官方竞争风险教程。这里展示的是观察性队列中的模型与绘图行为，调整曲线不自动等于因果效果；曲线置信带是逐时点区间，见 adjustedCurves 方法说明。

get_cat()：分析设置与返回对象

当前接口

get_cat(
  data, cat_var = NULL, adj_var = NULL,
  surv = TRUE, conf_level = 0.95,
  cif_args = list(model = c("FGR", "CSC", "CRR")),
  timepoint = 120, time_dif = c(60, 120, 180),
  methods = c("unadj", "direct"),
  methods_obj = methods,
  methods_haz = methods,
  methods_sur = methods,
  cat_var_combine = NULL
)
参数 作用与边界
cat_var 一个分类变量；本页用列名字符串，并明确因子水平
adj_var 调整项；本页为 Age 与 Race
surv = TRUE 需要 time 和 0/1 的 DSS，生存模式
surv = FALSE 竞争风险模式，需要 time、event 和 status；本页 0 = 删失、1 = 甲状腺癌死亡、2 = 其他原因死亡
timepoint UM 表中单时点概率 / 差值的时间；不是图的显示终点
time_dif Mul 表中多个时点的差值；只对二分类变量产生该表
methods 一次设置曲线、比值表、概率表所用的方法；默认 c("unadj", "direct")
methods_obj 单独设置 obj 中的曲线方法
methods_haz 设置 HR / sHR 表，也控制 Mul 的多时点差值方法
methods_sur 设置单时点概率 / 差值表的方法
cat_var_combine 两列以上合并为 .cat_combined 分类变量，覆盖 cat_var；组合成分自动移出调整项
conf_level 默认 0.95；改变区间需要重新分析

methods_obj、methods_haz、methods_sur 虽可分别配置，本页三个绘图函数按两个曲线对象及对应的未调整 / 调整表组织面板。复现这些组合图时，保留默认的 c("unadj", "direct") 最直接；单个方法生成的分析对象不能当作同样的两列绘图输入。

方法与 CIF 后端

方法 主要行为 本页执行范围
"unadj" 生存模式用 KM；CIF 模式用 Aalen–Johansen；回归比值未调整 实际展示
"direct" 用结局模型标准化得到组别曲线，回归比值另行估计 实际展示
"iptw" 倾向评分加权；当前二分类和多分类默认均按 ATE 应先检查重叠、权重与加权平衡
"psm" 二分类 1:1 近邻匹配，分析匹配后的子队列 未执行；不支持多分类暴露

cif_args$model 只影响 CIF + direct 的标准化概率路径。默认 FGR 使用 Fine–Gray 模型和 mets 解析推断，失败时才回退；本页显式选择 CSC，用各原因 Cox 模型与解析方差绘制 CIF。即使选择 CSC，HR 类表格仍是 Fine–Gray sHR；不能把它改读为原因特异 HR。更详细的模型与性能比较见 FGR / CSC 基准页。

cat_res 的四个部分

class(cat_fit)                 # "cat_res"
names(cat_fit[["cat"]])       # "obj" "UM" "Mul" "par"
names(cat_fit[["cat"]][["obj"]])
names(cat_fit[["cat"]][["UM"]])
cat_fit                       # 打印效应范围和可复制的坐标参数
路径 内容 用法
cat_fit$cat$obj 每个方法的生存 / CIF 曲线对象 三个绘图函数的曲线输入
cat_fit$cat$UM haz_unadj、haz_direct、sur_unadj、sur_direct 效应表 HR / sHR、单时点概率与差值
cat_fit$cat$Mul 未调整 / 调整的多时点差值表 plt_cat2() 的下排森林表；多分类时为 NULL
cat_fit$cat$par 原始分析数据、变量、方法、时间点与水平等 核对分析设置；保存完整对象会保留原数据

Mul 不是“多变量调整表”的简称。get_cat() 不负责把所有布局画好；改变图形参数可复用 cat_fit，改变结局、方法、调整变量或时间点则需要重新分析。

推断与结果更新（2026-10-09）

本节按 RegR 0.1.3 源码 40515e1 核对；下方 Cox 和 CSC 主示例的曲线、单时点表、多时点差值图已重新拟合与导出。

direct 的 Cox / CSC 概率差采用 riskRegression::ate() 的联合推断，差值区间包含组间估计的协方差。不能用两个单独组别区间或独立标准误拼成差值区间；点估计不变也可能伴随区间和 P 值更新。plt_cat2() 应读取同一次拟合产生的多时点结果，不能另用历史表替换。

竞争风险 cif_args = list(model = "FGR") 的默认标准化由 mets 的解析推断完成；只有失败时才回退。"CSC" 切换标准化概率模型，但 sHR 列仍来自 Fine–Gray 模型。当前与历史版本的区别见 CIF 后端比较。

同一次调用中的倾向评分拟合和直接 Cox 曲线区间可以复用，避免重复计算；这些优化不改变权重的 ATE 目标、匹配的 ATT 目标或差值方向。跨调用、跨队列或不同协变量设置仍需重新分析。

KM 差值区间与横向纯曲线（2026-10-12）

本机开发提交 d54e60f 修正了未调整和 PSM 生存路径的标准误：差值推断需要生存概率 S(t) 的 Greenwood 标准误，旧结果曾读取到 -log S(t) 的标准误，导致差值区间偏宽。组别生存概率、其区间和 HR 点估计不因此改变；未调整 / 匹配的生存概率差区间和 P 值可能改变。该修复不针对 direct、IPTW 或 CIF。

本页 KM 图片已从原始数据重算。历史 cat_res 必须重新调用 get_cat()，换绘图参数无法修正对象中的历史标准误。下面显示新增的纯曲线横向布局；sur 保持纵向，sur_h 并列未调整与调整曲线。多个暴露的 sur_h 组合现在形成每暴露一行的共享网格；逐面板堆叠可用strip2_arg=list(strip=FALSE)，见文末新示例。

参考行、区间标题与联合组核对（2026-10-20）

2026-10-20 按已推送 RegR a2f2553 核对。get_cat() 及三个 plt_cat*() 的生存/CIF 差值参考行统一显示 Reference，与比值列一致；这只是显示规范化，不改变参考组与差值方向。

get_cat()：多个独立暴露与曲线计算

2026-10-05 源码 3411eb0 支持一次传入多个 cat_var：每个暴露独立调用 get_cat，返回具名 cat_res list，不把它们组合成一个暴露。cat_var_combine 则建立联合分类，含义不同。下面重新抽取 800 人作为独立补充例子，与本页前面的全队列图分开阅读。

d_multi <- as.data.frame(seer_thyroid_mtc_2026)
used <- c("Sex", "Age", "Race", "DSS", "time", "event", "T_stage")
d_multi <- droplevels(d_multi[complete.cases(d_multi[used]) &
                               d_multi[["time"]] > 0, ])
d_multi[["Sex"]] <- factor(d_multi[["Sex"]], levels = c("Female", "Male"))
d_multi[["stage"]] <- factor(ifelse(d_multi[["T_stage"]] %in% c("T1", "T2"),
                                   "Early", "Other"))
set.seed(20261005)
d_multi <- droplevels(d_multi[sample.int(nrow(d_multi), 800L), ])
cat_multi <- run_quiet(get_cat(d_multi,
  cat_var = c(Sex = "Sex", Stage = "stage"), adj_var = c("Age", "Race"),
  timepoint = 120, time_dif = NULL,
  curve_args = list(ci = TRUE, max_times = 25L, contrasts = "reference")))
names(cat_multi)                    # "Sex" "Stage"
class(cat_multi[["Sex"]])           # "cat_res"
cat_multi[["Sex"]][["cat"]][["UM"]]

本次核对确认多暴露调用中的 Sex 效应表与相同参数的单独 Sex 调用一致。名称来自字符向量的 names；不命名时用列名。

curve_args 的公共默认值为 list(ci = TRUE, max_times = 50L, contrasts = c("reference", "all"))，实际默认选择 reference。ci = FALSE 仅省去 direct 曲线区间；max_times = NULL 保留完整网格，不小于 10 的整数控制调整曲线抽点；contrasts = "all" 请求全部曲线对比。它们不改变未调整 KM 或单时点效应表。未知、重复或空字段名会报错。

单时点 timepoint 与多时点 time_dif 会按组别随访上限处理，不能将自动截短的概率结果仍报告为原请求时点。IPTW 二分类默认已统一为 ATE；CIF 的 IPTW 曲线采用加权 Aalen–Johansen，不是加权 Fine–Gray 曲线。回归 sHR 与加权 CIF 是不同的估计量。conf_level != 0.95 时，应按帮助页区分从显示区间回推的 p_value 与保留的 p.value_0.95。

设置 作用与边界
sur_arg$ylim = "auto" 取打印结果推荐的曲线范围和刻度，依据概率点估计；置信带可能超出显示范围
sur_arg$xlim = "auto" 内嵌森林图的效应坐标；HR/sHR纳入参考值1、差值纳入0，各自取范围
ybre / ticks_at / ticks_digits 显式设置时保留；分别控制曲线刻度、森林刻度和小数位数
plt_cat1(fmt.fst.h = "auto") 在曲线和置信带留出的上、下空间中选择森林图位置；仍需检查宽表与长标签
forest.position 显式提供时优先；此时不触发自动位置选择

这些设置只重绘缓存，不改变 timepoint、调整项或估计量。sur_arg$xlim 不表示随访时间窗，时间窗用 max_t。plt_cat1() 与 plt_cat3() 都支持上述自动坐标；不能把它照搬到 plt_cat2() 的其他参数结构。当前 plt_cat3() 的在险人数偏移路径对 fmt.fst.h = "auto" 会报数值运算错误，所以本例明确使用数值 0.2。图中DSS与CIF不是互补概率，在险人数表只用于生存模式。

在险人数示例使用 display = "s+f" 将宽森林表放在右侧，并缩小人数文字。调整曲线下方的人数仍是原队列的观测在险人数，不是标准化后假想人群的人数；底层会提示这一解释边界，本页保留该提示。

当前 get_cat() 内部明确请求概率表，不受 get_eff(show_sur = FALSE) 新默认值影响。默认 CIF direct 为 mets/FGR 解析路线；新 cif_args = list(model = "CRR") 会选择 crr 比值拟合和 FGR bootstrap 概率路线，详细边界见当前 CIF 后端。
