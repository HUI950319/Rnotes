KM/CIF 组合图：get_cat 与 3 个绘图函数

发布于

2026年10月1日

先用 get_cat() 计算曲线和效应表，再用 plt_cat1()、plt_cat2() 或 plt_cat3() 选择布局。本页参照 MLR 的 SHAP 页面：每个参数选项配可复制代码与实绘图片，在标签页中切换比较，点击图片可放大。

版本与执行范围： 接口按 RegR 0.1.3（本机源码 0add2bb）核对，使用 WSL R 4.4.3 实际拟合并绘制 20 张图。执行了未调整分析、direct 标准化、多分类暴露，以及 CIF 的 CSC 标准化；IPTW、PSM 和 FGR 标准化只说明接口。本页显示保存的汇总图形，不提供患者级数据下载。

示例准备与读图规则

使用 RegR 自带的 seer_thyroid_mtc_2026：4,387 人甲状腺髓样癌（MTC）队列，Female 2,537 人、Male 1,850 人。甲状腺癌死亡 597 人、其他原因死亡 583 人，存活 / 删失 3,207 人。它与本站 森林图教程 使用的 598 人 M1 PTC 队列是不同的示例数据，不能跨页直接比较结果。

本页以 Sex 为分类变量，明确 Female 为第一水平；调整变量为 Age 与 Race。随访单位是月，单时点概率取 120 月，多时点差值取 60、120、180 月，主图显示 0–180 月，统一采用 95% CI。只检查本页需要的分析列，不对所有原始列做完整案例筛选或插补。

library(RegR)
library(ggplot2)

data("seer_thyroid_mtc_2026", package = "RegR")
d <- as.data.frame(seer_thyroid_mtc_2026)
used <- c("Sex", "Age", "Race", "DSS", "time", "event")
d <- droplevels(d[complete.cases(d[, used]) & d[["time"]] > 0, ])
d[["Sex"]] <- factor(d[["Sex"]], levels = c("Female", "Male"))
d[["status"]] <- factor(d[["event"]], levels = 0:2)

# 分析一次，后面的布局示例复用同一对象。
cat_fit <- get_cat(
  d, cat_var = "Sex", adj_var = c("Age", "Race"),
  surv = TRUE, conf_level = 0.95,
  timepoint = 120, time_dif = c(60, 120, 180),
  methods = c("unadj", "direct")
)
图上的量 本页的含义与方向 参考值 / 范围
HR Cox 危险比，Male 相对 Female；不是死亡概率比 1
sHR 竞争风险 Fine–Gray 亚分布危险比；不是原因特异 HR 1
\(S(t)\) DSS 的生存概率；其他原因死亡按该终点删失 0–1
\(\Delta S(t)\) Female − Male 的生存概率差 0；概率单位
\(CIF_1(t)\) 存在其他死因竞争时，甲状腺癌死亡的累计发生概率 0–1
\(\Delta CIF_1(t)\) Female − Male 的甲状腺癌死亡 CIF 差 0；概率单位
Event/total 目标事件 / 分析组总人数 不是随时间变化的在险人数
Number at risk 指定随访时刻仍在风险集中的人数 位于 plt_cat3() 的曲线下方

例如概率差 0.10 是 10 个百分点，不是 HR = 0.10；CIF 差为负表示第一组的累计发生概率较低。改变表头或曲线颜色不会改变差值方向，若要反向比较，应先改变因子水平，再重新调用 get_cat()。

注记

DSS 生存概率与竞争风险 CIF 是不同的统计量：存在其他死因时，不能把 \(1-S_{\mathrm{DSS}}(t)\) 当作甲状腺癌死亡 CIF，概率定义可参阅 survival 官方竞争风险教程。这里展示的是观察性队列中的模型与绘图行为，调整曲线不自动等于因果效果；曲线置信带是逐时点区间，见 adjustedCurves 方法说明。

get_cat()：分析设置与返回对象

当前接口

get_cat(
  data, cat_var = NULL, adj_var = NULL,
  surv = TRUE, conf_level = 0.95,
  cif_args = list(model = c("FGR", "CSC")),
  timepoint = 120, time_dif = c(60, 120, 180),
  methods = c("unadj", "direct"),
  methods_obj = methods,
  methods_haz = methods,
  methods_sur = methods,
  cat_var_combine = NULL
)
参数 作用与边界
cat_var 一个分类变量；本页用列名字符串，并明确因子水平
adj_var 调整项；本页为 Age 与 Race
surv = TRUE 需要 time 和 0/1 的 DSS，生存模式
surv = FALSE 竞争风险模式，需要 time、event 和 status；本页 0 = 删失、1 = 甲状腺癌死亡、2 = 其他原因死亡
timepoint UM 表中单时点概率 / 差值的时间；不是图的显示终点
time_dif Mul 表中多个时点的差值；只对二分类变量产生该表
methods 一次设置曲线、比值表、概率表所用的方法；默认 c("unadj", "direct")
methods_obj 单独设置 obj 中的曲线方法
methods_haz 设置 HR / sHR 表，也控制 Mul 的多时点差值方法
methods_sur 设置单时点概率 / 差值表的方法
cat_var_combine 两列以上合并为 .cat_combined 分类变量，覆盖 cat_var；组合成分自动移出调整项
conf_level 默认 0.95；改变区间需要重新分析

methods_obj、methods_haz、methods_sur 虽可分别配置，本页三个绘图函数按两个曲线对象及对应的未调整 / 调整表组织面板。复现这些组合图时，保留默认的 c("unadj", "direct") 最直接；单个方法生成的分析对象不能当作同样的两列绘图输入。

方法与 CIF 后端

方法 主要行为 本页执行范围
"unadj" 生存模式用 KM；CIF 模式用 Aalen–Johansen；回归比值未调整 实际展示
"direct" 用结局模型标准化得到组别曲线，回归比值另行估计 实际展示
"iptw" 倾向评分加权；当前二分类路径按 ATT，多分类路径按 ATE 未执行，应先检查重叠与加权平衡
"psm" 二分类 1:1 近邻匹配，分析匹配后的子队列 未执行；不支持多分类暴露

cif_args$model 只影响 CIF + direct 的标准化概率路径。默认 FGR 使用 Fine–Gray 模型和 bootstrap；本页显式选择 CSC，用各原因 Cox 模型与解析方差绘制 CIF。即使选择 CSC，HR 类表格仍是 Fine–Gray sHR；不能把它改读为原因特异 HR。更详细的模型与性能比较见 FGR / CSC 基准页。

cat_res 的四个部分

class(cat_fit)                 # "cat_res"
names(cat_fit[["cat"]])       # "obj" "UM" "Mul" "par"
names(cat_fit[["cat"]][["obj"]])
names(cat_fit[["cat"]][["UM"]])
cat_fit                       # 打印效应范围和可复制的坐标参数
路径 内容 用法
cat_fit$cat$obj 每个方法的生存 / CIF 曲线对象 三个绘图函数的曲线输入
cat_fit$cat$UM haz_unadj、haz_direct、sur_unadj、sur_direct 效应表 HR / sHR、单时点概率与差值
cat_fit$cat$Mul 未调整 / 调整的多时点差值表 plt_cat2() 的下排森林表；多分类时为 NULL
cat_fit$cat$par 原始分析数据、变量、方法、时间点与水平等 核对分析设置；保存完整对象会保留原数据

Mul 不是“多变量调整表”的简称。get_cat() 不负责把所有布局画好；改变图形参数可复用 cat_fit，改变结局、方法、调整变量或时间点则需要重新分析。

绘图入口速查

函数 图形内容 适用条件 / 默认布局
plt_cat1() 曲线与单时点效应表 二分类或多分类；默认 display = "v"
plt_cat2() 2×2：上排曲线 + HR，下排差值曲线 + 多时点差值表 仅二分类，需要 Mul
plt_cat3() 曲线、单时点表与在险人数表 默认 display = "h"；CIF 不提供在险人数表

当前 NAMESPACE 中导出的是上述三个 plt_cat*() 函数，没有名为 plt_cat() 的公共入口。

plt_cat1()：曲线与内嵌森林表

display 决定表与曲线的位置，show.noDif 决定内嵌概率列显示差值还是各组概率。所有标签页使用同一个 cat_fit，没有重新拟合模型。

  • 纵向组合
  • 横向组合
  • 曲线与表分开
  • 仅曲线
  • 显示各组概率
  • 坐标、颜色与条带
  • 内嵌表去掉森林线
  • 多分类暴露

默认纵向布局：未调整在上、调整后在下，内嵌表包含 HR 与 120 月生存概率差。

plt_cat1(cat_fit, display = "v", max_t = 180,
         xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)))

h 并列比较两种分析。图片较宽，点击放大阅读内嵌表。

plt_cat1(cat_fit, display = "h", max_t = 180,
         xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)))

s+f 将曲线放左侧、森林表放右侧，适合减少曲线内部的文字遮挡。本页分栏与横向人数表预览采用较宽画布；在较小的 RStudio 绘图窗口中查看时，应放大窗口或导出后检查表格是否裁切。

plt_cat1(cat_fit, display = "s+f", max_t = 180,
         xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)))

sur 不绘制森林表。适合先比较曲线形状和置信带。

plt_cat1(cat_fit, display = "sur", max_t = 180,
         xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)))

show.noDif = TRUE 改为展示各组的 120 月生存概率及区间；HR 列不变。

plt_cat1(cat_fit, display = "v", show.noDif = TRUE,
         max_t = 180, xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)))

缩短显示时间、设置两种颜色并自定义条带。sur_arg$ylim 控制曲线纵轴，sur_arg$xlim 控制内嵌森林图的横轴，两个 xlim 不能混读。

plt_cat1(cat_fit, display = "v", max_t = 120,
         xbreaks = seq(0, 120, 24),
         curve_color = c("#0072B2", "#D55E00"),
         sur_arg = list(ylim = c(0.6, 1), ybre = seq(0.6, 1, 0.1)),
         strip_arg = list(strip_label = c("KM: Female / Male",
                                          "Direct: adjusted for Age + Race"),
                          strip_fill = c("#E8F1F8", "#FFF0E6")))

del_forrest = TRUE 保留数值表而隐藏森林线；这是参数的实际拼写。

plt_cat1(cat_fit, display = "v", del_forrest = TRUE,
         max_t = 180, xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)))

Race 有三个观测水平，可生成多组曲线。此时 Mul 为 NULL，不能使用二分类专用的 plt_cat2()；这里选择仅曲线布局。

cat_multi <- get_cat(d, cat_var = "Race", adj_var = c("Age", "Sex"),
                     timepoint = 120)
plt_cat1(cat_multi, display = "sur", max_t = 180,
         xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)))

plt_cat2()：生存曲线与多时点差值

固定 2×2 布局：左列未调整、右列调整；上排曲线与 HR 表，下排概率差曲线与多时点差值表。上排不是 plt_cat1() 完整的单时点表；下排的 5、10、15 年对应分析时给出的 60、120、180 月。

sur_arg 和 dif_arg 都使用 ylim / ybre / xlim / ticks_at / ticks_digits，但前者作用于上排，后者作用于下排。不要再使用旧的 .2 后缀参数。

  • 默认条带
  • 共用行列条带
  • 差值坐标与标题
  • 配色与隐藏条带

四个面板各自带方法标题；下排的差值方向是 Female − Male。

plt_cat2(cat_fit, max_t = 180, xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)))

非空 strip2_arg 启用整张图的行列条带，替代每个面板的条带；strip2_arg = list() 保持原样。

plt_cat2(cat_fit, max_t = 180, xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)),
         strip2_arg = list(top_label = c("Unadjusted", "Age + Race adjusted"),
                           right_label = c("DSS survival", "Female - Male"),
                           top_right_fill = c("Grays", "Greens")))

dif_arg$ylim 控制下排曲线，dif_arg$xlim 控制下排的差值森林图。show_dif_header = FALSE 省去方法标题行，保留列标题与数值。

plt_cat2(cat_fit, max_t = 180, xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)),
         dif_arg = list(ylim = c(-0.05, 0.25), ybre = seq(0, 0.25, 0.05),
                        xlim = c(0, 0.25), ticks_at = c(0, 0.1, 0.2),
                        ticks_digits = 2),
         show_dif_header = FALSE)

color_pal 统一组别颜色；下排差值是一条对比曲线，不是两条组别曲线。

plt_cat2(cat_fit, max_t = 180, xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)),
         color_pal = "OkabeIto", strip_arg = list(strip = FALSE),
         tag_position = NULL)

plt_cat3()：曲线、森林表与在险人数表

plt_cat3() 在 plt_cat1() 的布局基础上添加在险人数表，默认横向 h。risk_table_args 是命名 list，可以局部覆盖；人数表的位置、字体与是否分组由此配置。嵌入森林表的位置则由 forest.position / fmt.fst.h 调整。

这里内嵌表使用 fmt.fst.h = 0.1，人数表占比 0.25；曲线纵轴从 0.4 开始，为表格预留空间。若改变人数表高度，应一起检查森林表是否挡住曲线。risk_table_args$height 是图形相对高度，不是英寸。

  • 横向与人数表
  • 纵向与人数表
  • 曲线与森林表分栏
  • 只保留曲线和人数
  • 合并人数与文字设置
  • 关闭人数表

每条方法曲线下方给出在险人数，与内嵌表中固定的 Event/total 区分。

plt_cat3(cat_fit, display = "h", fmt.fst.h = 0.1,
         max_t = 180, xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.4, 1), ybre = seq(0.4, 1, 0.1)),
         tag_position = NULL,
         risk_table_args = list(height = 0.25, size = 5, warn = FALSE))

纵向布局增加页面高度，但在网页中便于阅读每个方法的数值。

         max_t = 180, xbreaks = seq(0, 180, 36),

         tag_position = NULL,

s+f 把森林表移到右侧，曲线下方仍保留人数表。

plt_cat3(cat_fit, display = "s+f", max_t = 180,
         xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)),
         risk_table_args = list(height = 0.25, size = 5, warn = FALSE))

sur 仅省去森林表，不会关闭人数表。

plt_cat3(cat_fit, display = "sur", max_t = 180,

         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)),

stratify = FALSE 将人数合并成一行。只改变人数表的汇总显示，曲线仍按 Sex 分组。

plt_cat3(cat_fit, display = "sur", max_t = 180,
         xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)),
         risk_table_args = list(stratify = FALSE, height = 0.18,
                                size = 4, fontface = "plain",
                                ylab = "All patients", warn = FALSE))

risk_table = FALSE 保留曲线与内嵌森林表；需要相应调整内嵌表的纵向位置。

plt_cat3(cat_fit, display = "v", risk_table = FALSE,
         fmt.fst.h = 0, max_t = 180, xbreaks = seq(0, 180, 36),
         sur_arg = list(ylim = c(0.5, 1), ybre = seq(0.5, 1, 0.1)))

风险表在本页 unadj / direct 示例中使用原队列的风险集人数，不能称为“标准化后的预测人数”。IPTW 时 use_weights = TRUE 会使用加权人数，可能不是整数；PSM 时风险表对应匹配后的子队列。

三个绘图函数最后都有 save = list()，默认不保存。需要导出 PDF 时使用同一个命名配置入口：

p <- plt_cat2(cat_fit, max_t = 180, xbreaks = seq(0, 180, 36),
              strip2_arg = list(strip = TRUE),
              save = list(filename = "sex-survival-difference.pdf",
                          width = 16.5, height = 10))
p

save 交给 RegR::save_plt()，保存后仍返回原图形对象。页面图片是本次实际运行的 PNG 预览；PDF 导出代码用于说明保存方式，本页没有执行该文件写入。复用结果对象能避免调一次布局就重跑模型，但保存 cat_fit / cif_fit 本身会连同 par$data 保存原始数据。
