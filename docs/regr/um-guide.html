单多因素分析：手工模型、自动筛选与绝对效应

发布于

2026年10月1日

修改于

2026年11月6日

get_um() 用同一单因素行模板对齐多个多因素模型，适合清楚展示调整集合的变化。页面先展示预先指定模型，再展示自动筛选和绝对效应，最后比较 autoReg 的表格/绘图入口。

数据准备与复现

使用 RegR 自带的 SEER 甲状腺髓样癌队列。保留完整模型变量、正随访时间及肿瘤大小在 0–200 mm 内的记录，再固定种子抽取最多 800 人。stage 合并为 T1/T2 与其余分期，surgery 为无手术与任一手术。它们是本页的演示编码。时间单位沿用原始队列的月。只发布汇总结果。

library(RegR)
library(ggplot2)
library(survival)
data("seer_thyroid_mtc_2026", package = "RegR")
d <- as.data.frame(seer_thyroid_mtc_2026)
d[["DSS"]] <- as.integer(as.character(d[["DSS"]]))
d[["OS"]] <- as.integer(as.character(d[["OS"]]))
needed <- c("time", "DSS", "OS", "Age", "Tum", "Sex", "Race", "T_stage", "Sur")
d <- d[complete.cases(d[needed]) & d[["time"]] > 0 &
       d[["Tum"]] > 0 & d[["Tum"]] < 200, , drop = FALSE]
d[["stage"]] <- factor(ifelse(d[["T_stage"]] %in% c("T1", "T2"), "Early", "Other"))
d[["surgery"]] <- factor(ifelse(d[["Sur"]] == "No surgery", "No", "Yes"),
                          levels = c("No", "Yes"))
set.seed(20261001)
d <- droplevels(d[sample.int(nrow(d), min(800L, nrow(d))), , drop = FALSE])

共用计算与返回对象

get_um() 的 surv=TRUE 是 Cox，FALSE 是 Fine–Gray（需要 event/status 的 0/1/2 编码），字符列名是 Logistic。这个分派与 get_rpa() 不同。var_mul=NULL 直接拟合 full；变量名向量是手工模型，p/forward/backward/lasso/boruta 是筛选方法。列表中的 selection 保留名可消除“列名刚好与方法重名”的歧义。

candidate <- c("Age", "Tum", "Sex", "stage")
um_manual <- run_quiet({get_um(d, var_uni = candidate,
  var_mul = list(clinical = c("Age", "Sex"), full = candidate))})
set.seed(20261001)
um_auto <- run_quiet({get_um(d, var_uni = candidate,
  var_mul = list(clinical = c("Age", "Sex"),
                 selection = c("p", "forward", "lasso")),
  p_args = list(p_threshold = 0.05), step_args = list(criterion = "AIC"),
  lasso_args = list(lambda_rule = "1se", nfolds = 5L))})
um_log <- run_quiet({get_um(d, var_uni = candidate,
  var_mul = list(full = candidate), surv = "DSS",
  abs_args = list(enabled = TRUE))})
um_abs <- run_quiet({get_um(d, var_uni = candidate,
  var_mul = list(full = candidate),
  abs_args = list(enabled = TRUE, time = 60))})

八个返回组件怎么使用

组件 用途
model Log / Cox / Crr
tables eff_res 列表；直接传入 plt_eff / plt_eff2
table 描述列加每个模型的 effect、p_value 宽表
var_mul 最终使用的命名变量集合
selection 完整筛选结果，手工模型时为 NULL
empty 没有入选变量的模型名称，不强行拟合
model_info 来源、变量数与拟合状态清单
absolute 默认 NULL；启用后含绝对效应 tables/table/info

对齐后的空白单元格可能表示该变量不在某模型内，并不表示效应为 0。先读 var_mul/model_info，再读图中的点和区间。

2026-10-20 按已推送 RegR a2f2553 核对：生存/CIF 差值和二分类结局风险差的参考行文字现统一为 Reference，与比值列一致。旧版导出可能仍为小写 reference；参考组、数值和 reference_row 字段没有因此改变。批量整理结果时应按 reference_row 判断参考行，避免只匹配某一种显示拼写。

特殊列名与内部名称避让（2026-11-03）

get_um()将实际列名按字面处理，包括空格、冒号、加号和反引号。"x:z"若就是数据中的一列，不会被拆成交互项；结局列名同样按字面读取。预测列名event或.__w也保留原值，人数/事件数从真正的结局列计算。

以下120行合成数据仅改变列名；P值筛选阈值设为1，以核对两项候选都保留时与原名完整模型的一致性。这里展示实际返回模型表的相关列。

library(RegR)
set.seed(1987)
literal_data <- data.frame(y = rbinom(120, 1, .4), x = rnorm(120),
  z = rnorm(120), g = factor(rep(c("A", "B", "C"), length.out = 120)))
renamed_data <- literal_data
names(renamed_data)[match(c("y", "x", "g"), names(renamed_data))] <- c("out come", "x:z", "g name")
um_literal <- get_um(renamed_data, c("x:z", "g name"), surv = "out come",
  var_mul = "p", p_args = list(p_threshold = 1), abs_args = list(enabled = TRUE))
literal_table <- um_literal[["tables"]][["select_p"]]
literal_view <- gt::gt(as.data.frame(literal_table[c("variable", "label", "row_type",
  "estimate", "conf.low", "conf.high")])) |>
  gt::fmt_number(columns = c(estimate, conf.low, conf.high), decimals = 3)
gt::gtsave(literal_view, file.path(tempdir(), "20261103b-update-um-literal-names.html"))

缺失值规范化与各模型人数（2026-11-03）

get_um()先规范化模型列：SPSS用户缺失值和缺失范围按NA处理，变量标签保留；不支持的列形状、无限值与常量候选列按列名报错。每个模型表的计数来自该模型的完整病例，宽表共用的描述列仍来自各单因素队列。需要模型总人数与事件数时读attr(result$tables[[模型名]], "fit_info")，不要用宽表某列代替所有模型的N。

下面120行中，x有15个SPSS用户缺失，z有60个普通缺失：x单因素用105人，z单因素和完整模型用60人。

library(RegR)
set.seed(1987)
cohort_data <- data.frame(y = rbinom(120, 1, .4), x = rnorm(120), z = rnorm(120),
  g = factor(rep(c("A", "B", "C"), length.out = 120)))
cohort_data[["x"]][1:10] <- 99
cohort_data[["x"]][11:15] <- 95
cohort_data[["x"]] <- haven::labelled_spss(cohort_data[["x"]],
  na_values = 99, na_range = c(90, 98), label = "Predictor X")
cohort_data[["z"]][1:60] <- NA_real_
cohort_result <- get_um(cohort_data, c("x", "z", "g"), surv = "y")
cohort_rows <- dplyr::bind_rows(lapply(names(cohort_result[["tables"]]), function(model) {
  tab <- cohort_result[["tables"]][[model]]
  dplyr::mutate(tab[c("variable", "label", "num1", "eve1")], Model = model)
}))
cohort_gt <- gt::gt(cohort_rows, groupname_col = "Model")
gt::gtsave(cohort_gt, file.path(tempdir(), "20261103c-update-um-cohorts.html"))

非默认因子编码仍比较首水平（2026-11-03）

get_um()从拟合的contrast矩阵和协方差重建因子水平比较：sum、polynomial或另指定基准的treatment编码下，结果表仍以因子首水平为参考，不直接把编码系数当成某一水平的OR。UMS的autoReg入口有不同限制，见UMS编码校验。

library(RegR)
set.seed(1987)
contrast_data <- data.frame(y = rbinom(120, 1, .4), x = rnorm(120), z = rnorm(120),
  g = factor(rep(c("A", "B", "C"), length.out = 120)))
baseline_contrast <- get_um(contrast_data, c("g", "z"), surv = "y", conf_level = .90)
contrast_results <- lapply(list(sum = stats::contr.sum(3), polynomial = stats::contr.poly(3),
  treatment_B = stats::contr.treatment(3, base = 2)), function(coding) {
    changed <- contrast_data
    contrasts(changed[["g"]]) <- coding
    get_um(changed, c("g", "z"), surv = "y", conf_level = .90)
})
contrast_rows <- dplyr::bind_rows(lapply(names(contrast_results), function(coding) {
  tab <- contrast_results[[coding]][["tables"]][["full"]]
  dplyr::mutate(tab[tab[["variable"]] == "g" & tab[["row_type"]] == "level",
    c("label", "estimate", "conf.low", "conf.high", "p_value")], Coding = coding)
}))
gt::gtsave(gt::gt(contrast_rows, groupname_col = "Coding"),
  file.path(tempdir(), "20261103c-update-um-contrasts.html"))

缺失参照水平与绝对概率（2026-11-06）

绝对差的P值口径与不可估计状态（2026-11-03）

使用边界、保存与复现记录

多因素模型加入变量后估计对象可能改变；OR/HR 的非可折叠性也会造成差异，不能把数值变化全部归因于混杂被消除。筛选后的模型不自动获得有效的选择后推断。Cox 需核对比例风险等模型条件，Fine–Gray 与原因特异 Cox 的 estimand 不同。绝对效应时间点必须与随访单位一致；本页没有独立验证，也没有把这些演示结果解释为临床建议。

绘图调色、字体和布局只改变展示；模型、编码、样本、预测时间或权重改变后需要重新计算。带 save 的接口按帮助页传入保存配置；其余返回图可用 ggplot2::ggsave() 或 RegR::save_plt()，表格按返回类型使用 save_tb() / save_gt()。重采样示例的预算仅用于演示，应结合实际分析目的增加并报告失败与收敛情况。
