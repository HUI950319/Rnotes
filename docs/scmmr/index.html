scMMR 概览

scMMR 是基于 reticulate + PyTorch 的单细胞多任务深度学习模型，包含细胞注释、模块评分和通路分析。

主要函数： DNN_*()、ComputeModuleScore()、RunPathwayAnalysis()、PlotPathway*()

参考文档：https://hui950319.github.io/scMMR/　源码：https://github.com/HUI950319/scMMR
