HTE SHAP：代理模型、Kernel SHAP 与保真度

发布于

2026年10月7日

get_hte_shp() 将模型预测的治疗效应分解为协变量贡献。默认会新拟合一个 xgboost 代理模型， 返回这个代理模型的 TreeSHAP。 它对原森林是近似解释。method="kernel" 则直接调用 原森林计算 Kernel SHAP。这两个方法都复用原因果森林，但解释路线不同。 接口按提交 d4aeb78 核对，以下森林、SHAP 和全部图形实际计算。

方法和解释对象

方法 实际解释 保真度与成本
surrogate（默认） 用协变量预测森林完整 CATE 的新 xgboost 模型 80% 解释患者训练，20% 检查；analysis$r2 报告留出患者上的加权 R²
kernel 原森林的预测函数，相对于背景患者 无新代理模型；最多 8 个原协变量时枚举联盟，更多变量采用混合计算，森林预测次数较多

默认 TreeSHAP 的贡献对代理模型成立；R² 高表示代理预测较好地复现森林输出，仍不保证 每个变量的贡献与 Kernel 路线相同。两者对相关变量的分配机制也不同。 方法背景见 Lundberg 与 Lee（2017） 和 Kernel SHAP 官方文档。

解释的单位是森林 CATE 的 diff 尺度：连续结局均值差、二分类风险差，或生存 S(t) / RMST 差。 变量贡献不等于这个变量对结局的因果效应，也不能单凭 SHAP 重要性确立独立效应修饰。

参数与返回对象

参数 默认 作用与条件
x 完整 hte_res 复用森林、协变量数据和训练编码
method "surrogate" 可选 "kernel"
max_n NULL 由成本模型选解释人数；正整数或 Inf 显式指定
bg_n 50 仅 Kernel 的背景人数，均匀取行；代理路线不要显式传此项
surrogate_args list(nrounds=300,max_depth=6,learning_rate=0.1) 仅代理路线；部分覆盖按默认合并；Kernel 路线不要显式传此项
time_budget 20 max_n=NULL 时按估算成本选择人数，不强制计时中断
seed 123 留出切分或联盟抽样种子；函数退出恢复原 RNG 状态
verbose FALSE 输出估计与实际耗时

返回标准 shapviz 对象：S 是患者 × 原协变量贡献矩阵，X 保留原协变量值，baseline 是解释基线。one-hot 编码列会合并回原变量，每个因子一列 SHAP。analysis 属性记录方法、 实际人数、背景人数或代理 R²、参数及耗时；该对象没有自动提供 SHAP 交互矩阵。

拟合一次并检查保真度

set.seed(20261007)
n <- 900
d <- data.frame(marker = rnorm(n), age = rnorm(n, 60, 10),
                stage = factor(sample(c("I", "II", "III"), n, replace = TRUE)),
                noise = rnorm(n))
d$z <- rbinom(n, 1, plogis(0.2 * d$marker + 0.01 * (d$age - 60)))
d$y <- d$marker + 0.03 * (d$age - 60) +
  d$z * (0.5 + 1.5 * tanh(d$marker) + 0.3 * (d$stage == "III")) + rnorm(n)
covs <- c("marker", "age", "stage", "noise")
res <- get_hte(d, "z", adj_var = covs, surv = "y", factor_encoding = "onehot",
               grf_args = list(num.trees = 500, seed = 17, num.threads = 2))

sv <- get_hte_shp(res, max_n = 400, seed = 123)
stopifnot(inherits(sv, "shapviz"), ncol(sv$S) == length(covs),
          identical(.Random.seed, rng_before), all(is.finite(sv$S)))

预算、权重与复现记录

默认时间成本模型可能将大森林的 Kernel 解释压缩到少量患者；少于 10 人会警告。 max_n=Inf 绕过抽样预算，应先估计规模。记录 analysis$n/n_total、方法、背景人数、 种子和代理参数；20 秒预算是规模估算，实际耗时随机器变化。

观察权重进入代理训练、留出 R² 和 Kernel 背景积分；shapviz::sv_importance() 等默认汇总 仍等权平均解释患者。报告加权目标人群的全局汇总时应另行匹配其权重。
