发布于

修改于

注记运行前核对树变量参数

本页按本站72d6139及b0f67c1统一使用tree_var：对应本机causalR f505185中的select、unihtee、tree和icf四个入口。核对时远端f3f7ecc仍用candidate_var；旧安装请替换该参数名。历史输出未因改名重新计算，详见 发布状态。

比较多种树时，常见成本来自重复拟合发现/估计森林。reuse 允许在相同拟合背景下复用森林， 重新建立规则与估计叶子。它不是给新患者套用模型的接口；新患者分组用 predict()，见 树稳定性与预测。

可变和不可变的参数

设置 可与 reuse 一起改变？ 理由
method 可以 同一得分背景上尝试不同树引擎
tree_var、max_depth、alpha、min_leaf 可以 改变规则发现；alpha 只适用于检验引擎
tree_args 可以 新引擎的切点、剪枝和检验控制
estimator 可以 AIPW/TMLE 叶子报告；TMLE 只适用非生存
原始 data、行顺序、列内容 不可以 原始数据严格一致，包括未用于拟合的列
cat_var/adj_var/surv/time 不可以 决定治疗、调整集合和结局目标
factor_encoding 不可以 改变森林设计列与水平编码
split_frac/seed 不可以 决定患者划分和随机背景
grf_args、grf 版本 不可以 森林设置与后端环境必须一致

从模型树开始时，某个森林可能尚未建立；第一次需要它时仍会计算。 attr(x,"analysis")$forests_reused 的 discovery/estimation 布尔值才是本次是否复用的记录。 仅传入了 reuse 不代表所有森林都跳过拟合。

单次计时受缓存、线程与系统负载影响。初始建模成本要计入完整流程；只有多次比较相同背景时， 才有机会摊薄它。对象各自保留数据与拟合背景，R 内存共享不等于序列化文件共享。

常用引擎与计算参数

引擎/参数 默认 对计算和统计的影响
max_depth 3 深度上限；可设 Inf，policy 要求有限
min_leaf 0.05 占发现患者的最小比例，范围 [0,0.5)；每个子节点还需每臂两人
alpha 0.05 检验门槛；1 强制允许分裂到深度/叶子约束，rpart/policy 不接受
maxt n_boot NULL，按发现集人数解析 ≤5万人用1000；更大时减少，最低250。0无P值并要求alpha=1；详见下节
maxt max_cuts 100 每设计列最多尝试的切点数
ctree testtype "Bonferroni" 可用 Univariate/MonteCarlo，改变检验控制
mob trim/max_cuts 0.1/100 数值切分两端裁去比例/候选切点上限；每切点重拟合，成本可很高
abs/rel/aft adjust TRUE 节点模型调整完整集合；FALSE 只放治疗
abs/rel/aft parm "treatment" 只检验治疗参数，"all" 检验所有参数，问题不同
rpart xval 10 CV 折数；0 保留生长后的未剪枝树
rpart cp_rule "min" "1se" 倾向选择误差在一标准误内的更小树
policy cost/better 0/"higher" 决策阈值与结局有利方向；不良事件通常用 lower
policy split_step NULL 按发现人数设置切点步长，减少精确搜索成本
grf_args$num.trees 包内默认 500，大样本 200 只控制森林；不会代替节点 bootstrap/CV
grf_args$num.threads grf 自动 同时多任务时减少线程竞争；本页为 2

tree_args 只接受相应引擎的已命名字段。把 maxt 的 n_boot 传给 rpart 会报错。 树接口不接受逐行 W.hat/Y.hat/sample.weights/clusters，因为发现/估计行被拆开； 单个已知 PS 标量可以使用，例如随机试验 W.hat=0.5。

max-t默认抽样预算

已推送f3f7ecc把默认tree_args\(n_boot改为NULL：在完整发现样本确定后，使用 `as.integer(min(1000, max(250, round(5e7 / n_disc))))`，并在减少时给出消息。这里n_disc是进入规则发现的有效人数，不是整个队列人数；实际次数记录在 `attr(res,"analysis")\)tree_args$n_boot`。

由公式得到：5万人为1000次、10万人为500次、20万及30万人为250次。这是预算公式示意，本轮没有运行这些大样本来测量耗时。更少抽样使P值分辨率变粗，最小P值为1/(n_boot+1)；不能把这一变化称为统计精度完全相同的加速。需要固定次数时显式传 tree_args=list(n_boot=1000L)。

下面600人例子按本机e389a75在Windows R 4.4.3、UTF-8中实际运行：默认解析为1000，再复用同一森林显式设250。改变次数可能改变分裂P值和树，因此不宣称两棵树结果相同。

set.seed(20261016)
d_boot <- data.frame(b=rbinom(600,1,0.5),x=rnorm(600))
d_boot$z <- rbinom(600,1,0.5)
d_boot$y <- d_boot$x+d_boot$z*(-2+5*d_boot$b)+rnorm(600)
boot_common <- list(data=d_boot,cat_var="z",adj_var=c("b","x"),tree_var=c("b","x"),
  surv="y",method="maxt",max_depth=1,min_leaf=0.1,split_frac=0.5,seed=123,
  grf_args=list(num.trees=100,num.threads=1))
boot_default <- do.call(get_hte_tree,boot_common)
boot_fixed <- do.call(get_hte_tree,c(boot_common,
  list(reuse=boot_default,tree_args=list(n_boot=250L))))
attr(boot_default,"analysis")$tree_args
attr(boot_fixed,"analysis")$tree_args
attr(boot_fixed,"analysis")$forests_reused
