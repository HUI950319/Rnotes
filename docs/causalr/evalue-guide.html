E-value：已发表比值与 Cox / Logistic 模型

发布于

2026年10月7日

get_evalue() 计算一个已观察到的比值及其置信区间的 E-value。可以输入论文里的数字， 也可以在给定数据上拟合 Cox 或 Logistic 模型。它返回结果表；本页的图用这张表绘制。 接口按 causalR 提交 d4aeb78 核对，所有结果与图形均在渲染时实际计算。

E-value 衡量：在已调整协变量之外，未测量混杂与暴露、结局的关联需要有多强，才可能把 观察到的关联解释到无效值。它使用风险比尺度，不给出混杂发生的概率，也不能证明因果识别成立。 方法依据见 VanderWeele 与 Ding（2017）。

选择输入和效应尺度

输入 写法 模型与尺度
论文表格中的字符串 effect="1.85 (1.20-2.85)", measure="OR" 必须明确 RR、OR 或 HR
已有数值 est=0.58, lo=0.41, hi=0.80, measure="HR" lo/hi 同时给出或同时省略
生存数据 data, cat_var, adj_var, surv=TRUE 固定读取 time、DSS，拟合 Cox，返回 HR
二分类数据 data, cat_var, adj_var, surv="y" 结局列为 0/1、逻辑或两水平因子，拟合 Logistic，返回 OR

数据拟合时不要再指定 measure，模型决定尺度。多水平暴露每个非参照水平返回一行。 当前入口拒绝 surv=FALSE 的 Fine–Gray sHR；也不能直接接收森林 CATE、RMST 差或任意效应表。

参数与返回表

参数 默认 作用与条件
data NULL 缺省时使用字符串或数值输入；两种输入路线择一
cat_var / adj_var NULL 数据路线的暴露列、调整列；调整变量预先确定
surv TRUE Cox；列名字符串选择 Logistic
effect NULL 一个字符串，支持括号或方括号以及横线、逗号等分隔符
est/lo/hi NULL 正数；区间需包含点估计并按下限、上限排序
measure NULL 手输路线必填 RR/OR/HR；数据路线不接受
rare FALSE OR/HR 先换算为 RR；TRUE 按罕见结局近似直接使用；RR 忽略此项
conf_level 0.95 仅用于数据路线的 Wald 区间；手输区间已有自己的置信水平

返回列包括原尺度的 est/lo/hi、换算后的 rr/rr_lo/rr_hi，以及 evalue_point/evalue_ci。 没有区间时 evalue_ci=NA；区间覆盖 1 时 evalue_ci=1。term 标记模型中的暴露对比， 手输结果为 NA；RR 输入的 rare 也为 NA。

from_text <- get_evalue(effect = "1.85 (1.20-2.85)", measure = "OR")
from_num <- get_evalue(est = 1.85, lo = 1.20, hi = 2.85, measure = "OR")
stopifnot(isTRUE(all.equal(from_text, from_num)))
knitr::kable(from_text, digits = 3)
term measure est lo hi rare rr rr_lo rr_hi evalue_point evalue_ci
NA OR 1.85 1.2 2.85 FALSE 1.36 1.095 1.688 2.06 1.419

plot_ev <- function(x, title) {
  tab <- data.frame(target = c("Point estimate", "Confidence limit"),
                    evalue = c(x$evalue_point, x$evalue_ci))
  ggplot(tab, aes(target, evalue, fill = target)) +
    geom_col(width = 0.6) + geom_hline(yintercept = 1, linetype = 2) +

    scale_fill_manual(values = c("Point estimate" = "#B13B35",
                                "Confidence limit" = "#347BA0")) +
    scale_y_continuous(expand = expansion(mult = c(0, 0.15))) +
    labs(x = NULL, y = "E-value (risk-ratio scale)", title = title) +
    theme_minimal(base_size = 12) + theme(legend.position = "none")
}

rare：先核查结局发生，再选择近似

rare=TRUE 把 OR/HR 直接当作 RR；默认 FALSE 对 OR 使用平方根，对 HR 使用近似换算。 因此相同的 OR/HR 数字可能得到不同的 E-value。换算依据见 VanderWeele（2020） 和 EValue 官方帮助。

rare_tab <- do.call(rbind, lapply(c("OR", "HR"), function(m) {
  do.call(rbind, lapply(c(FALSE, TRUE), function(r) {
    ev <- get_evalue(est = 2, lo = 1.3, hi = 3, measure = m, rare = r)
    data.frame(measure = m, rare = paste0("rare = ", r),
               point = ev$evalue_point, limit = ev$evalue_ci)
  }))
}))
ggplot(rare_tab, aes(rare, point, fill = rare)) + geom_col(width = 0.6) +
  geom_point(aes(y = limit), size = 3, shape = 21, fill = "white") +
  geom_text(aes(label = sprintf("%.2f", point)), vjust = -0.5) +
  facet_wrap(~ measure) + labs(x = NULL, y = "E-value", fill = NULL) +
  scale_y_continuous(expand = expansion(mult = c(0, 0.15))) +
  theme_minimal(base_size = 12) + theme(legend.position = "none")

包帮助建议在每个暴露组核查随访终点的累积发生，而不只看总样本比例。Cox 数据存在删失时， 事件数除以样本量会低估累积发生；病例对照样本的病例占比也不能代表来源人群的发病风险。 帮助页以各组低于约 15% 作为罕见结局参考，10% 是更严格的选择；研究中应预先说明判据， 信息不足时保留默认值。下面提供检查代码，不替读者自动判定。

# Logistic：每个暴露组的结局比例
prop.table(table(data[["exposure"]], data[["outcome"]]), 1)
# Cox：在预先指定、各组有随访支持的共同终点检查累积发生
km <- survival::survfit(survival::Surv(time, DSS) ~ exposure, data = data)

从数据拟合：同一队列、不同模型

下面是公开的合成数据；连续时间结局与二分类结局分别生成，不能把二者的 OR、HR 当成同一估计量。

set.seed(20261007)
n <- 1200
d <- data.frame(age = rnorm(n, 60, 10),
                exposure = factor(sample(c("A", "B", "C"), n, replace = TRUE)))
z <- as.integer(d$exposure) - 1
d$y <- rbinom(n, 1, plogis(-2 + 0.025 * (d$age - 60) + 0.45 * z))
event_time <- rexp(n, rate = 0.02 * exp(0.03 * (d$age - 60) + 0.3 * z))
censor_time <- rexp(n, rate = 0.012)
d$time <- pmin(event_time, censor_time)
d$DSS <- as.integer(event_time <= censor_time)

置信水平只改变区间及相应 E-value，不改变点估计。报告中应同时写出原效应尺度、调整变量、 置信水平、rare 的选择依据，以及点估计和置信限的 E-value。大 E-value 仍不能处理所有 选择偏倚、测量误差、模型误设或选择后的分析问题。
