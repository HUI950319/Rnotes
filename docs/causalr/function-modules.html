get_PSW()：含空格或连字符的变量名

2026-10-03 的源码修复 4582e7f 让 PS 拟合可以使用 Age (years)、chol-level 等列名。内部为 WeightIt 建立合法占位名，返回拟合对象的 covs 恢复原名，避免变量被误当成函数或在平衡诊断中遗漏。

library(causalR)
set.seed(20261005)
d_psw <- data.frame(age = rnorm(300, 50, 10), chol = rnorm(300))
d_psw[["z"]] <- rbinom(300, 1,
  plogis(-1 + 0.02 * d_psw[["age"]] + 0.4 * d_psw[["chol"]]))
names(d_psw) <- c("Age (years)", "chol-level", "treatment arm")
psw <- get_PSW(d_psw, treat = "treatment arm",
  adj_var = c("Age (years)", "chol-level"), estimand = "ATE", balance = TRUE)
psw[["stats"]]
names(psw[["fit"]][["covs"]])
# "Age (years)" "chol-level"

HTE 输入与缺失分母（2026-10-28）

本轮按已推送 causalR 26af481 核对，版本仍为 0.0.0.9000、显式导出仍为 24 项。get_hte() 规范化带标签及精确范围内的 integer64，SPSS 用户缺失按 NA 处理，先拒绝保留输出名和非向量分析列。只有暴露或结局缺失删除整行，GLM 筛查另需完整模型协变量；两入口的 integer64 支持不同。240 行输入复核实际保留 238 行，其中四行缺失协变量仍进入森林。本轮 causalR 新例仅在 Windows R 4.4.3 执行，旧图保留原快照。

结果打印与读取层级（2026-10-25）

2026-10-25 按已推送 causalR 7a43fb9、UtilsR 0.6.10 0e4cffe 核对，显式导出仍为 24 项。本轮主要更新 get_sens()、get_hte()、get_hte_icf()、get_hte_tree()、get_PSM()、get_PSW() 返回结果的打印方法，采用共享的类标签、键值、分节与紧凑表格；没有因此增加估计器。

先看类名、方法和样本摘要，再读设置块与结果表，末尾提示给出后续绘图或读取入口。屏幕表可能省略行列，程序分析仍应直接读取返回对象。这里用 R 自带 mtcars 演示线性模型敏感性结果，仅在 Windows R 4.4.3 执行；本轮未在 WSL 重跑 causalR，也没有重新训练因果森林。

平衡结果的摘要与组成字段（2026-10-26）

按已推送 causalR 4952af8，get_bal() 返回 bal_res：print() 先显示方法摘要与最大绝对 SMD，再提示组成字段；完整 SMD、权重和图仍从命名分量读取。get_hte_select()、树稳定性与 unihtee 的返回类也增加摘要打印，HTE、iCF、树、PSM、PSW、敏感性结果末尾列出 Components，帮助定位对象内部，不会因打印重拟合。

下面使用 60 行合成数据，仅在 Windows R 4.4.3 运行 ATE / ATO 两种 glm 权重方案，不重训因果森林。摘要中的 SMD 是本次平衡诊断，不能把它单独当作因果识别或结局效果的证明。

balance26 <- get_bal(data_balance26, treat = "Tx", adj_var = c("Age", "Sex"),
  methods = c("ATE", "ATO"), tbl = FALSE, cores = 1)
lines_balance26 <- capture.output(printed_balance26 <- withVisible(print(balance26)))
names(balance26)
UtilsR::pr_tree(balance26, max_depth = 1, max_items = 4, attrs = FALSE)

save_console26 <- function(lines, name) {
  body <- paste(fansi::sgr_to_html(htmltools::htmlEscape(lines)), collapse = "\n")
  chars <- strsplit(body, "", fixed = TRUE)[[1]]; cp <- utf8ToInt(body)
  for (i in which(cp > 127L & !(cp >= 0x2500L & cp <= 0x257fL))) {
    w <- cli::ansi_nchar(chars[i], type = "width")
    if (w %in% 1:2) chars[i] <- sprintf('<span class="w%d">%s</span>', w, chars[i])
  }
  html <- paste0('<!doctype html><meta charset="utf-8"><style>',
    'body{margin:0;background:white;color:#222}pre{margin:0;padding:20px;',
    'font:15px/1.6 Consolas,"DejaVu Sans Mono",monospace;white-space:pre}',
    '.w1,.w2{display:inline-block}.w1{width:1ch}.w2{width:2ch}',
    '</style><pre data-native-console>', paste(chars, collapse = ""), '</pre>')
  writeLines(html, file.path(tempdir(), paste0("20261026-update-", name, ".html")), useBytes = TRUE)
}
save_console26(lines_balance26, "causal-balance-summary")
validation_values <- list(class = class(balance26), components = names(balance26),
  balance = as.data.frame(balance26[["balance"]]), print_invisible = !printed_balance26[["visible"]])

亚组显示与总体行（2026-10-20）

2026-10-20 按已推送 causalR 7a983f1d 更新 plt_hte_sub(effect = ...) 的说明：未单独指定 "All patients" 时，总体行会跟随被替换的亚组估计或区间；明确给 "All patients" = "conf_0.95" 可保留森林的原总体。替换多个分组变量的估计时必须明确指定总体。

工作流中的完整模拟例子已在 Windows / WSL R 4.4.3 运行，提供“总体跟随”和“保留原总体”的两张 PDF。人工替换是展示操作，不重拟合森林；交互检验、cate_mean 和其他分组变量的估计不会据此重算。

随后按已推送 c200683 补齐三处名称映射：get_bal() / plt_hte_unihtee() 的 var_names 与 plt_hte_sub() 的 label_column_list 接受重复键并保留第一项。不同候选变量在筛查图中仍须有不同显示名；默认合并RegR字典与 NULL 保留原名的区别不变。共用字典的三个实际预览核对平衡数值、亚组表和绘图数据不变，Windows / WSL 均通过；显式导出数量仍为24项。
