关于这份笔记

这里收集我自己开发的几个 R 包的笔记：函数为什么这样设计、参数怎么选、 不同实现的耗时与结果差异，以及使用中踩过的坑。每个包一个分区， R 与开发环境的故障记录单独收录在 R 问题排查。函数的参考文档仍以各包的 pkgdown 站点为准。

每个包分区的第一页是功能模块图，包含功能总览、完整接口索引和流程展示。点击图片可放大，也可下载可编辑的 draw.io 文件和 PDF。

RegR 与 MLR 的 GitHub 源码仓库为私有，源码链接需获授权的 GitHub 账号；各页记录核对的源码提交和图形执行快照，旧安装需按接口核对。各包参考站点仍可用于查阅帮助。

causalR 的功能模块图收录在本站；因果推断读书笔记见 causalR。
