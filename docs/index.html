R 包开发笔记

RegR · MLR · UtilsR · seerR · LabR · scMMR · ToyData · causalR

作者

HUI950319

关于这份笔记

这里收集我自己开发的几个 R 包的笔记：函数为什么这样设计、参数怎么选、 不同实现的耗时与结果差异，以及使用中踩过的坑。每个包一个分区， 函数的参考文档仍以各包的 pkgdown 站点为准。

每个包分区的第一页是功能模块图，包含功能总览、完整接口索引和流程展示。点击图片可放大，也可下载可编辑的 draw.io 文件和 PDF。

causalR 的功能模块图收录在本站；因果推断读书笔记见 causalR。

包一览

包 用途 功能模块图 参考文档
RegR 临床回归分析：效应估计、亚组与交互、RCS、竞争风险，森林图等可视化 查看图谱 pkgdown
MLR 机器学习特征重要性、SHAP、PDP 与变量交互（VIVI） 查看图谱 pkgdown
UtilsR 通用绘图、格式化与数据探索工具 查看图谱 pkgdown
seerR SEER 肿瘤登记数据的 ETL 流程与队列构建 查看图谱 —
LabR CCK-8、Western blot、qPCR 等基础实验作图 查看图谱 pkgdown
scMMR 单细胞多任务深度学习模型（reticulate + PyTorch） 查看图谱 pkgdown
ToyData 各包共享的示例数据集 查看图谱 —
causalR 倾向评分设计、异质性效应与未测量混杂敏感性分析 查看图谱 因果推断笔记

包之间的依赖

分析流程的数据从下往上流动，包依赖只指向下层：

L2  seerR  Imports  -> UtilsR
L1  UtilsR Suggests -> RegR, scMMR, ToyData
