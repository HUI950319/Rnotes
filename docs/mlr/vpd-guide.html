变量分布与 PDP：解释器、分组和预测时间

发布于

2026年10月9日

修改于

2026年10月27日

get_exp() 构建预测解释器，get_vpd() 将变量分布（VD）与部分依赖（PD）放在一起。本页用实际图形解释两块面板的差别，并对照主要任务和分组路径。

版本与执行范围： 按 MLR 0.1.13 当前源码核对，使用 WSL R 4.4.3 实际导出原主教程 12 张参数对照图。Cox、Logistic 和生存随机森林均实际训练，图形来自公开入口；使用已有临床示例和模拟二分类数据，未执行外部临床验证。

示例准备与读图规则

生存示例使用 ToyData::toy_ptc_m1_cnd 的 598 人 M1 PTC 队列，175 个疾病特异死亡事件，time 单位为月，与 ToyData 介绍一致。模型使用 Age、Sex、Tum_3；Unknown 是原有因子水平。二分类示例为固定种子的 300 行模拟数据，正类明确为 Yes，避免把删失生存记录直接当成完整二分类结局。

面板 如何得到预测 解释范围
VD 每个观测保留其实际特征，展示变量值与模型预测 有混杂特征与其他变量差异
PD 扫描关注变量并对参考样本预测平均 已拟合模型的平均响应；不是回归系数
生存 y 轴 S(t) 当前预测时间的生存概率
二分类 y 轴 P(Outcome = Yes) 正类预测概率

横轴上的密集区域反映观测分布。超出数据支持的变量组合需要结合样本密度判断；曲线也不能直接解释为干预效果。

  c("time", "DSS", "Age", "Sex", "Tum_3", "Race")])

  0.7 * dc[["Marker"]] * (dc[["Group"]] == "B"))

  levels = c("No", "Yes"))

get_ale2()：去除主效应后的二阶 ALE

本节按 MLR 0.1.13 源码 95d3204 核对；复用 二维 PDP 页的 300 行合成数据与 cvars，在 WSL R 4.4.3 中实际执行。

原有 get_vpd(exp_var=c("Group","Marker")) 是按组展示的一维响应曲线。get_ale2() 计算两个变量的局部二阶变化、累积并去除低阶项，用于观察模型中的二阶交互；它与包含主效应的 get_pdp2() 有不同含义。

get_ale2(EXP.obj, exp_var, N = 10000, grid_size = 20, scale = c("link", "prob"),
  engine = c("iml", "ale"), cores = NULL, save = list())
  • 随机森林的概率尺度
  • 加性 Logistic 的 link 尺度
ec_joint <- get_exp(dc, vars = cvars, surv = "Outcome", model = "ranger", cores = 1)
interaction_ale <- get_ale2(ec_joint, c("Marker", "Group"),
  N = 300, scale = "prob", cores = 1)
interaction_ale
ec_linear <- get_exp(dc, vars = cvars, surv = "Outcome", model = "default")
linear_ale <- get_ale2(ec_linear, c("Marker", "Group"),
  N = 300, scale = "link", cores = 1) +
  coord_cartesian(ylim = c(-0.1, 0.1))
linear_ale

第二张图将纵轴固定在 ±0.1 logit，避免放大约 1e−16 的浮点误差。模拟数据含有 Marker × Group，但默认 Logistic 工作模型只拟合主效应，所以第二张图的 link 尺度交互应接近零。图解释的是实际拟合模型；不能据此否定真实数据生成过程中的交互。概率尺度与 link 尺度的交互含义也不同。

默认 N=10000，N=NULL 使用全部数据；超过 N 时等间隔取行，不消耗 RNG。二阶 ALE 的成本主要是每个有效局部区间四角预测。随机森林没有对应的拟合 link，显式使用 scale="prob"；Cox / Logistic 的 link 则对应模型工作尺度。

本例执行默认 engine="iml"；其他引擎和分类水平排序应按当前帮助选择。二阶 ALE 是模型解释图，不提供交互 P 值，也不能替代临床效应修饰检验。

接口、返回对象与分析流程

surv 实际任务 预测时间
TRUE / FALSE 生存 默认 120；FALSE 仍走生存路径
数值，如 60 生存 使用该数值，单位跟随 time
字符结局名 二分类 没有随访时间维度

model = default 对生存是 Cox，对二分类是 Logistic；另外支持 ranger 和 xgboost。get_exp() 返回统一的 12 字段 list：核心解释器在 EXP，追加预测的原始数据在 dat，类型名称在 cat_vars / con_vars，原始设置在 par_lis。per、imp_res、imp_plot 等随任务填充；默认生存简化路径中的预生成重要性/PDP 字段可为 NULL。

get_vpd() 接受完整解释结果或构建参数 list，返回组合图。exp_var = c(group, focus) 的第一项必须为分类变量。这是分组的一维 PDP。当前生存分组路径会按组重建解释器；分类路径使用 DALEX 的分组剖面。因此不能把组间曲线直接当成同一模型的二维联合响应。真正二维生存 PDP 的接口和图谱见后续专题。

get_exp(data, vars, surv = 120,
        model = c("default", "ranger", "xgboost"))
get_vpd(EXP.obj, exp_var, tidy_plot = TRUE, cores = NULL)
get_vpd_pnl(EXP.obj, exp_var, N = 300, cores = NULL)

输入隔离、正类编码与预测缓存（2026-10-27）

按已推送 MLR 52c03f9，get_exp() 在拟合前统一输入检查，阻止把结局放进 vars，保留字 yhat 也不能被原数据占用。生存任务还禁止 time / DSS 出现在预测变量中，并在无事件时提前停止。下例只拟合 60 行合成 Logistic 数据，演示带空格的结局名、字符/逻辑特征和预测缓存。

library(MLR)
library(ggplot2)
set.seed(20261027)
exp_data27 <- data.frame("Marker score" = rnorm(60), Group = rep(c("A", "B"), 30),
  Flag = rep(c(TRUE, FALSE, FALSE), 20), check.names = FALSE)
exp_data27[["Clinical outcome"]] <- factor(ifelse(runif(60) < plogis(
  .2 + .5 * exp_data27[["Marker score"]]), "Event", "Control"),
  levels = c("Unused", "Control", "Event"))
exp_before27 <- exp_data27
exp_vars27 <- c("Marker score", "Group", "Flag")
exp27 <- get_exp(exp_data27, vars = exp_vars27, surv = "Clinical outcome", model = "default")
print(exp27)
exp_types27 <- data.frame(variable = exp_vars27,
  input = vapply(exp_before27[exp_vars27], function(x) class(x)[1], ""),
  returned = vapply(exp27[["dat"]][exp_vars27], function(x) class(x)[1], ""))
gt::gtsave(gt::gt(exp_types27), file.path(tempdir(), "20261027-update-explainer-types.html"))
exp_plot27 <- ggplot(exp27[["dat"]], aes(x = yhat, fill = `Clinical outcome`)) +
  geom_histogram(position = "identity", alpha = .5, bins = 12) +
  labs(x = "P(Event)", y = "Training observations", fill = "Original outcome",
    title = "Apparent predictions; no validation split") + theme_minimal(base_size = 12)
ggsave(file.path(tempdir(), "20261027-update-explainer-probabilities.pdf"), exp_plot27,
  width = 7, height = 4.5)

因子结局丢掉未观测水平后，保持其余原顺序，第二个水平为 1 和预测正类；字符结局按 factor(y) 的水平顺序，数值可用 0/1 或 1/2（较大值为正类），逻辑 TRUE 为正类。缺失、单类和多类结局会拒绝。本例是 Control / Event，因此 EXP$y=1 对应 Event；dat 和 par_lis$data 仍保留原结局标签。

字符、逻辑预测变量被转成 factor，cat_vars 与返回数据保持一致；普通数值仍是连续变量。Date、difftime、integer64、矩阵或 list 预测列应先明确转换，不能自动猜测单位或编码。data.table、分组 tibble 会在内部规范化为普通 data.frame，调用者对象不被改写；命名 vars 向量的名字也不重命名真实列。

原始预测列、缺失边界与保存后复用（2026-10-27）

MLR a4865f2 在上一小节 52c03f9 的快照之后，继续补齐预测输入和 RDS 回读。原始字符/逻辑预测列可直接交给 stats::predict(result$EXP, newdata)，内部与拟合时的因子水平对齐；ranger 分类预测也遵守 cores，小批量预测的线程数不会超过行数。下面只训练 48 行合成分类数据，不作外部验证或速度比较。

library(MLR)
set.seed(2712)
reload_data27 <- data.frame(Marker = rnorm(48),
  Group = rep(c("A", "B"), 24), Flag = rep(c(TRUE, TRUE, FALSE, FALSE), 12))
reload_data27[["Outcome"]] <- factor(ifelse(runif(48) < plogis(.3 * reload_data27[["Marker"]]),
  "Event", "Control"), levels = c("Control", "Event"))
reload_vars27 <- c("Marker", "Group", "Flag")
reload_before27 <- reload_data27
reload_log27 <- get_exp(reload_data27, reload_vars27, surv = "Outcome", model = "default")
reload_rf27 <- get_exp(reload_data27, reload_vars27, surv = "Outcome", model = "ranger", cores = 1)
reload_file27 <- file.path(tempdir(), "explainer-ranger-20261027.rds")
saveRDS(reload_rf27, reload_file27)
# 在另一个 R 会话中加载同一版本及依赖后，可直接读取并预测，不重新训练。
reload_restored27 <- readRDS(reload_file27)
stats::predict(reload_restored27[["EXP"]], reload_data27[1:6, reload_vars27])

预测变量的边界按后端区分：所有路径拒绝 Inf / -Inf；Logistic 分类、Cox 与 ranger 生存要求完整预测列，不自动删行。ranger 分类和 XGBoost 保留各自的缺失值处理能力，不应统一 na.omit() 或笼统写成所有后端都拒绝 NA。

生存结局必须是普通数值向量：DSS 无缺失且为 0/1、至少 1 个事件；time 有限且非负，XGBoost 进一步要求随访严格大于 0。预测时点为 0 与随访为 0是两件事，不能把 XGBoost 的随访限制套到预测时点。因子/逻辑事件列、Date 时间列须先按真实含义显式转换。

当前网格与统一工作流

2026-10-16按MLR 78c4238 与RegR a8a6eb8 的固定源码快照在WSL R 4.4.3执行以下新例；相关ALE接口已包含于核对时远端MLR 462f041、RegR 1dc3b2f。旧图保留原快照。

grid_size默认20，是每个连续变量的分位数区间数，两种引擎都使用它；通常有grid_size+1个网格点，重复分位数会减少实际点数。分类变量仍每个水平一个点。它与N限制背景行数是两种控制，改变任一项都可能改变近似结果。

热图当前统一用红色表达较高风险：log累计风险、logit和事件概率的正ALE为红；生存概率尺度则负ALE为红。不能将所有尺度都读作“红色=ALE正值”。分类×连续变量仍用分类曲线展示。

相同模型比较两种网格

同一个解释器只训练一次，分别用6和16个分位数区间计算二阶ALE。连续网格更细时每格样本更少；这会改变估计的曲面，不能作为纯计算提速比较。

set.seed(20261016)
d_ale <- data.frame(Age = runif(400,20,80), Marker = rnorm(400),
  Group = factor(sample(c("A","B"),400,TRUE)))
d_ale$Outcome <- factor(ifelse(runif(400) < plogis(-0.4 +
  0.04*(d_ale$Age-50) + d_ale$Marker + 0.06*(d_ale$Age-50)*d_ale$Marker),"Yes","No"))
exp_ale <- get_exp(d_ale, vars=c("Age","Marker","Group"), surv="Outcome", model="ranger",cores=1)
ale_coarse <- get_ale2(exp_ale,c("Age","Marker"),N=400,grid_size=6,scale="prob",cores=1)
ale_fine <- get_ale2(exp_ale,c("Age","Marker"),N=400,grid_size=16,scale="prob",cores=1)
(ale_coarse + ggtitle("6 quantile intervals") |
  ale_fine + ggtitle("16 quantile intervals")) &
  theme(text=element_text(size=10),strip.text=element_text(size=11),
    axis.title=element_text(size=11),legend.title=element_text(size=10),
    plot.title=element_text(size=13))

get_all的二阶ALE入口

统一入口显式传ale2.args才启用分析，结果在ale2字段。此例选择ranger与概率尺度；省略model的当前模板选择xgboost，省略scale选择link。

ale_all <- get_all(com.args=list(data=d_ale,adj_var="Group",surv="Outcome"),
  ale2.args=list(exp_var=c("Age","Marker"),model="ranger",scale="prob",
    grid_size=6,N=400,cores=1))
ale_all$ale2 + theme(text=element_text(size=10),strip.text=element_text(size=12),
  legend.title=element_text(size=10))

get_all现在有13个分析入口。ale2.args必须显式提供才启用；仅提供exp_var时继承model=“xgboost”、scale=“link”、grid_size=20。com.args提供data、adj_var、surv和生存预测时间time；N、engine、cores、save继续传给get_ale2。返回 res$ale2 是图，不是交互显著性检验。
