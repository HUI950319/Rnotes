变量交互：H 统计量、paired-VIMP 与 VIV 图谱

发布于

2026年10月1日

修改于

2026年10月22日

get_hstats() 与 get_rfint() 将不同的交互计算结果组织成同一 VIV 矩阵，plt_viv() 负责热图和网络展示。本页重点展示计算参数与图形参数分别改变什么。

版本与执行范围： 按 MLR 0.1.13 当前源码核对，使用 WSL R 4.4.3 实际导出本页 12 张参数对照图。实际训练 ranger / randomForestSRC，并生成 12 张图；使用小规模网格和单线程设置。交互统计量用于预测结构探索，本文没有进行模型交互项的显著性检验。

示例准备与读图规则

生存示例使用 ToyData::toy_ptc_m1_cnd 的 598 人 M1 PTC 队列，175 个疾病特异死亡事件，time 单位为月，与 ToyData 介绍一致。模型使用 Age、Sex、Tum_3；Unknown 是原有因子水平。二分类示例为固定种子的 300 行模拟数据，正类明确为 Yes，避免把删失生存记录直接当成完整二分类结局。

模拟生成过程含 Marker 与 Group 的乘积项；森林可能学到其他预测交互，不能用某一张热图证明恢复了全部真实结构。

library(MLR)
library(ToyData)
library(ggplot2)

d <- as.data.frame(ToyData::toy_ptc_m1_cnd[,
  c("time", "DSS", "Age", "Sex", "Tum_3", "Race")])
d <- droplevels(d[complete.cases(d), ])
vars <- c("Age", "Sex", "Tum_3")
set.seed(246)
n <- 300L
dc <- data.frame(Age = runif(n, 20, 85),
  Sex = factor(sample(c("Female", "Male"), n, TRUE)),
  Marker = rnorm(n), Group = factor(sample(c("A", "B"), n, TRUE)))
prob <- plogis(-0.4 + (dc[["Age"]] - 50) / 20 +
  0.5 * (dc[["Sex"]] == "Male") + 0.8 * dc[["Marker"]] +
  0.7 * dc[["Marker"]] * (dc[["Group"]] == "B"))
dc[["Outcome"]] <- factor(ifelse(runif(n) < prob, "Yes", "No"),
  levels = c("No", "Yes"))
cvars <- c("Age", "Sex", "Marker", "Group")

# 较小网格只用于示例；正式分析应检查更细网格的稳定性
hs_args <- list(approx = TRUE, grid_size = 10, n_max = 60)
h <- get_hstats(dc, vars = cvars, surv = "Outcome", class = "Yes",
  num.trees = 100, Num.sample = 250, hstats_args = hs_args,
  seed = 246, verbose = FALSE, num.threads = 1)
hr <- get_hstats(dc, vars = cvars, surv = "Outcome", class = "Yes",
  num.trees = 100, Num.sample = 250, scale_interaction = FALSE,
  hstats_args = hs_args, seed = 246, verbose = FALSE, num.threads = 1)
ha <- get_hstats(dc, vars = cvars, surv = "Outcome", class = "Yes",
  num.trees = 100, Num.sample = 250, normalize = FALSE, squared = FALSE,
  scale_interaction = FALSE, hstats_args = hs_args,
  seed = 246, verbose = FALSE, num.threads = 1)
hchf <- get_hstats(d, vars = vars, surv = TRUE, num.trees = 80,
  Num.sample = 250, hstats_args = hs_args, seed = 246,
  verbose = FALSE, num.threads = 1)
hprob <- get_hstats(d, vars = vars, surv = 60, num.trees = 80,
  Num.sample = 250, hstats_args = hs_args, seed = 246,
  verbose = FALSE, num.threads = 1)
rf <- get_rfint(dc, vars = cvars, surv = "Outcome", num.trees = 100,
  Num.sample = 250, nrep = 2, seed = 246, verbose = FALSE, nthread = 1)

接口、返回对象与分析流程

路线 模型 / 交互定义 预测目标
get_hstats ranger + hstats，比较联合 PDP 与可加 PDP 生存 TRUE 为 CHF；数值 surv 为固定时间生存概率；字符 surv 为指定正类概率
get_rfint randomForestSRC + paired-VIMP，比较变量联合扰动与单独扰动 生存或分类森林的重要性尺度
SHAP interaction 分配预测贡献的交互分量 见现有 SHAP 专题，依赖模型输出尺度

返回值是带行列变量名的数值矩阵：对角线为变量重要性，非对角线为交互强度。矩阵附带原始交互等属性；例如 attr(h, "interaction_raw") 可检查缩放前数值。plt_viv() 返回 ggplot，使用两套色标分别表示对角线与非对角线。

H² 是预测尺度上的交互强度，不是交互 HR、置信区间或 P 值。normalize = FALSE 改成绝对量，squared = FALSE 改成 H，scale_interaction 仅控制最终展示缩放。数值 surv 使用所选时点之前最近的森林网格值（右连续阶梯），不取距离最近的未来网格；应检查所选时间附近的支持。

H 统计量：定义与展示缩放

normalize 决定 H 的相对/绝对定义，squared 决定 H²/H；scale_interaction 是最后一步的可视化缩放，不能混为同一个设置。

  • 默认缩放
  • 保留相对 H²
  • 未归一化 H

对角线是缩放后的重要性，非对角线是展示用缩放交互；两个色条分别解释。

plt_viv(h, mode = "heatmap", fixed_size = FALSE)

关闭 scale_interaction，非对角线保留相对 H²；仍需留意对角线另用重要性色标。

plt_viv(hr, mode = "heatmap", fixed_size = FALSE)

normalize = FALSE、squared = FALSE；幅度依赖当前正类概率的预测尺度。

plt_viv(ha, mode = "heatmap", fixed_size = FALSE)

plt_viv()：热图参数

热图参数可局部覆盖。数字、轴顺序和色标应一起阅读；调配色不会改变交互统计量。

  • 颜色、边框和标签角度
  • 隐藏数字

保持矩阵数值不变，切换配色并提高数字可读性。

plt_viv(h, color = "blue_red", heatmap_arg = list(border = TRUE, angle = 45, text_size = 4), fixed_size = FALSE)

关闭单元格文字，保留重要性和交互两套色标。

plt_viv(h, color = "purple_gold", heatmap_arg = list(text = FALSE), fixed_size = FALSE)

plt_viv()：网络阈值与节点

intThreshold 筛选边，removeNode 决定是否移除没有保留边的节点。网络阈值不是统计显著性阈值。

  • 较低边阈值
  • 较高阈值与去除孤点
  • 力导向布局与边宽

保留交互强度至少 0.2 的边；阈值针对当前矩阵的展示尺度。

plt_viv(h, mode = "network", network_arg = list(intThreshold = 0.2, removeNode = FALSE), fixed_size = FALSE)

提高阈值并移除孤点，突出少量较强连接。

plt_viv(h, mode = "network", network_arg = list(intThreshold = 0.7, removeNode = TRUE), fixed_size = FALSE)

相同矩阵换为力导向布局，并扩大边宽差异。

plt_viv(h, mode = "network", network_arg = list(intThreshold = 0.2, layout = igraph::layout_with_fr, edgeWidths = c(1, 6)), fixed_size = FALSE)

生存预测目标：CHF 与固定时间

surv = TRUE 使用 CHF 路线；数值 surv 指定生存概率时间。两个目标不同，数值不能当成同一统计量直接比较。

  • 总体 CHF
  • 60 月生存概率

对累积风险函数的多时间输出计算并汇总交互，适合整体筛查。

plt_viv(hchf, fixed_size = FALSE)

交互限定在当前实现映射的 60 月附近生存概率预测上。

plt_viv(hprob, fixed_size = FALSE)

get_rfint()：paired-VIMP 路线

该入口训练 randomForestSRC，并调用 paired-VIMP 交互计算。importance、nrep、pairwise_m 控制扰动方法、重复次数及候选变量。

  • paired-VIMP 热图
  • paired-VIMP 网络

另一套随机森林、另一种交互定义；观察结构，不能把其数值等同 H²。

plt_viv(rf, fixed_size = FALSE)

对 paired-VIMP 的展示矩阵应用 0.4 阈值。

plt_viv(rf, mode = "network", network_arg = list(intThreshold = 0.4), fixed_size = FALSE)

当前 H 统计量：直接构造焦点配对与提示次数

2026-10-22 按已推送 MLR 71c2753 在 Windows / WSL R 4.4.3 执行，使用 iris 的四个数值特征和 setosa 分类概率。int_var 路线现在在 PDP 准备和矩阵组装中直接构造焦点的 p−1 对，避免先枚举全部变量对再过滤；配对顺序及原始分数保持不变。其他 hstats 版本或不兼容缓存仍可能回退到全配对计算，实际路线读 settings$pairwise_calculation。

library(MLR)
features <- names(iris)[1:4]
run_focus <- function(focus = NULL) get_hstats(iris, vars = features,
  surv = "Species", class = "setosa", int_var = focus,
  importance = "impurity", num.trees = 40, num.threads = 1,
  hstats_args = list(grid_size = 6, n_max = 30),
  scale_interaction = FALSE, order_by = "none", seed = 922, verbose = FALSE)
full_h <- run_focus()
focuses <- features[c(1, 2, 4)]
focal_h <- lapply(focuses, run_focus)
names(focal_h) <- focuses
full_raw <- attr(full_h, "interaction_raw")
for (focus in focuses) {
  raw <- attr(focal_h[[focus]], "interaction_raw")
  stopifnot(isTRUE(all.equal(raw[focus, ], full_raw[focus, ], tolerance = 1e-12)),
    all(is.na(raw[features != focus, features != focus])))
}
focus_values <- data.frame(focus = focuses, partners = length(features) - 1L,
  calculation = vapply(focal_h, function(x) attr(x, "settings")[["pairwise_calculation"]], character(1)))
focus_values
plt_viv(focal_h[[features[[2]]]], mode = "heatmap", fixed_size = FALSE,
  save = list(filename = file.path(tempdir(), "20261022-sync-hstats-focal.pdf"), width = 7, height = 6))

四个变量的全配对为 6 对，每个焦点保留 3 对；本例分别验证首、中、末位置的焦点与同一设置的全配对原始值一致。其余空缺仍表示未计算。优化减少配对枚举和无关二阶 PDP，边际与补集计算仍涉及所有特征，训练、背景抽样和网格成本也仍存在；这里没有新增计时或加速倍数。原始值、覆盖率与时间尺度继续按下节合同读取。

impurity_corrected 的预测建议每次分析至多一次

下例的 time 约定为月。

d_advice <- data.frame(a = sin(seq_len(60)), b = cos(seq_len(60)),
  y = factor(rep(c(0, 1, 1, 0), 15)), time = rep(c(5, 20, 60, 100, 150), 12),
  status = rep(c(0, 1, 1, 0, 1), 12))
advice_values <- do.call(rbind, lapply(list("y", 60, 1), function(mode) {
  notes <- character()
  out <- withCallingHandlers(get_hstats(d_advice, c("a", "b"), surv = mode,
    event_col = "status", importance = "impurity_corrected",
    num.trees = 15, num.threads = 1,
    hstats_args = list(grid_size = 4, n_max = 15), seed = 922, verbose = FALSE),
    warning = function(w) {
      notes <<- c(notes, conditionMessage(w)); invokeRestart("muffleWarning")
    })
  n_advice <- sum(grepl("Forest was grown with 'impurity_corrected'", notes, fixed = TRUE))
  expected <- if (is.numeric(mode) && mode < min(d_advice[["time"]])) 0L else 1L
  stopifnot(n_advice == expected, all(is.finite(diag(out))))
  data.frame(prediction = as.character(mode), advice_count = n_advice)
}))

当前 H 统计量：配对覆盖、锚点与原始行位置

以下按已推送 MLR 8d94e59 在 Windows / WSL R 4.4.3 执行，使用 120 行合成数据、40 棵树和小网格验证合同。int_var 是 get_hstats() 新增的焦点变量参数，与上方 get_rfint() 的同名参数分别生效。

library(MLR)
set.seed(621)
dh <- data.frame(x = runif(120), z = rnorm(120),
                 group = factor(rep(c("A", "B"), 60)))
dh[["Outcome"]] <- factor(ifelse(runif(120) < plogis(
  2 * dh[["x"]] + dh[["z"]] * (dh[["group"]] == "B") - 1), "Yes", "No"),
  levels = c("No", "Yes"))
hv <- c("x", "z", "group")
h_now <- function(...) get_hstats(dh, hv, surv = "Outcome", class = "Yes",
  num.trees = 40, Num.sample = 100,
  hstats_args = list(approx = TRUE, grid_size = 10, n_max = 50),
  scale_interaction = FALSE, order_by = "none", seed = 621,
  verbose = FALSE, num.threads = 1, ...)
set.seed(21)
rng_before <- .Random.seed
full_now <- h_now()
focal_now <- h_now(int_var = "x")
screened_now <- h_now(pairwise_m = 1L)
attr(focal_now, "interaction_total")[c("var", "n_pairs", "coverage")]

全部配对 2 / 100% 2 / 100%
int_var="x" 2 / 100% 1 / 50%

interaction_total 新增 n_pairs、coverage。没有已计算配对时，原值与汇总分数是 NA；未计算不等于零交互。常量或未活跃变量已知为零的配对按其变量身份填入，不能让顺序错配。汇总是可用配对之和，不是 Friedman 总体 H²；覆盖不同时不能直接比较总分。

int_var 只保留锚点与其余变量的 p−1 对，其他非对角元素为 NA；不能同时传 pairwise_m。hstats 1.2.2 可复用同一背景和缓存的边际量，其他版本或不支持的对象回退到完整计算后掩膜；本页只核对原始配对数值一致，没有给出新的加速倍数。scale_interaction=TRUE 时最大值基于当前保留配对，跨范围比较应读取 interaction_raw。

固定时点使用 t_grid <= t_target 的最后一个网格值；早于首个时间时生存概率为 1，晚于最后时间时沿用最后值。settings 记录 target_time、actual_time、time_rule 和请求/实际时间网格。surv=TRUE 的 CHF 路线对记录时间上的 H² 作算术平均，不是按时间间隔加权。更改 time.interest 会改变预测和统计目标，不能把缩短时间网格描述为完全等价的计算优化。

对角线的 ranger 重要性是模型整体的重要性，并非当前指定类别或固定时点专属的重要性。分类先在完整病例中确定类别，三类及以上需指定 class，抽样丢失请求类别会报错；生存先解析原始事件编码，再筛选抽样，训练集没有事件会提前报错。结局列、保留列名和歧义配对名称会被拒绝；不能用 write.forest=FALSE 等破坏后续预测的设置。

  • 只计算锚点变量的paired-VIMP

int_var与pairwise_m不能同时使用。p个变量只计算锚点与其余变量的p−1对；其他配对未计算，不能把矩阵空缺解释为无交互。每对的Var 1 VIMP来自该对自身的重复，不能假设与全配对一次调用完全相同。
