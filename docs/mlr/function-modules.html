ALE 与二维 PDP 入口

以下说明按 2026-10-07 的本地源码与帮助文件核对。三个入口均接受 get_exp() 返回的 生存或二分类解释器，也接受用于构造解释器的参数 list；生存解释在解释器指定的预测时点计算。

get_ale()：一阶局部效应

get_ale(EXP.obj, exp_var = "Sex", N = 10000,
        tidy_plot = TRUE, cores = NULL)

返回上方变量分布、下方一阶 ALE 的 patchwork 组合图。exp_var = c(group, focus) 是在同一模型下分别计算各组的一阶 ALE，不是二阶交互。ALE 中心化到均值零； 纵轴表示预测相对变化，不能当作绝对生存概率。

get_ale2()：二阶局部效应

get_ale2(EXP.obj, exp_var, N = 10000,
         scale = "link", engine = "iml", cores = NULL, save = list())

exp_var 指定两个不同变量。返回 ggplot，其 data 含 x1、x2 和 ale， 去除两个主效应后展示模型的二阶局部效应；可选 engine = "ale"。 默认 "link" 在生存任务用 log(-log(S(t)))，二分类用 logit。 Cox / Logistic 的加性结构可在该尺度解释；森林并不在此尺度拟合，建议用 scale = "prob"，并注意概率尺度的非线性本身也可能产生交互形状。

get_pdp2()：二维联合响应

get_pdp2(EXP.obj, exp_var, N = 1000,
         scale = "prob", engine = "iml", cores = NULL, save = list())

返回 ggplot，其 data 含 x1、x2 和 pd，保留两个主效应与交互的联合响应。 默认 "prob" 展示生存概率或事件概率，也可用 "link"；可选 engine = "pdp"。 PDP 会在各网格组合下对所用行的预测求均值，相关变量可能产生数据中罕见的组合。

三者的 N 均为所用解释器行数上限，NULL 使用全部行；当前实现按行序等距抽取， 不能自动保证样本代表性。get_ale() 的按组计算在各组内分别应用上限。 二维入口的 save = list() 默认不写文件；非空配置交给 RegR::save_plt() 保存 PDF。

环形标签、训练副本与结构摘要（2026-10-26）

2026-10-26 按已推送 MLR 45e743a 核对，仍为 0.1.13 / 72 项显式导出。新增绘图与重采样示例均在 Windows / WSL R 4.4.3 执行。

  • 环形百分比图使用 label_args 控制径向标签；重要性页给出长标签及换行对照，SHAP 页验证 mode="sum_per" 的转发。该控制不适用于 per2，布局改变不改变重要性或 SHAP 值。
  • get_model_evaluation() 的线程限制识别带点的参数名，并递归进入 AutoTuner。它修改训练副本，保留调用者对象；48 行、两折重采样核对了调用者、最终模型及折内模型的线程参数，没有据此声称端到端加速。
  • print(exp) 对 exp.obj.sur / exp.obj.log 显示解释器摘要；get_exp() 本身仍保留训练模型的打印。分类摘要中的 apparent AUC 来自建模样本，不是交叉验证性能。
  • mlr_hstats_matrix / mlr_rfint_matrix 的专门打印方法汇总矩阵与配对信息；mlr_shp_clust、mlr_shp_k、mlr_shp_assign 汇总聚类、选 K 或新样本分配。完整矩阵、属性和结果组件仍在对象中；Components: 或结构树帮助定位，不会重新计算。

构建解释器和 get_shp() 准备提示使用消息通道。关闭提示不取消相应计算；历史性能表继续按原源码、数据与平台解释。
