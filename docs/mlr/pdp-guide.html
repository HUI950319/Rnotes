生存 PDP 图谱：时间、分箱与二维交互面

发布于

2026年10月1日

生存 PDP 除变量网格之外，还包含时间维度。本页复用同一个预测剖面，比较固定时间曲线、固定 Age 曲线、等高线、分箱矩阵和三维面；再展示真正二维 PDP。

版本与执行范围： 按 MLR 0.1.13 当前源码核对，使用 WSL R 4.4.3 实际导出本页 16 张参数对照图。实际训练 Cox 模型，使用 survex 公开入口计算剖面，保存 10 张 R 图形与 6 张交互图预览；每张三维交互预览同时链接完整 HTML，可在页面展开旋转、缩放和悬停。

示例准备与读图规则

第一套模型使用 598 人 M1 PTC 队列中的 Age、Sex、Tum_3、Race；原始 time 单位为月。第二套连续 × 连续模型使用完整的 Age、Tum、Sex、Race，共 531 人、147 个 DSS 事件；Tum 缺失导致样本集合不同。二者都来自 ToyData::toy_ptc_m1_cnd。

纵轴为模型平均 S(t)，不是患者的 Kaplan–Meier 估计或干预效果。横轴组合可能超出实际观测的联合支持；尤其连续变量二维网格需要结合原始样本分布阅读。含两个特征和时间的图，仍称二维 PDP：二维指扫描的特征数量。

library(MLR)
library(ToyData)
library(survex)
library(ggplot2)

d <- as.data.frame(ToyData::toy_ptc_m1_cnd[,
  c("time", "DSS", "Age", "Sex", "Tum_3", "Race")])
d <- droplevels(d[complete.cases(d), ])
e60 <- get_exp(d, vars = c("Age", "Sex", "Tum_3", "Race"), surv = 60)
ex <- e60[["EXP"]]
# 多时间解释器：显式设定完整预测时间网格
ex[["times"]] <- seq(0, 120, 10)
set.seed(246)
pdp <- survex::model_profile(ex, variables = "Age", N = 100,
  variable_splits = list(Age = seq(20, 90, 5)), grid_points = 15)
set.seed(246)
pdp2 <- survex::model_profile_2d(ex,
  variables = list(c("Age", "Sex")), N = 80, grid_points = 8)

d2 <- as.data.frame(ToyData::toy_ptc_m1_cnd[,
  c("time", "DSS", "Age", "Tum", "Sex", "Race")])
d2 <- droplevels(d2[complete.cases(d2), ])
e2 <- get_exp(d2, vars = c("Age", "Tum", "Sex", "Race"), surv = 60)
ex2 <- e2[["EXP"]]
ex2[["times"]] <- seq(0, 120, 10)
set.seed(246)
pdp4 <- survex::model_profile_2d(ex2,
  variables = list(c("Age", "Tum")), N = 80, grid_points = 8)

# 检查绘图器将精确匹配哪些值
sort(unique(pdp[["result"]][["_times_"]]))
sort(unique(pdp[["result"]][["_x_"]]))

接口、返回对象与分析流程

计算采用 survex 的公开 model_profile() / model_profile_2d()；MLR 的 .get_profile_sur() 是内部 helper，本文示例无需调用它。绘图读取聚合后的 pdp[["result"]]；个体剖面与平均 PDP 不应混用。

MLR 绘图入口 呈现 返回
plt_pdp_con_time 固定 timepoints 的变量曲线 ggplot
plt_pdp_con_line 固定 con_value 的生存时间曲线 ggplot
plt_pdp_con_area 按连续变量渐变着色的时间曲线 ggplot
plt_pdp_con_contour bins / binwidth 控制的等高线 ggplot
plt_pdp_con_matrix n_col × n_row 分箱平均 ggplot
plt_pdp_3D display 1 静态、2 交互曲面 NULL / plotly
plt_pdp2_3D 连续 × 分类的多面、散点或水平差 plotly
plt_pdp2_3D4 连续 × 连续，按时间着色 plotly

get_vpd(exp_var = c(group, focus)) 生成分组一维曲线；这里的 model_profile_2d() 同时扫描两个特征，在同一个参考样本上平均，是二维联合响应。水平差曲面描述预测差，没有显著性检验或因果解释。

固定时间与固定变量值

时间和变量值必须实际存在于网格；这些绘图器使用精确匹配，不会自动插值。

  • 30 / 60 月
  • 60 / 90 / 120 月
  • 四个 Age 值
  • 密集 Age 值

同一平均预测剖面切出两个随访时间。

plt_pdp_con_time(pdp, timepoints = c(30, 60))

改变 timepoints 后，比较的是不同 S(t)，不是新的模型。

plt_pdp_con_time(pdp, timepoints = c(60, 90, 120))

固定年龄，观察平均生存曲线随时间的变化。

plt_pdp_con_line(pdp, con_value = c(30, 50, 70, 90))

更多曲线会自动扩展色板，增加密度也增加读图负担。

plt_pdp_con_line(pdp, con_value = seq(20, 90, 5))

曲线、等高线与矩阵

同一个预测面可以用曲线、等高线或分箱矩阵展示。分箱平均与连续网格的单点预测不同。

  • 连续颜色曲线
  • 5 档等高线
  • 10 档等高线
  • 4 × 4 分箱
  • 6 × 7 分箱

area 名称对应渐变着色的多条曲线，没有表示置信区间的带状区域。

plt_pdp_con_area(pdp)

较少颜色层级，突出大范围变化。

plt_pdp_con_contour(pdp, bins = 5)

只增加显示层级，没有增加估计精度。

plt_pdp_con_contour(pdp, bins = 10)

每格为时间与 Age 分箱后的平均预测，标注三位小数。

plt_pdp_con_matrix(pdp, n_col = 4, n_row = 4)

分箱变细，格内预测点较少；不等于新增观测。

plt_pdp_con_matrix(pdp, n_col = 6, n_row = 7)

三维预测面

本节同时保留静态预览与可旋转的 Plotly 实例。三维坐标里的时间方向应结合轴标题阅读。

  • 静态三维面
  • 一维变量 × 时间

plot3D 后端在图形设备直接绘图，返回 invisible(NULL)。

plt_pdp_3D(pdp, display = "1")

Plotly 预测面；可旋转、缩放和悬停查看模型的平均 S(t)。

plt_pdp_3D(pdp, display = "2")

  • Age × Sex：散点

plt_pdp2_3D(pdp2, display = "1")

两个连续变量的联合网格，颜色对应一个固定时间；此示例重新拟合 Age、Tum、Sex、Race 模型。

参数调整、保存与使用边界

参数 作用 本页对照
N / grid_points / variable_splits 参考样本与特征计算网格 100 / 80 人；明确 Age 网格
explainer 的 times 生存预测计算时间网格 0–120 月，间隔 10 月
timepoints 从已有时间中精确筛选 30/60 与 60/90/120
con_value 从已有特征值中精确筛选 稀疏与密集 Age 值
bins / binwidth 等高线色阶 5 档与 10 档
n_col / n_row 时间 × 特征分箱 4×4 与 6×7
display 静态/交互；多面/散点/差值 本页所有支持模式
vs_vars display 3 的相减方向 Female − Male

plt_pdp_con_time() / plt_pdp_con_line() / plt_pdp2_3D4() 不会为不存在的值插值；先核对 result，否则可能得到空图。plt_pdp_con_area() 实际画渐变曲线，名称不表示置信区间。

p <- plt_pdp_con_time(pdp, timepoints = c(30, 60))
ggplot2::ggsave("pdp-time.pdf", p, width = 9, height = 6)
w <- plt_pdp_3D(pdp, display = "2")
htmlwidgets::saveWidget(w, "pdp-surface.html", selfcontained = TRUE)

survex 1.2.0 的二维实现，在扫描两列后仅剩一列时可能因自动降维而丢失列名；本页实际使用四特征解释器完成验证。小规模参考抽样可产生无事件子样本的上游提示，本文图形仍是已拟合 Cox 的平均预测，不包含模型开发不确定性。三维多曲面可能互相遮挡，宜同时查看散点和二维切片。
