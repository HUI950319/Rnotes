ggplot 格式化：主题、坐标、图例、条带与面板标签

发布于

2026年10月1日

fmt_plot 和常用 fmt_* 的前后对照、主题选择、坐标尺度及多面板格式化。各节用固定输入比较重要参数，标签页中展示可复制代码与实际结果。

版本与执行范围： 本页按 UtilsR 0.6.8 的公共接口核对；31 个示例已在 WSL R 4.4.3 中实际执行，其中 31 张图已完成构建与 PNG 导出。使用固定随机种子的模拟数据。

数据准备与输入约定

所有示例使用下列模拟数据，因子水平显式固定，重复执行可得到相同输入。

library(UtilsR)
library(ggplot2)
library(patchwork)
set.seed(1003)
dat <- data.frame(group = factor(rep(c("A", "B", "C"), each = 60)),
                  batch = factor(rep(c("Batch 1", "Batch 2"), 90)),
                  x = rnorm(180))
dat[["y"]] <- 0.7 * dat[["x"]] + rnorm(180, sd = 0.6) + rep(c(0, 0.4, 0.9), each = 60)
cols <- c(A = "#0072B2", B = "#E69F00", C = "#009E73")
p <- ggplot(dat, aes(x, y, colour = group)) + geom_point(alpha = 0.6) +
  scale_colour_manual(values = cols) + theme_my()
p_box <- ggplot(dat, aes(group, y, fill = group)) + geom_violin(alpha = 0.65) +
  scale_fill_manual(values = cols) + theme_my()
p_facet <- p + facet_wrap(vars(batch))
p_matrix <- wrap_plots(p, p_box, p, p_box, ncol = 2)

函数选择与重要参数

函数 本页重点参数 语义与条件
fmt_plot() fmt_axis_list、fmt_tag_list、fmt_legend_list、fmt_ref_list 用命名 list 组合对应函数设置；默认均为 NULL
fmt_plot_base() ggtheme、labs_list、scale_y_list/scale_x_list 将 ggplot 组件广播到组合图；scale list 用连续轴设置
theme_my() base_size = 14、base_family = "sans"、border = TRUE、panel.grid 统一基础字号、字体、边框和网格
fmt_axis() x.axis = FALSE、y.axis = FALSE、plot_dims = NULL TRUE 表示隐藏；也可用子图索引或维度选择隐藏位置
fmt_axisText() x/y = NULL、size/color/face x/y 是角度，自动匹配常用文字对齐
fmt_axisTile() colors、mode = "tile"、axis = "x"、tile_height/width 离散轴用颜色块或文字编码，颜色按轴类别对应
fmt_text() xlab/ylab/title/subtitle/caption、title_size/color/hjust 文字和样式可按子图向量化
fmt_panel() grid = "none"、border、bg、grid_color/linewidth 网格可选 none/major/minor/both/x/y
fmt_legend() legend.position/direction、collect = FALSE、ncol/nrow、scale 合并图例需映射与标签一致；缩放影响显示尺寸
fmt_tag() labels、label_position = c(0.02,0.98)、size = 18 NPC 位置是相对面板位置；tl-out 等关键字放在图外
fmt_ref() x/y、linetype = "dashed"、linewidth = 0.5、color 按实际数据坐标放参考线，可多个值
fmt_strip() label、label_fill/color、strip = TRUE 增加或改条带；FALSE 去掉条带
fmt_strip2() top_label/right_label、ncol、top_fill/right_fill 为规则矩阵组合图增加列和行标签
fmt_bg() palcolor/palette、alpha = 0.3、bg_axis = "x" 离散类别背景，与点层填色分别控制
fmt_his() type = "histogram"、height_ratio = 0.3、con_var、binwidth/adjust 插入分布层；直方图与密度各用不同设置
fmt_scale() x/y 命名 list breaks、labels、limits、trans 等交给对应 scale；limits 会移除范围外数据
fmt_expand() mult = 0、add = c(0,0)、axis = NULL 改两端留白，add 是数据尺度上的扩展
fmt_point() type = "point"、jitter.args、sample_n、white_border jitter/beeswarm 减少重叠；sample_n 为每组的绘图抽样数
fmt_boxplot() boxplot.args、inherit.aes = TRUE list 控制图层；当前实现不显示箱线自身的离群点
fmt_com() com_method = "con"、label.y/label.y.prop、label 统计比较标注，不能当作纯主题调整

基础图与主题

  • 基础散点图
  • 去边框和网格
  • 热图主题
  • 简化坐标箭头

后续坐标、图例和标签对照都使用这份基础图。

p

字号、边框和网格同时调整，点的数据保持一致。

p + theme_my(base_size = 16, border = FALSE,
             panel.grid = element_blank(), panel.grid.minor = element_blank())

展示 theme_heat 的实际坐标与图例样式；选择主题后仍可继续用 fmt_* 调整。

p + theme_heat(base_size = 16)

theme_blank 返回主题和注释组合，可直接加到图上。

p + theme_blank(xlab = "Axis 1", ylab = "Axis 2", lab_size = 14)

坐标、网格与文字

  • 隐藏坐标
  • 旋转轴标签
  • 轴颜色条
  • 彩色轴文字
  • 网格和背景
  • 标题与字号

x.axis=TRUE 隐藏横轴；FALSE 表示这一调用不额外隐藏对应轴。

fmt_axis(p, x.axis = TRUE, y.axis = FALSE)

x 控制文字角度而不是轴范围；旋转后的对齐由函数自动处理。

fmt_axisText(p_box, x = 45, size = 12, color = "#37474F")

在离散横轴外增加颜色条，与 A/B/C 的类别固定对应。

fmt_axisTile(p_box, colors = cols, mode = "tile", axis = "x",
             tile_height = 0.08, tile_border = "white")

改用文字颜色编码类别；没有额外轴颜色块。

fmt_axisTile(p_box, colors = cols, mode = "text", axis = "x",
             text_size = 13, text_face = "bold")

只保留 y 方向网格，边框和背景独立设置。

fmt_panel(p, grid = "y", grid_color = "#CAD5DF", grid_linewidth = 0.3,
          border = TRUE, border_linewidth = 0.7, bg = "#F5F8FC")

文字样式由 fmt_text 控制，示例明确标注模拟数据。

fmt_text(p, xlab = "Standardized exposure", ylab = "Simulated response",
         title = "Scatter comparison", subtitle = "Fixed simulated input",
         caption = "No causal interpretation", title_size = 18,
         title_color = "#263238", title_hjust = 0, axis_title_size = 14)

图例与参考线

  • 底部横向图例
  • 缩放图例
  • 组合图共用图例
  • 多条参考线

图例位置、方向、列数与标题可以分别设置。

fmt_legend(p, legend.position = "bottom", legend.direction = "horizontal",
           ncol = 3, title = "Cohort")

放大图例元素以配合大画布，数据点的大小未因此改变。

fmt_legend(p, legend.position = "right", scale = 1.4)

两个面板使用相同颜色映射与图例名称，适合合并图例。

fmt_legend(wrap_plots(p, p, ncol = 2), collect = TRUE,
           legend.position = "bottom", title = "Cohort")

参考线使用真实数据坐标；颜色、线型会按线条数循环对应。

fmt_ref(p, x = 0, y = c(0, 1), color = c("#777777", "#B2182B"),
        linetype = c("dashed", "dotted"), linewidth = 0.7)

条带与面板编号

  • 给单图加条带
  • 隐藏分面条带
  • 图内编号
  • 图外编号
  • 行列双层标签

单图也可用条带标明结果类型。

fmt_strip(p_box, label = "Distribution", label_fill = "#DCECF5", label_color = "#16324F")

隐藏文字与条带背景，保留两个实际分面。

fmt_strip(p_facet, strip = FALSE)

使用相对面板位置添加 A–D 编号；不会改变横纵轴数值。

fmt_tag(p_matrix, labels = c("A", "B", "C", "D"),
        label_position = "tl", size = 14, label.size = 0.4)

tl-out 将标签放在整幅子图边缘，适合避免遮挡数据；padding 明确给出四个方向的单位值。

fmt_tag(p_matrix, labels = c("A", "B", "C", "D"),
        label_position = "tl-out", size = 13, label.padding = grid::unit(rep(0.12, 4), "lines"))

规则两列矩阵增加列标题与行标题，行列颜色分别指定。

fmt_strip2(p_matrix, top_label = c("Scatter", "Distribution"),
           right_label = c("Row 1", "Row 2"), ncol = 2,
           top_fill = c("#DDEBF7", "#FCE4D6"), right_fill = c("#E2F0D9", "#EDEDED"))

尺度、留白与分布插图

  • 刻度和格式
  • scale 范围限制
  • 两端留白
  • 插入直方图
  • 插入密度

只设置 breaks/labels，改变刻度与格式而不筛去观测。

fmt_scale(p, x = list(breaks = seq(-2, 2, 1)),
          y = list(breaks = seq(-1, 3, 1), labels = scales::label_number(accuracy = 0.1)))

scale limits 将范围外点移除；需要保留统计计算数据的观察窗时，使用 coord_cartesian。

fmt_scale(p, y = list(limits = c(-1, 2)))

左端留白 3%、右端留白 15%，给图内注释预留横向空间。

fmt_expand(p, mult = c(0.03, 0.15), add = c(0, 0), axis = "x")

直方图的横轴来自 x，binwidth 决定分箱；height_ratio 控制插入的相对高度。

fmt_his(p, type = "histogram", con_var = "x", height_ratio = 0.25,
        binwidth = 0.4, his_color = "#9AB8D1", his_alpha = 0.6)

密度平滑用 adjust 控制，与直方图 binwidth 的含义不同。

fmt_his(p, type = "density", con_var = "x", height_ratio = 0.3,
        adjust = 0.8, his_color = "#9AB8D1")

图层叠加与统一入口

  • 分类背景
  • 抖动点与白边
  • 每组抽样
  • 箱线叠加
  • 比较标注
  • 命名 list 组合格式
  • 广播主题与标签

离散轴每个类别增加背景色，与小提琴的颜色映射分别设置。

fmt_bg(p_box, palcolor = c("#E8F1F8", "#FFF1D6", "#E4F3EA"), alpha = 0.45)

点层横向抖动减少遮挡，纵向不抖动；白边通过可填色点形实现。

fmt_point(p_box, type = "jitter", size = 1.6, white_border = TRUE,
          jitter.args = list(width = 0.16, height = 0), seed = 32)

每组抽取 20 个点用于显示，基础小提琴仍使用完整数据。

fmt_point(p_box, type = "jitter", sample_n = 20, seed = 32,
          jitter.args = list(width = 0.16, height = 0))

通过命名 list 调整箱线图层，函数不显示箱线自身的离群点。

fmt_boxplot(p_box, boxplot.args = list(width = 0.18, alpha = 0.25, colour = "#222222"))

con 在当前横轴顺序上比较相邻组，标注高度与图形数据范围相联系。

fmt_com(p_box, com_method = "con", label = "p.format", label.y.prop = 1.15)

fmt_plot 复用对应 formatter 的命名 list，重要设置显式写入各自入口。

fmt_plot(p, fmt_legend_list = list(legend.position = "bottom", ncol = 3),
         fmt_ref_list = list(y = 0, color = "#B2182B", linewidth = 0.7),
         fmt_tag_list = list(labels = "A", label_position = "tr", size = 15),
         plot.margin = c(10, 10, 10, 10))

统一主题和文字应用到组合图各子图；保留组合布局。

fmt_plot_base(p_matrix, ggtheme = theme_my(base_size = 12, border = FALSE),
              labs_list = list(caption = "Simulated data"))

返回对象、保存与使用边界

多数 formatter 支持 ggplot、patchwork 和图列表，尽量保留输入对象类型。fmt_axisTile(mode="tile")、插图及图外标签可能把结果组织为 patchwork。格式化顺序有实际影响：后添加的 theme/scale 可能覆盖前面的设置。

final_plot <- fmt_legend(p, legend.position = "bottom")
# ggplot2::ggsave("formatted-scatter.pdf", final_plot, width = 8, height = 5)

坐标观察窗、scale limits 与绘图抽样的作用不同。统计标注、添加箱线和分布图层会增加新的计算；配色、字号和标签位置主要改变显示。组合图中共享图例应保证类别映射一致。
