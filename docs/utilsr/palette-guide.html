library(ggplot2)

函数选择与重要参数

目标 参数及默认值 使用要点
检索色板 pal_list(pattern=NULL, type="all", show=TRUE) 正则过滤名字；type 为 discrete/continuous；show=FALSE 仍打印名称，返回 list 不可见
提取颜色 pal_get(palette="Paired", n=NULL, x=NULL) NULL（pal_lancet）、名称、R 能绘制的颜色、颜色向量或完整命名的色板 list；x 与 n 同时给出时优先 x
稳定类别映射 x 为 factor/character/logical 返回按水平命名的颜色；factor 按 levels，其余按首次出现顺序，缺失值不占颜色
按数值取色 x 为 numeric 每个元素按数值在色板上取色；NA、Inf 返回 NA，所有值相同时取中间色
颜色数量 n pal_get 的 n 可为0，保留取前缀或插值规则；pal_show/来源查看函数要求正整数；各来源的生成与单色显示遵守下方原生规则
顺序与透明度 reverse=FALSE、alpha=1 返回颜色顺序反转和透明通道，数值 x 时 reverse 翻转色标、元素位置不变；alpha 范围 0–1，默认 1 保留颜色自带的透明度
色卡输出 pal_show(output="gt") 默认 gt 表格；本页图形用 output=“gg”；console 输出控制台色卡
色卡布局 max_colors=20、index=NULL、label=TRUE、label_size=3、ncol=NULL index 为非空唯一正整数索引；ncol/label/label_size用于ggplot，max_colors限制实际预览数
Brewer type="all"、n=NULL qual/seq/div 分类；最大原生颜色数受该色板限制
HCL n=8、type="all" qualitative/sequential/diverging；从指定方案生成 n 色
ggsci pattern/index、n、reverse/alpha 使用完整色板名或正则；如 ggsci_npg_nrc，而不是只有期刊缩写
viridis n=8、begin=0、end=1、direction=1、alpha=1 begin/end 控制取色域，direction=-1 反向；生成时覆盖指定范围
已内置对象 pal_lancet/pal_bar/pal_paraSC/pal_other/pal_heat 是颜色向量或 list；热图 pal_heat 用连续插值，不能当作五个离散等级

控制台色卡与注册集合的范围（2026-11-02）

pal_list() 仍在控制台打印注册集合的名称与可选色块，不返回Viewer表格；gt预览用 pal_show()。窄控制台保留完整色板名，放不下的数量、类型另行换行。show_color() 按stdout支持的颜色深度渲染，透明背景合成到白底，但RGBA标签和可复制的原始向量保留；无色日志跳过ANSI样式构建。图形预览与无色/256色/真彩终端的视觉效果不能直接等同。

console_colours <- c("#FF000080", "transparent", "steelblue")

窄控制台、缺失颜色与可复制属性（2026-11-03）

show_color()接受无类、无维度的字符颜色向量，rev只接受普通逻辑标量。实际NA_character_、字面"NA"和"transparent"按R的透明颜色显示，但返回值与可复制表达式保留它们各自的原值、名称和其他属性；反转时名称随颜色反转。数值属性保留17位精度。环境属性及标记为 bytes 编码的名称不能保证由 dput() 精确重建；需要完整对象保真时，对返回值使用 saveRDS()。

色块按stdout能力、可用宽度与渲染器实际支持的颜色深度绘制；索引终端按其发出的颜色选择文字对比度。旧cli版本最多支持256色，用户自定义终端主题仍可能改变观感。HEX标签保持完整，不把窄控制台的色块换行解释成数据变化。

console_values <- structure(c(missing = NA_character_, literal = "NA", clear = "transparent", red = "#FF000080"),
  cutoff = c(1.2345678901234567, pi))
console_plain <- withr::with_options(list(width = 12, cli.width = 12, cli.num_colors = 1L),
  capture.output(console_return <- withVisible(show_color(console_values, rev = TRUE))))
console_true <- withr::with_options(list(width = 12, cli.width = 12, cli.num_colors = 16777216L),
  capture.output(show_color(console_values, rev = TRUE)))

共享 .resolve_color() 将数值颜色索引固定为 RGBA HEX，保留 double 精度，并在进入绘图前检查截断后的整数范围。目录入口 pal_get() 的数字开头字符串须先通过颜色文本校验。重复数值、单色及常数映射继续保留输入位置、缺失位置和透明度。长向量验证的内部优化不改变这些输出合同。

绘图解析器的数字颜色与输入校验（2026-11-03）

UtilsR 0.6.22的共享绘图解析器.resolve_color()会把数字颜色索引（包括数字字符串）按调用时的grDevices::palette()转成固定RGBA。普通颜色名和缺失颜色保持原值。它服务于绘图入口；日常检索和连续插值仍用pal_get()，其颜色向量校验不因此放开数字索引。

下面先指定base颜色索引2为绿色，解析后再把索引2改为金色；已返回的颜色仍为绿色。局部作用域退出时恢复原base palette。

library(UtilsR)
frozen_colours <- local({
  old <- grDevices::palette(c("black", "#009E73"))
  on.exit(grDevices::palette(old))
  resolved <- UtilsR::.resolve_color(c("2", "red"))
  grDevices::palette(c("black", "gold"))
  resolved
})

命名映射也按真实颜色校验（2026-11-03）

plt_cat()、plt_con()和plt_dist()选中命名映射中的值后，现在共用同一字面颜色校验。某一类别的值不能写成"lancet"等色板名来要求展开；非法颜色在构图阶段报错。数字索引会先固定成RGBA，类别名和顺序仍由命名映射控制。为直接比较颜色，下例把分布柱图的alpha显式设为1；其默认值仍为0.7。
