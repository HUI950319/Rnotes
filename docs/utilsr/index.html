UtilsR 概览

修改于

2026年10月31日

UtilsR 是其余几个包共用的底层工具包：绘图主题、因子与表格格式化、数据探索和系统诊断。

主要函数： theme_my()、fct_to_combine() 等

参考文档：https://hui950319.github.io/UtilsR/　源码：https://github.com/HUI950319/UtilsR

注记版本与复现记录

本轮补充按已推送 UtilsR 5a9d8eb（0.6.14）导出源码，在 Windows / WSL R 4.4.3 独立运行。新增预览来自真实控制台输出；原有截图保留各自注明的历史快照。

专题教程

各页采用可复制代码、参数对照和实际结果；从分类、连续分布与格式化开始阅读。

页面 覆盖内容
分类变量：plt_cat 的 11 种图形与重要参数 计数与百分比、堆积与并排、分层布局、缺失与空水平，以及流向和集合图
连续变量：分布、统计比较与多面板布局 plt_con 的四种图形、箱线与原始点叠加、统计标注、纵轴观察窗和多变量布局
ggplot 格式化：主题、坐标、图例、条带与面板标签 fmt_plot 和常用 fmt_* 的前后对照、主题选择、坐标尺度及多面板格式化
配色系统：检索、颜色映射与离散和连续色阶 pal_list、pal_get、pal_show 及 Brewer、HCL、ggsci、viridis 色卡，命名映射与热图应用
数据检视与缺失：摘要、缺失模式和 KNN 插补 lv / check_na 的返回与特殊值，check_size 的指定环境与共享存储，plt_na 布局、联合缺失及 KNN 插补
组合散点图：边际分布、双分组与配对差值 PlotScatter1/2/3 的点、椭圆、回归、相关、边际布局、栅格化和配对差值插图
分类分布与流向：堆积柱、Alluvial 和 Sankey plt_dist 的分派，plt_alluvial 的比例、间隔和命名 list，plt_sankey 的节点次序与标签
集合比较：Venn、UpSet、成员分组与 Jaccard 热图 plt_upset 的列表和指示列输入、区域标签和返回数据，PlotHeatmapJaccard 的顺序、色阶和矩阵
双侧比较图：Butterfly、分布镜像与 Dumbbell 堆积与并排双侧柱形、min-max 和透明度映射、镜像分布、蜂群与配对哑铃插图
排名与共享特征：Rank、方法一致性和圆形棒棒糖 排名高亮与截断、两种组内缩放、秩和原始分数相关、点映射、共享特征连线及圆形布局
因子与统计文本：排序、合并、分箱和区间格式化 fct_cat 的互斥模式、临床水平顺序、固定与自动分箱、列组合与缺失，以及 CI/P 值的格式和边界
图形组合与导出：展平、grob、插图和栅格化 嵌套 patchwork 的选择和重排、gtable 边缘组件与插图、两种 raster 后端、面板尺寸和真实 PDF 比较

绘图、集合身份与打印边界（2026-10-31）

从 5a9d8eb 核对到已推送 05f4c9638991e55c36c582e285b8cdd86a6b6634，新增82次提交；UtilsR为0.6.18、104项显式导出。函数总数未增加，主要是输入合同、分组与显示边界、保存顺序及预览开销的修复。

  • 缺失图：原始缺失掩码、SPSS缺失、id列、同名显示和比例端点。
  • 连续变量：纵向抖动默认为0、参考组比较、独立坐标与分位数观察窗、完整SD、缺失组点计数。
  • 集合图：身份与显示名分离、真实缺失集合、透明区域、集合叠色和完整Venn/UpSet组合。
  • 分类背景：核对原始计数和背景位置；该已推送快照的空水平仍待包内修复，未把本地未推送改动当作新支持。
  • 分布与流带：fmt_text在测量和保存前应用，导出的PDF与返回图文字一致。
  • 表格与P值、分布和结构、窄屏键值：行身份、日期与内嵌列、十进制文本、极端尺度、带类向量、字素簇换行与盒内样式。

新增示例固定RegR e2926a6为保存依赖，在Windows / WSL R4.4.3实际执行；原图继续保留各自快照。没有新增性能倍数、修改统计定义或安装包。

参考组与数据边界（2026-10-24）

2026-10-24 按已推送 UtilsR 875c710 更新五个教程，新增示例均在 Windows / WSL R 4.4.3 执行。

任务 阅读入口

对齐分布图样本与命名颜色，核对矩阵和标签位置 分类分布与流向

fct_cat() 的正式参数为 ref_idx，旧名 binary_ref 仍警告兼容。lv() 返回原输入，check_na() 返回报告表；环境诊断的 CIM 回退与跨库包副本计数见检视页。完整变更入口见功能模块索引。

因子组合与统计文本（2026-10-23）

2026-10-23 按已推送 UtilsR 23ba378 更新因子与统计文本教程：组合自动保留缺失、区分文字 NA，说明组内计算改变参考水平的风险，并验证 data.table 源数据保护。旧版“缺失会拼成文字”的示例已替换。

P 值新例区分界限文本与确切数值：<0.001 不推断星号，略大于 0.05 的数值即使显示为 0.050 也不添星；缺失、非法值及映射边界均在 Windows / WSL R 4.4.3 验证，附两张原生 HTML 表。

数据检视（2026-10-21）

2026-10-22 按已推送 UtilsR 3269981 更新数据检视教程：check_size(envir=...) 可检查局部环境，method="lobstr" 的总计对共享存储去重；四张原生表展示环境选择、两种计量方法及对数背景。新增示例已在 Windows / WSL R 4.4.3 执行。

lv() 选列检视后仍返回完整输入；check_na() 当前返回 gt 报告表，不能再把它当作返回原数据的管道步骤。返回合同与特殊值、分箱后的实际组数继续保留独立说明；完整更新入口见功能模块索引。
