排名与共享特征：Rank、方法一致性和圆形棒棒糖

发布于

2026年10月1日

排名高亮与截断、两种组内缩放、秩和原始分数相关、点映射、共享特征连线及圆形布局。各节用固定输入比较重要参数，标签页中展示可复制代码与实际结果。

版本与执行范围： 本页按 UtilsR 0.6.8 的公共接口核对；28 个示例已在 WSL R 4.4.3 中实际执行，其中 25 张图已完成构建与 PNG 导出。使用固定随机种子的模拟数据。

数据准备与输入约定

score_mat 与 rank_long 是相同的三组模拟分数，两种输入用于交叉演示；cor_long 在相同名称上制造两方法差异；circle_dat 同时包含五个共享名称和各组三个独有名称。

library(UtilsR)
library(ggplot2)
set.seed(1010)
feat <- c("HALLMARK_ALPHA", "HALLMARK_BETA", "KEGG_GAMMA", "TF_DELTA(+)",
          "GOBP_EPSILON", paste0("Gene_", 6:12))
score_mat <- cbind(A = runif(12, 2, 10), B = runif(12, 10, 40), C = runif(12, 0.1, 1))
rownames(score_mat) <- feat
rank_long <- do.call(rbind, lapply(colnames(score_mat), function(g)
  data.frame(cell = g, feature = feat, score = score_mat[, g], row.names = NULL)))
cor_long <- subset(rank_long, cell %in% c("A", "B"))
cor_long[["method"]] <- "Method 1"
method2 <- cor_long
method2[["method"]] <- "Method 2"
method2[["score"]] <- 1.5 * method2[["score"]] + rnorm(nrow(method2), 0, 3)
cor_long <- rbind(cor_long, method2)
cor_long[["weight"]] <- rep(seq(0.2, 1, length.out = 12), 4)
cor_signed <- cor_long
cor_signed[["score"]] <- cor_signed[["score"]] - 10
circle_dat <- do.call(rbind, lapply(c("A", "B", "C"), function(g)
  data.frame(group = g, name = c(paste0("Shared", 1:5), paste0(g, "_Unique", 1:3)),
             value = runif(8, 0.1, if (g == "A") 0.9 else 0.6))))
circle_dat[["color"]] <- ifelse(grepl("Shared", circle_dat[["name"]]), "#0072B2", "#D55E00")

排名输入与筛选

  • 命名向量
  • 多组矩阵
  • 长表和组序
  • 选两个组
  • 增加高亮数
  • 截断显示行

一个命名向量进入单面板；名称是特征，数值是排序依据。

PlotRank(score_mat[, "A"], top_n = 4, title = "Single group A")

矩阵行名为特征、列名为组；各组内部独立排序和自由坐标，原始分数跨度不同。

PlotRank(score_mat, top_n = 4, ncol = 3, label_size = 3)

用列名声明长表输入，与矩阵相同数据；group_levels 改变组序。

PlotRank(rank_long, "cell", "feature", "score", group_levels = c("C", "B", "A"),
         top_n = 3, ncol = 3, label_size = 3)

groups 先选择组；没有被选择的 C 不参与展示。

PlotRank(score_mat, groups = c("B", "A"), top_n = 3, ncol = 2)

top_n 从 4 改为 7，只增加高亮和标签，全部 12 个点仍在。

PlotRank(score_mat[, "A"], top_n = 7, point_size = 2.5, label_size = 3)

max_show=6 才把图和返回数据缩减为排名前六；其余特征未展示。

PlotRank(score_mat[, "A"], top_n = 3, max_show = 6)

排名缩放与返回

  • 完整组范围缩放
  • 显示范围缩放
  • 保留原特征名称
  • 核对数据和高亮

采用原始每组 12 个值的 min-max，截断后最低显示值通常仍大于 0。

PlotRank(score_mat, top_n = 3, max_show = 6, value_scale = "group",
         ylab = "Scaled against full group", ncol = 3, label_size = 3)

选项名为 top_n，实际按 max_show 后六个显示值缩放；每组最低显示点为 0。

PlotRank(score_mat, top_n = 3, max_show = 6, value_scale = "top_n",
         ylab = "Scaled against displayed rows", ncol = 3, label_size = 3)

关闭名称清理，保留前缀、下划线及 (+)；清理只改变显示标签。

PlotRank(score_mat[, "A"], clean_names = FALSE, top_n = 4,
         highlight_color = "#D55E00", base_color = "#E1E5EB", label_size = 3)

both 的 plot 可继续排版，data 可核对排序、缩放和 IsTop；这里展示实际返回前八行。

res <- PlotRank(score_mat, max_show = 6, top_n = 3, value_scale = "top_n", return_type = "both")

秩相关与数值相关

  • 组内秩比较
  • 原始分数比较
  • 分别 min-max
  • 分别标准化
  • 带符号 log1p

每组×方法先降序排秩，再按同名特征对齐；图中统计为组内 Spearman。

PlotRankCor(cor_long, "feature", "score", "cell", "method",
            label.size = 2.7, max.overlaps = Inf) +
  theme(plot.margin = margin(8, 22, 8, 8))

横纵轴为两方法原始分数，相关改为 Pearson；Method 2 的单位尺度是本页人为改变的。

PlotRankCor(cor_long, "feature", "score", "cell", "method", use_rank = FALSE,
            show.label = FALSE, pt.size = 3.5) +
  theme(plot.margin = margin(8, 22, 8, 8))

每组内两个方法分别缩放到 0–1，数值可比较但绝对分数信息消失。

PlotRankCor(cor_long, "feature", "score", "cell", "method", use_rank = FALSE,
            scale_x = "minmax", scale_y = "minmax", show.label = FALSE) +
  theme(plot.margin = margin(8, 22, 8, 8))

按各组×方法的均值和 SD 标准化；线性变换不改变该组 Pearson 相关。

PlotRankCor(cor_long, "feature", "score", "cell", "method", use_rank = FALSE,
            scale_x = "zscore", scale_y = "zscore", show.label = FALSE) +
  theme(plot.margin = margin(8, 22, 8, 8))

变换为 sign(x)×log1p(abs(x))，允许负数；Pearson 在变换后显示值上计算，可能改变相关。

PlotRankCor(cor_signed, "feature", "score", "cell", "method", use_rank = FALSE,
            scale_x = "log1p", scale_y = "log1p", show.label = FALSE) +
  theme(plot.margin = margin(8, 22, 8, 8))

点映射与对齐数据

  • 大小与透明度映射
  • 关闭参考线和标签
  • 对齐后的数据

点大小和透明度均编码同一辅助 weight；输入跨两方法一致，平均后保持该值。

PlotRankCor(cor_long, "feature", "score", "cell", "method", size_by = "weight",
            size_range = c(2, 7), alpha_by = "weight", alpha_range = c(0.25, 1),
            show.label = FALSE, legend.position = "bottom", palette = c("#0072B2", "#D55E00")) +
  theme(plot.margin = margin(8, 22, 8, 8))

参考线和标签只影响显示，组内的秩和相关计算保持不变。

PlotRankCor(cor_long, "feature", "score", "cell", "method", show.diag = FALSE,

圆形共享特征

  • 默认共享与独有
  • 每组选前五
  • 按完整组缩放
  • 按入选组缩放

24 个条目，Shared1–5 在三组都有；颜色及内弧表示名称共享，独有条目用另一色。

PlotCircleLollipop(circle_dat, label_cex = 0.55)

这里 top_n 真正删掉每组未入选行，共享判定也在筛选后重算；与 PlotRank 的高亮含义不同。

PlotCircleLollipop(circle_dat, top_n = 5, label_cex = 0.65)

原始每组八个值确定 min-max，再显示前五；最低入选值通常不为 0。

PlotCircleLollipop(circle_dat, top_n = 5, value_scale = "group",
                   label_cex = 0.6, yaxis_label = "Full-group scaled score")

各组入选五个值伸展到 0–1，不能用径向长度比较不同组原始分数大小。

PlotCircleLollipop(circle_dat, top_n = 5, value_scale = "top_n",
                   label_cex = 0.6, yaxis_label = "Selected scaled score")

圆形标签与布局

  • 标签在扇区内
  • 标签移到外圈
  • 旋转和组间间隔
  • 无标签和内弧
  • 逐行配色

outside 把标签置于灰色扇区框内；height 控制连接线长度而不是字体大小。

PlotCircleLollipop(circle_dat, top_n = 5, label_side = "outside",
                   label_cex = 0.6, label_height = 3, point_cex = 1, sector_bg = "#EDF2F7")

outer 把名称放在最外圈，减小轨道高度给标签留空间。

PlotCircleLollipop(circle_dat, label_side = "outer", label_cex = 0.5,
                   label_height = 3, track_height = 0.28)

同时展示组序、旋转、末端开口与内弧高度；数值和入选条目不变。

PlotCircleLollipop(circle_dat, top_n = 5, group_levels = c("C", "B", "A"),
                   start_degree = 45, gap_after = 35, gap_between = 7,
                   track_height = 0.28, link_h = 0.45, link_lwd = 1, label_cex = 0.55)

减少装饰仍保留共享配色，但缺少条目标签时需要配套数据表。

PlotCircleLollipop(circle_dat, show_links = FALSE, show_labels = FALSE,
                   show_yaxis = FALSE, common_color = "#009E73", unique_color = "#CC79A7")

使用明确的逐行颜色列，覆盖 common/unique 配色；本例保留原行序和全部条目。

PlotCircleLollipop(circle_dat, color_col = "color", show_links = FALSE,
                   label_side = "outside", label_cex = 0.5)

返回对象、保存与使用边界

Rank 和 RankCor 返回 ggplot；Rank 另可返回排名数据或 plot/data。圆形棒棒糖通过 circlize 在当前设备直接绘图，返回 invisible(NULL)，不能传给 ggsave。需要保存时使用圆图自己的 filename，或先打开 PDF/PNG 设备再调用；本页已核对真实 PDF。

圆图 value_scale=none 的值若超出 [0,1]，当前实现仍以所有入选值的全局 min-max 转成径向位置，并将最小位置下限设为 0.05。因此“none”不保证任意原始单位按原值映射半径。本页默认 circle_dat 已在 [0,1]。

Rank 排的是输入分数，不能从高亮推出显著性；清理后同名条目不会自动合并。RankCor 相关只使用两列都有效的对齐特征：use_rank=TRUE 用 Spearman；FALSE 用 Pearson，即使控制台字段仍写 rho。重复特征×组×方法记录会在排秩之后按均值合并，适宜在输入阶段先明确定义聚合规则。圆图连线只表示筛选后名称共享，不表示方法一致性、网络强度或统计检验。
